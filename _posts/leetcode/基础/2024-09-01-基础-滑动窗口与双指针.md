滑动窗口和双指针都是由暴力破解法优化而来的，减少了暴力破解法重复的一些步骤，将复杂度降低到O(N)。

双指针是两个独立的指针同向或者相向的运动，这个过程中两个指针的移动是根据不同的场景来的，但它们不论怎么移动，在过程中都非常像一个滑动的窗口。滑动窗口可以通过滑动来避免求做一些重复的运算或者是根据题意来说没有意义的一些运算，所以时间复杂度相对来说比较友好。

## 总结
维护一个滑动窗口的要点：

1. 滑动窗口存的是什么？也就是滑动窗口要维持一个什么状态
2. 右边界什么时候移动，什么时候停止？
3. 左边界什么时候移动，什么时候停止？
4. 一般来说，当右指针停止时，左指针就开始移动；当左指针停止时，右指针就开始移动。

## 同向双指针
### [209. Minimum Size Subarray Sum](https://leetcode.cn/problems/minimum-size-subarray-sum/)
长度最小的子数组：求和 >= target 的连续子数组的最小长度。

**暴力解法**：枚举右端点 right，再向左扩展求和，找到 >= target 的最短子数组。时间复杂度 O(n²)。问题在于每次枚举都重新累加，做了大量重复计算。

**为什么能用滑动窗口（关键）**：本题所有元素都是正数，所以窗口的和具有单调性——right 右移窗口变大，sum 只增不减；left 右移窗口变小，sum 只减不增。正因为 sum 随窗口大小单调变化，找到一个满足的窗口后，收缩一定会破坏它、扩张只会更满足，无需回头重新组合。**如果数组含负数，这个单调性就不成立，滑动窗口不再适用。** 记住这句话：滑动窗口成立的前提是"条件相对窗口大小是单调的"。

**正确的思考模型**：不要想成"窗口维护一个和 >= target 的子数组"。而是——**固定右端点 right，尽量收缩左边界，找到以 right 结尾的最短合法窗口，记录长度，然后 right 继续右移。** 每个子数组都会作为"某个 right 结尾的窗口"被考虑到，所以不会漏解。

左指针永不回退——回退只会让窗口变长、不可能优于已记录的答案;而元素全为正保证 sum 随窗口单调,
因此 right 右移时最小合法左边界也只会右移,左右指针各自单向走完全程,总代价 O(n)。

**收缩循环的方向（最容易错的点）**：
- 求最小长度（本题）：`while (合法) { 记录答案; 收缩; }`——趁还合法时先记录，再收缩。
- 求最大长度（如无重复最长子串）：`while (不合法) { 收缩; } 记录答案;`——收缩到重新合法后再记录。

先问自己"在求最小还是最大"，就能确定用哪种。

```java
class Solution {
  public int minSubArrayLen(int target, int[] nums) {
    int left = 0;
    int sum = 0;
    int minLen = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
      sum += nums[right];               // 扩张：右端点纳入窗口
      while (sum >= target) {           // 趁窗口仍合法
        minLen = Math.min(minLen, right - left + 1);  // 先记录
        sum -= nums[left];              // 再收缩左边界
        left++;
      }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
  }
}
```

要点：`minLen` 在 `sum -= nums[left]` 之前记录，保证测量的是合法窗口；外层不需要额外的 `if (sum >= target)`，while 已经判断了。

时间复杂度 O(n)——每个元素最多被加入一次、移出一次，常数不计入大 O；空间复杂度 O(1)。

**⚠️ 易错点：题意是"和 ≥ target"，不是"和 == target"。** 因为是 ≥，最短的合法窗口它的和往往严格大于 target（整数没法刚好卡到，再缩一个就掉到 target 以下了）。别把它理解成只找"和恰好等于 target"的窗口，那样很多用例会漏解。

**变体：如果题意改成"和恰好 == target"，解法还一样吗？**

骨架一样（还是滑动窗口、O(n)、靠正数的单调性），但**收缩条件和记录时机变了**：

- `≥ target`：窗口够大就合法 → 趁 `sum >= target` 时收缩，收缩前先记录（每个合法窗口都记，取最小）。
- `== target`：和必须刚好相等 → 趁 `sum > target`（严格大于）时收缩，收缩到不再超之后，再判断是否正好等于。

```java
for (int right = 0; right < n; right++) {
    sum += nums[right];
    while (sum > target && left <= right) {   // 注意是 > 不是 >=
        sum -= nums[left];
        left++;
    }
    if (sum == target) {                       // 收缩后才判断是否刚好命中
        minLen = Math.min(minLen, right - left + 1);
    }
}
```

原理：对固定的 right，左指针右移时 sum 严格递减（每个数都是正的），所以 sum 对每个值最多命中一次。收缩到 sum 第一次 ≤ target：正好落在 target 就记录，若直接跳过（从 >target 掉到 <target）就说明以该 right 结尾没有恰好为 target 的窗口。

**关键前提：滑动窗口能用在 == / ≥ 上，全靠"所有元素为正数 → sum 单调"。若数组含 0 或负数，`== target` 不能再用滑动窗口，需改用前缀和 + 哈希表（见 560. 和为 K 的子数组）**——有负数时收缩不再保证 sum 单调递减，可能来回穿过 target。

### [713. Subarray Product Less Than K](https://leetcode.cn/problems/subarray-product-less-than-k/)
这道题很有启发，用右端点的视角看问题。右指针移动到一个位置，就计算以这个右指针为右端点（右边界）的所有答案。左指针配合移动始终保证滑动窗口中的元素满足题意。

滑动窗口维护的是积小于K的子数组，右指针移动直到积大于等于K，此时 移动左指针，左指针移动直到积小于K。

```java
class Solution {
  public int numSubarrayProductLessThanK(int[] nums, int k) {
    int res = 0;
    int product = 1;
    int left = 0;
    for (int right = 0; right < nums.length; right++) {
      product *= nums[right];
      while (left <= right && product >= k) {
        product /= nums[left];
        left++;
      }
      // 以right为右端点的个数
      // [10] : [10] 
      // [10, 5] : [10, 5] [5]
      // [5, 2]: [5, 2] [2]
      // [num_l, num_r]: [l, r] [l+1, r] ... [r, r] -> r - l + l 
      res += right - left + 1;
    }
    return res;
  }
}
```

### [3. Longest Substring Without Repeating Characters](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)
跟上面的713题的思路是一样的。

维护一个滑动窗口，滑动窗口始终存储没有相同字符的元素，同时维护一个set集合，存储滑动窗口中的元素。

当遇到滑动窗口中已经有的字符时：说明最长不重复的特性被打破了，那就只能从滑动窗口中重复的字符下一个字符开始算。

```java
class Solution {
  public int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int len = 0;
    int left = 0;
    for(int right = 0; right < s.length(); right++) {
      while(left <= right && set.contains(s.charAt(right))) {
        set.remove(s.charAt(left));
        left++;
      }
      set.add(s.charAt(right));
      len = Math.max(len, right - left + 1);
    }

    return len;
  }
}
```

### [228.Summary Ranges](https://leetcode.cn/problems/summary-ranges/)
灵神分组循环模版：

```java
i, n = 0, len(nums)
while i < n:
    start = i
    while i < n and ...:
        i += 1
    # 从 start 到 i-1 是一段
    # 下一段从 i 开始，无需 i+=1
```

```java
class Solution {
  public List<String> summaryRanges(int[] nums) {
    List<String> res = new ArrayList<>();
    int left = 0;
    int right = 0;
    while(right < nums.length) {
      left = right;
      while(right < nums.length - 1 && nums[right + 1] - nums[right] == 1) {
        right++;
      }

      StringBuilder sb = new StringBuilder();
      if(left < right) {
        sb.append(nums[left] + "->" + nums[right]);
      } else {
        sb.append(nums[left]);
      }
      right++;
      res.add(sb.toString());
    }
    return res;
  }
}
```

## 相向双指针
### [167. Two Sum II - Input Array Is Sorted](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/)
在**非递减有序**数组中找两个数使其和为 target，返回它们的下标（**1-based**，且 index1 < index2），题目保证恰有一解，要求空间 O(1)。

**暴力解法**：两层 for 枚举所有二元组，O(n²)。浪费在哪：它把数组当成无序的，完全没用上"已排序"这个最强的条件。

**为什么能用相向双指针（关键）**：设当前区间为 `[left, right]`，因为数组有序，`nums[left]` 是区间里最小的、`nums[right]` 是最大的。看 `sum = nums[left] + nums[right]`：

- `sum > target`：`nums[right]` 与区间内**任何**数配对都 ≥ `nums[left] + nums[right] > target` → `nums[right]` 这个数**永远不可能出现在答案里**，`right--` 排除它。
- `sum < target`：`nums[left]` 与区间内**任何**数配对都 ≤ `nums[left] + nums[right] < target` → `nums[left]` 永远不可能出现在答案里，`left++` 排除它。
- `sum == target`：命中，直接返回。

**这才是 O(n) 的来源：每一步不是"试了一个组合"，而是"排除了一个数（相当于排除了一整行/一整列的组合）"。** 想象一张 n×n 的和表，从右上角出发，每次砍掉一行或一列——这和 [240. 搜索二维矩阵 II] 从右上角开始搜是同一个思想。

**正确性（不会漏解）**：设答案是 `(i, j)`，`i < j`。维护不变量 **`left ≤ i` 且 `j ≤ right`**（答案始终在当前区间内）。

- 初始 `left = 0, right = n-1`，成立。
- 若 `sum > target` 要执行 `right--`，此时 `right ≠ j`：否则 `nums[left] + nums[j] ≤ nums[i] + nums[j] = target`（因为 `left ≤ i` 且有序），与 `sum > target` 矛盾。所以 `right > j`，减完仍有 `right ≥ j`。
- `left++` 同理，此时必有 `left < i`。

所以指针永远不会跨过答案，最终一定停在 `(i, j)` 上。

**时间复杂度 O(n)**：`left` 只增、`right` 只减，两者相遇即停，总移动次数 ≤ n。**空间复杂度 O(1)**。

```java
class Solution {
  public int[] twoSum(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1;
    // left < right：题意要求 index1 < index2，同一个元素不能用两次
    while (left < right) {
      int sum = nums[left] + nums[right];
      if (sum == target) {
        return new int[]{left + 1, right + 1};   // 题目是 1-based
      } else if (sum > target) {
        right--;    // nums[right] 太大，排除
      } else {
        left++;     // nums[left] 太小，排除
      }
    }
    return new int[]{-1, -1};   // 题目保证有解，走不到这里
  }
}
```

**⚠️ 易错点**

1. **循环条件是 `left < right`，不是 `left <= right`。** 相等意味着同一个元素用了两次，题意不允许。
2. **返回的是 `left + 1, right + 1`**，本题下标从 1 开始，忘了 +1 是最常见的 WA。
3. **不要写成外层 while 套内层 while 去"一次性把 right 移到位"**：
    ```java
    while (nums[left] + nums[right] > target) { right--; }   // ❌ 缺少 left < right 保护
    ```
    在"保证有解"的前提下它凑巧不会越界（就是上面那个不变量的证明），但一旦数组无解，`right` 会一路减到负数抛 `ArrayIndexOutOfBoundsException`——写在后面的"无解返回值"永远执行不到。三分支的单层循环既短又没有这个坑。
4. **`sum` 用 int 存**：本题约束下不会溢出；但若元素范围到 `10^9` 级别（如某些变体），要用 `long`。

**和 [1. Two Sum] 的对比**：1 题数组无序，只能哈希表 O(n) 时间 / O(n) 空间（排序会破坏原下标）。本题因为**已经有序**，双指针把空间降到 O(1)，这就是"有序"这个条件换来的收益。反过来说，如果一道题让你先排序再找两数之和，说明它**不关心原下标**（比如 15. 3Sum 返回的是值不是下标）。

**变体一：找出所有和为 target 的数对（去重）**——命中后不能直接返回，要两边同时收缩并跳过重复元素：

```java
while (left < right) {
  int sum = nums[left] + nums[right];
  if (sum == target) {
    res.add(List.of(nums[left], nums[right]));
    int l = nums[left], r = nums[right];
    while (left < right && nums[left] == l) left++;    // 跳过所有相同的左值
    while (left < right && nums[right] == r) right--;  // 跳过所有相同的右值
  } else if (sum > target) right--;
  else left++;
}
```
这段就是 15. 3Sum 里被复用的内核。

**变体二：和最接近 target（如 16. 3Sum Closest）**——移动规则完全不变（依然靠"排除一个数"），只是每一步额外用 `|sum - target|` 更新一次答案，循环走完再返回。

### [15. 3Sum](https://leetcode.cn/problems/3sum/)
三数之和

暴力破解法：时间复杂度O(N^3)

双指针法：

1. 不可以包含重复：利用排序避免重复答案。
2. 确定第一个数，剩下的两个数 就变成了两数之和的题；

```java
class Solution {
  public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> results = new ArrayList<>();
    int len = nums.length;
    // 固定一个数，剩下选择两个数，让问题变成two-sum

    for(int i = 0; i < len - 2; i++) {
      // 防止出现重复的数
      if(i != 0 && nums[i] == nums[i-1]) {
        continue;
      }
      // 如果前三个数之和大于0，后续不可能有大于0的情况了
      if(nums[i] + nums[i+1] + nums[i+2] > 0) {
        break;
      }
      // 如果这个数 和最后两个数的和小于0，说明nums[i]太小，继续下一个数
      if(nums[i] + nums[len-2] + nums[len-1] < 0) {
        continue;
      }
      List<List<Integer>> result = twoSum(nums, i + 1, -nums[i]);
      for(List<Integer> list : result) {
        results.add(Arrays.asList(nums[i], list.get(0), list.get(1)));
      }
    }

    return results;
  }
  // 两数之和 nums必须是排好序的
  // 返回结果不能是重复的
  public List<List<Integer>> twoSum(int[] nums, int start, int target) {

    Set<Integer> set = new HashSet<>();
    List<List<Integer>> result = new ArrayList<>();
    Set<Integer> duplicate = new HashSet<>();
    for(int i = start; i < nums.length; i++) {
      // 防止出现重复结果
      if(duplicate.contains(nums[i])) {
        continue;
      }
      if(set.contains(target - nums[i])) {
        duplicate.add(nums[i]);
        result.add(Arrays.asList(target - nums[i], nums[i]));
      }
      set.add(nums[i]);
    }
    return result;
  }
}
```

```java
class Solution {
  public int maxArea(int[] height) {
    // min(h(l), h(r)) * (r - l)
    int left = 0;
    int right = height.length - 1;
    int maxArea = 0;
    while(left < right) {
      int area = Math.min(height[left], height[right]) * (right - left);
      maxArea = Math.max(maxArea, area);
      if(height[left] < height[right]) {
        left++;
      } else {
        right--;
      }
    }

    return maxArea;
  }
}
```

```java
class Solution {
  public int countSubstrings(String s) {
    int count = 0;
    for(int i = 0; i < s.length(); i++) {
      count += countPalindrome(s, i, i);
      // 
      count += countPalindrome(s, i, i + 1);
    }
    return count;

  }
  private int countPalindrome(String s, int start, int end) {
    int count = 0;
    while(start >= 0 && end < s.length() && s.charAt(start) == s.charAt(end)) {
      count++;
      start--;
      end++;
    }

    return count;
  }
}
```

由于数组是升序的，双指针的策略是快慢指针都在初始位置，快指针一直往前走，直到遇到不重复的数字才停下来，此时慢指针和快指针之间必定都是重复的数字，慢指针再进一步后替换不重复的数字，然后快指针又继续走，直到遇到与慢指针不重复的数字，继续替换。最后慢指针在的位置就是删除重复项之后的不重复数组中末尾。

本质就是要将不重复的数字逐渐向前覆盖。

滑动窗口保证左指针和右指针 的数字都是相同的。

左指针在与右指针不一样时，右指针替换成左指针的数字，然后向左移动一步，右指针则继续移动，直到与左指针上的数字不一样；

```java
class Solution {
  public int removeDuplicates(int[] nums) {
    int slow = 0;
    int fast = 0;
    while(fast < nums.length) {
      if(nums[fast] != nums[slow]) {
        slow++;
        nums[slow] = nums[fast];
      }
      // [0,1,1,1,2,3]
      // [1,1,1,2,3]
      fast++;
    }
    return slow + 1;
  }

}
```

时间复杂度：O(N)

空间复杂度：O(1)

```java
            sum = sum - nums[left - 1] + nums[right];

            right++;
```

```java
  public void sortColors(int[] nums) {
    // all in [0, p0) == 0
    // all in [p0, i) == 1;
    // all in (p2, len - 1) == 2;
    int len = nums.length;
```

### [76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)
求最小覆盖子串，这道题跟[209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/)非常像。

1. use two pointers to create a window of letters in s, which could have all the characters from t
2. expand the right ponter until all characters of t are covered
    1. 当[left, right]不包含该子串t，[left + k1, right - k2]也不会包含该子串，所以要继续移动right
3. once all the character are covered, mvoe the left pointer and ensure that all the characters are still covered to minimize the subarray size.
    1. 当[left, right]包含了该子串t，就没有必要再看[left, right + k]了，因为[left, right + k]的长度必然大于[left, right]; 
    2. 所以要移动left。如果移动的left后窗口是否仍然包括t，所以移动的是多余的字符，但如果移动后窗口不包括t了，说明把关键字符给移除去了，就继续找，如果找到了就就继续移动left，看有没有最小的，没找到的话就说明这个字符是不可或缺的，那关于它的最小窗口长度在第一次也就记录下来了。
4. continue expanding the right and left pointers until you reach the end of s

这道题的难点不在于滑动窗口，在于时间复杂度的限制.

```java
class Solution {
  public String minWindow(String s, String t) {
      // -1 判断是否无解
    int ansLeft = -1;
    int ansRight = s.length();
    int[] cntS = new int[128];
    int[] cntT = new int[128];
    for(int i = 0; i < t.length(); i++) {
      cntT[t.charAt(i)]++;
    }
    int left = 0;
    int right = 0;
    while(right < s.length()) {
      cntS[s.charAt(right)]++;
      while(left <= right && isCovered(cntS, cntT)) {
        if(right - left < ansRight - ansLeft) {
          ansLeft = left;
          ansRight = right;
        }
        cntS[s.charAt(left)]--;
        left++;
      }
      right++;
    }
    return ansLeft < 0 ? "" : s.substring(ansLeft, ansRight + 1);
  }
  private boolean isCovered(int[] cntS, int[] cntT) {
    for(int i = 'a'; i <= 'z'; i++) {
      if(cntS[i] < cntT[i]) {
        return false;
      }
    }
    for(int i = 'A'; i <= 'Z'; i++) {
      if(cntS[i] < cntT[i]) {
        return false;
      }
    }
    return true;
  }
}
```

```java
class Solution {
  public String minWindow(String s, String t) {

    // -1 判断是否无解
    int ansLeft = -1;
    int ansRight = s.length();
    int[] cntS = new int[128];
    int[] cntT = new int[128];
    // 本意是子串有没有包含t，cntS[i] >= cntT[i]
    // 定义less为，cntS[i] < cntT[i]的个数，即子串中有less种字母的出现次数小于t中字母的出现次数；
    // 可以简单理解为不同的字母个数（可能会出现）
    // less == 0 意味着包含子串包含t
    int less = 0;
    for(int i = 0; i < t.length(); i++) {
      if(cntT[t.charAt(i)] == 0) {
        // 初始化less为t中的不同字母个数
        less++;
      }
      cntT[t.charAt(i)]++;
    }
    int left = 0;
    int right = 0;
    while(right < s.length()) {
      char cr = s.charAt(right);
      cntS[cr]++;
      // 子串中的cr字符已经和t中一样，所以不同字母个数-1
      if(cntS[cr] == cntT[cr]) {
        // cr的出现次数从< 变成>=
        less--;
      }
      // less==0说明是子串是包含了t的，那么就移动left
      while(left <= right && less == 0) {
        if(right - left < ansRight - ansLeft) {
          ansLeft = left;
          ansRight = right;
        }
        char cl = s.charAt(left);
        // 移动之前发现cl是t中的字符，意味着移动之后不同字符个数需要加1
        if(cntS[cl] == cntT[cl]) {
          // cl的出现次数由>=变成<
          less++;
        }
        left++;
        cntS[cl]--;
      }
      right++;
    }
    return ansLeft < 0 ? "" : s.substring(ansLeft, ansRight + 1);
  }
}
```

### [424. 替换后的最长重复字符](https://leetcode.cn/problems/longest-repeating-character-replacement/)
替换k次使得 重复的子串（所有的字符都一样）更长

暴力破解法：枚举出所有的子串，对于每一个子串：

1. 如果子串所有的字符都一样，就考虑长度更长的重复子串；
2. 如果子串中有不一样的字符，替换掉出现次数最多 以外的字符。

时间复杂度O(N^3)

滑动窗口：

我恍然大悟，滑动窗口其实就是这个可变大小的容器，我们趋向于保持这个容器中不重复的元素小于等于k个，当不重复的元素大于k个的时候，无论你怎么替换都不可能满足，因此如果不重复的元素大于k个的时候，就将滑动窗口的左侧向右移动，减少滑动窗口的长度直到滑动窗口的不重复元素小于等于k个，此时右侧的窗口就可以继续向右试探。

滑动窗口 维护 的是 不重复的元素小于k个，

```java
class Solution {
  public int characterReplacement(String s, int k) {
    int len = s.length();

    int left = 0;
    int right = 0;
    // 滑动窗口中出现次数最多的字符个数
    int maxCount = 0;
    // 记录滑动窗口中的每个字符出现的频次
    int[] freq = new int[26];
    int res = 0;
    while(right < len) {
      freq[s.charAt(right)- 'A']++;   
      maxCount = Math.max(maxCount, freq[s.charAt(right)- 'A']);
      // maxCount [left, right]中出现次数最多的字符个数
      // 不重复的元素大于k时，间接说明已经替换成功了，左指针向右移动
      if (right - left + 1 - maxCount > k) {
        // 保证freq[]中存的是滑动窗口中的
        freq[s.charAt(left)- 'A']--;
        left++;
        // 这里没有维护maxCount，是因为：
        // 1. 右边界如果读到了移除去的left的字符，那么maxCount依然准确；
        // 2. 如果右边界读到的不是刚才移除去的字符，新的子串要变得更长，但是依然小于maxCount。
      }
      // 滑动窗口能维护的最大长度就是替换后的重复字符的最大长度
      res = Math.max(res, right - left + 1);
      right++;
    }
    return res;
  }
}
```

### [1695. Maximum Erasure Value](https://leetcode.cn/problems/maximum-erasure-value/)
[1695. 删除子数组的最大得分](https://leetcode.cn/problems/maximum-erasure-value/)

思路跟3是一样的，left和i维护一个滑动窗口，同时维护一个set集合保存滑动窗口的东西。

遇到相同的元素滑动窗口左侧开始收缩，直到没有相同的元素；

遇到不相同的元素滑动窗口右侧继续移动，直到遇到相同的元素；

```java
class Solution {
  public int maximumUniqueSubarray(int[] nums) {

    int left = 0; 
    int len = nums.length;
    Set<Integer> sets = new HashSet<>();
    int sum = 0;
    int res = 0;
    for(int i = 0; i < len; i++) {
      if(sets.contains(nums[i])) {
        while(i < len && nums[left] != nums[i]){
          sets.remove(nums[left]);
          sum -= nums[left];
          left++;
        }
        left++;

      } else {
        sets.add(nums[i]);
        sum += nums[i];
      }
      res = Math.max(res, sum);
    }

    return res;
  }
}
```

```java
      if (sLen < pLen) {
        return new ArrayList<Integer>();
      }

      int[] sCount = new int[26];

        pCount[p.charAt(i) - 'a']++;
        sCount[s.charAt(i) - 'a']++;
      }

      // s == p
      if(Arrays.equals(sCount, pCount)) {

      for(int i = 0; i < sLen - pLen; i++) {
        sCount[s.charAt(i) - 'a']--;
        sCount[s.charAt(i + pLen) - 'a']++;
        if(Arrays.equals(sCount, pCount)) {
          res.add(i + 1);
        }
      }

      return res;

    }
```

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int sLen = s.length(), pLen = p.length();

        if (sLen < pLen) {
            return new ArrayList<Integer>();
        }

        List<Integer> ans = new ArrayList<Integer>();
        int[] count = new int[26];
        for (int i = 0; i < pLen; ++i) {
            ++count[s.charAt(i) - 'a'];
            --count[p.charAt(i) - 'a'];
        }

        int differ = 0;
        for (int j = 0; j < 26; ++j) {
            if (count[j] != 0) {
                ++differ;
            }
        }

        if (differ == 0) {
            ans.add(0);
        }

        for (int i = 0; i < sLen - pLen; ++i) {
            if (count[s.charAt(i) - 'a'] == 1) {  // 窗口中字母 s[i] 的数量与字符串 p 中的数量从不同变得相同
                --differ;
            } else if (count[s.charAt(i) - 'a'] == 0) {  // 窗口中字母 s[i] 的数量与字符串 p 中的数量从相同变得不同
                ++differ;
            }
            --count[s.charAt(i) - 'a'];

            if (count[s.charAt(i + pLen) - 'a'] == -1) {  // 窗口中字母 s[i+pLen] 的数量与字符串 p 中的数量从不同变得相同
                --differ;
            } else if (count[s.charAt(i + pLen) - 'a'] == 0) {  // 窗口中字母 s[i+pLen] 的数量与字符串 p 中的数量从相同变得不同
                ++differ;
            }
            ++count[s.charAt(i + pLen) - 'a'];

            if (differ == 0) {
                ans.add(i + 1);
            }
        }

        return ans;
    }
}
```

```java
class Solution {
    public int numberOfPoints(List<List<Integer>> nums) {
      Collections.sort(nums, (a, b) -> a.get(0) != b.get(0) ? a.get(0) - b.get(0) : a.get(1) - b.get(1));
      int ans = 0;
      int i = 0;
      while(i < nums.size()) {
        List<Integer> list  = nums.get(i);
        int start = list.get(0);
        int end = list.get(1);
        i++;
        while(i < nums.size() && end >= nums.get(i).get(0)) {
            end = Math.max(end, nums.get(i).get(1));
            i++;
        }
        ans += (end - start + 1);
      }
      return ans;
    }
}
```
