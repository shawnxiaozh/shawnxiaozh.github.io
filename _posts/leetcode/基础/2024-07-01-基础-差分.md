## 性质
前缀和是不断的求和，差分则是不断的求差。

$ 
diff[i] = \left\{\begin{aligned} 
nums[0]  \quad i=0 \\ 
nums[i]-nums[i-1] \quad i>0\\
\end{aligned}\right. $

如何根据差分数组反推出原数组元素呢？

差分数组的性质：

1、差分数组的前缀和就是原数组：

$ nums[k]=nums[k-1]+diff[k] $

$ nums[k]=\sum_{i=0}^{i=k}{diff[i]} $

2、原数组nums[n-1]的前缀和为：

$ preSum[n]=\sum_{i=0}^{i=n-1}{nums[i]}=\sum_{i=0}^{n-1}\sum_{j=0}^{i}{diff[j]}=\sum_{i=0}^{n-1}{(n-i+1)diff[i]} $

## 适用场景
前缀和：频繁查询某个区间的累加和；

差分：频繁对原始数组的某个区间的元素进行加减。如果不用差分，时间复杂度为 操作次数 * 平均区间长度，用差分的时间复杂度为 操作次数。

## [370. Range Addition](https://leetcode.cn/problems/range-addition/)

```java
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
      // 暴力求解
      return bruce(length, updates);
    }

    public int[] bruce(int length, int[][] updates) {
      int[] res = new int[length];
      for(int[] update : updates) {
        int start = update[0];
        int end = update[1];
        int value = update[2];
        for(int i = start; i <= end; i++) {
          res[i] += value;
        }
      }
      return res;
    }
}
```

如果我们用暴力破解，那时间复杂度就是O(M*N)

数组的一段区间[i, j]全部加上一个相同的数value，

$ nums[i]=nums[i]+value\\
...\\
nums[j]=nums[j]+value $

如果看它的差分数组的话，

由于

$ nums[i] - nums[i-1] =diff[i]\\
nums[j+1]-num[j]=diff[j+1] $

得：

$ nums[i] +value- nums[i-1] =diff[i]+value\\
nums[j+1]-(num[j]+value)=diff[j+1]-value $

意味着这一段区间的起点i加上了addition，结束点后一点i+1减去了value。

> 某段区间加上value的原数组还是可以通过变化后的差分数组求前缀和得到的
>

所以就等价于

$ diff[i] =diff[i]+value\\
diff[j+1] =diff[j+1]-value $

```java
class Solution {
  public int[] getModifiedArray(int length, int[][] updates) {
    // 差分数组
    return diff(length, updates);

  }
  public int[] diff(int length, int[][] updates) {

    int[] diff = new int[length];

    for(int[] update : updates) {
      int start = update[0];
      int end = update[1];
      int value = update[2];

      diff[start] += value;
      if(end < length - 1) {
        diff[end+1] -= value;
      } 
    }
    
    int[] res = new int[length];
    res[0] = diff[0];
    for(int i = 1; i < length; i++) {
      res[i] = res[i-1] + diff[i];
    }
    return res;
  }
}
```

## [1109. Corporate Flight Bookings](https://leetcode.cn/problems/corporate-flight-bookings/)
一模一样的题：

```java
class Solution {
  public int[] corpFlightBookings(int[][] bookings, int n) {
    int[] diff = new int[n];

    for(int[] booking : bookings) {
      int start = booking[0] - 1;
      int end = booking[1] - 1;
      int reserved = booking[2];
      diff[start] += reserved;
      if(end < n - 1) {
        diff[end + 1] -= reserved;
      }
    }
    int[] res = new int[n];
    res[0] = diff[0];
    for(int i = 1; i < n; i++) {
      res[i] = res[i-1] + diff[i];
    }

    return res;
  }
}
```
