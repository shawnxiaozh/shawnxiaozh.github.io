## 前缀和简介
数组序列[a0, a1, ...., an]，前缀和定义为

$ S_i=\sum_{j=0}^{j=i}a_j $

区间和定义

$ R[left, right]=\sum_{i=left}^{i=right}a_j $

区间和和前缀和的联系为：

$ R[left, right]=S_{right} - S_{left} + a_{left} $

前缀和的优势在于要求区间和时，可以用前缀和数组在O(1)的时间内推导出来，而不需要重新以O(N)的时间去计算一遍区间的和。

相当于前缀和已经缓存了区间和的结果，并且避免了重复的计算，这跟动态规划中的重复子问题是类似的。

注意在实际的 代码编写中，为了代码的简洁，我们总是以`preSum[i+1]`来表示`nums[0:i]`的和。

那么`nums[j:i]`的区间和 就为：`preSum[i + 1] - preSum[j]`。

### [303. 区域和检索 - 数组不可变](https://leetcode.cn/problems/range-sum-query-immutable/)
$ sumRange(left, right)=preSum[right]-preSum[left-1] $

```java
class NumArray {
  int[] preSum;

  public NumArray(int[] nums) {
    preSum = new int[nums.length + 1];
    for(int i = 0; i < nums.length; i++) {
      preSum[i + 1] = preSum[i] + nums[i];
    }
  }

  public int sumRange(int left, int right) {
    return preSum[right + 1] - preSum[left];
  }
}
```

初始化时间复杂度O(n)，检索O(1)

空间复杂度O(n)

### [304. 二维区域和检索 - 矩阵不可变](https://leetcode.cn/problems/range-sum-query-2d-immutable/)
令$ f[i,j]=\sum_{k=0}^{k=i}\sum_{m=0}^{m=j}{matrix[k][m]} $，则：

$ f[i][j]=f[i][j-1] +  f[i-1][j] - f[i][j] + matrix[i-1][j-1] $

```java
class NumMatrix {
  int[][] preSum;
  public NumMatrix(int[][] matrix) {
    preSum = new int[matrix.length + 1][matrix[0].length + 1];
    for(int i = 0; i < matrix.length; i++) {
      for (int j = 0; j < matrix[0].length; j++) {
        preSum[i + 1][j + 1] = preSum[i + 1][j] + preSum[i][j + 1] - preSum[i][j] + matrix[i][j];
      }
    }
  }

  public int sumRegion(int row1, int col1, int row2, int col2) {
    return preSum[row2 + 1][col2 + 1] - preSum[row2 + 1][col1] - preSum[row1][col2 + 1] + preSum[row1][col1];
  }
}

/**
* Your NumMatrix object will be instantiated and called as such:
* NumMatrix obj = new NumMatrix(matrix);
* int param_1 = obj.sumRegion(row1,col1,row2,col2);
*/
```

初始化时间复杂度O(m*n)，检索时间复杂度O(1)

空间复杂度O(m*n)

## 前缀异或
前缀和的加法运算可以推广到其它运算，只要该运算满足区间减法，即i位置和j位置的前缀运算结果的差值是区间[i,j]的运算结果。

这类运算常见异或操作

### [1310. 子数组异或查询](https://leetcode.cn/problems/xor-queries-of-a-subarray/)
```java
class Solution {
  public int[] xorQueries(int[] arr, int[][] queries) {
    int n = arr.length;
    int[] preXor = new int[n];
    // preXor[j-1] ^ preXor[i] = arr[j]^arr[j+1]^...^arr[i]
    for(int i = 0; i < n; i++) {
      preXor[i] = i == 0 ? arr[i] : preXor[i - 1] ^ arr[i];
    }

    int[] result = new int[queries.length];
    for(int i = 0; i < queries.length; i++) {
      int low = queries[i][0];
      int high = queries[i][1];
      result[i] = low == 0 ? preXor[high] : preXor[low - 1] ^ preXor[high];
    }
    return result;
  }
}
```

这道题最有意思的是得到了一个公式：

前缀异或 

$ preXor[j-1] \oplus preXor[i]  = (nums[0] \oplus nums[1] \oplus ... \oplus nums[j-1]) \oplus (nums[0] \oplus ... nums[j-1]) \oplus (nums[j] \oplus ... \oplus nums[i]) $

由于 

$ X \oplus X =0 $

故

$ preXor[j-1] \oplus preXor[i]  = nums[j] \oplus nums[j+1] \oplus ... \oplus nums[i]
 $

### [238. 除自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)
不能用前缀积再加上除法，因为当有元素为0时就无法判断了。

最直接的是使用两个前缀数组，一前一后的算前缀积。当然，从左侧开始的前缀数组可以用一个变量`product`代替。

```java
class Solution {
  public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] suffix = new int[n + 1];
    suffix[n] = 1;
    for(int i = n - 1; i >= 0; i--) {
      suffix[i] = suffix[i + 1] * nums[i];
    }

    int[] product = new int[n];
    int preProduct = 1;
    for(int i = 0; i < n; i++) {
      product[i] = preProduct * suffix[i + 1];
      preProduct *= nums[i];
    }
    return product;
  }
}
```

为了达到O(1)的空间复杂度，可以使用输出数组来代替后缀数组：

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {

      int[] suffix = new int[nums.length];
      suffix[nums.length - 1] = nums[nums.length - 1];
      for(int i = nums.length - 2; i >= 0; i--) {
        suffix[i] = suffix[i + 1] * nums[i];
      }

      int preProduct = 1;
      for(int i = 0; i < nums.length; i++) {
        suffix[i] = preProduct * (i == nums.length - 1 ? 1 : suffix[i + 1]);
        preProduct *= nums[i];
      }
      return suffix;
    }
}
```

### [724. 寻找数组的中心下标](https://leetcode.cn/problems/find-pivot-index/)
```java
class Solution {
  public int pivotIndex(int[] nums) {
    int[] suffix = new int[nums.length + 1];
    for(int i = nums.length - 1; i >= 0; i--) {
      suffix[i] = suffix[i + 1] + nums[i];
    }

    int preSum = 0;
    int pivot = -1;
    for(int i = 0; i < nums.length; i++) {
      if(preSum == suffix[i + 1]) {
        pivot = i;
        break;
      }
      preSum += nums[i];
    }
    return pivot;
  }
}
```

### [325. Maximum Size Subarray Sum Equals k](https://leetcode.cn/problems/maximum-size-subarray-sum-equals-k/)
暴力求解法只需要判断`nums[j:i]`的区间和`rangeSum = preSum[i + 1] - preSum[j]`是否等于`k`。

```java
class Solution {
  public int maxSubArrayLen(int[] nums, int k) {
    int[] preSum = new int[nums.length + 1];
    for(int i = 0; i < nums.length; i++) {
      preSum[i + 1] = preSum[i] + nums[i];
    }

    int longest = 0;
    for(int i = 0; i < nums.length; i++) {
      for(int j = 0; j <= i; j++) {
        // [j:i]
        if(preSum[i + 1] - preSum[j] == k && i - j + 1 >= longest) {
          longest = i - j + 1;
        }
      }
    }
    return longest;
  }
}
```

time complexity: O(N^2)，因为第i个数与前面的每一个数都要计算一遍的区间和，来判断`preSum[i + 1] - preSum[j] == k`，但实际上我们可以把第`j`个数`preSum[j]`都存到map中，然后看`preSum[i + 1] - k`在map中是否存在，存在则说明有等于k的区间和。

> 需要注意的是：因为我们求的是区间和等于k的最长长度，所以我们的map存的是这个数第一次出现时的索引。
>

优化版：

```java
class Solution {
  public int maxSubArrayLen(int[] nums, int k) {
    int[] preSum = new int[nums.length + 1];
    for(int i = 0; i < nums.length; i++) {
      preSum[i + 1] = preSum[i] + nums[i]; 
    }

    Map<Integer, Integer> numToIndexMap = new HashMap<>();
    // Map中存的0的索引一定是在nums[0]对应的索引前一个，这样才能将nums[0]考虑进来。
    // 注意我们用preSum[i + 1]来表示nums[0:i]的前缀和，所以0的索引为0；
    // 如果preSum[i]来表示nums[0:i]的前缀和，所以0的索引为-1；
    numToIndexMap.put(0, 0);

    int maxLen = 0;
    for(int i = 0; i < nums.length; i++) {
      // nums = [1, -1, 5, -2, 3] k = 1, 0, 4, 3
      maxLen = Math.max(maxLen, i + 1 - numToIndexMap.getOrDefault(preSum[i + 1] - k, i + 1));
      numToIndexMap.putIfAbsent(preSum[i + 1], i + 1);
    }
    return maxLen;
  }
}
```

time complexity: O(N)， time complexity: O(N)

preSum数组可以优化为一个数。

```java
class Solution {
  public int maxSubArrayLen(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, -1);
    int n = nums.length;
    int result = 0;
    int preSum = 0;
    for(int i = 0; i < n; i++) {
      preSum += nums[i];
      if(map.containsKey(preSum - k)) {
        result = Math.max(result, i - map.get(preSum - k));
      }        
      map.putIfAbsent(preSum, i);
    }
    return result;
  }
}
```

### [525. 连续数组](https://leetcode.cn/problems/contiguous-array/)
Given a binary array nums, return the maximum length of a contiguous subarray with an equal number of 0 and 1.

这道题用前缀和，可以转换成区间的和等于其长度的一半的最大区间长度。

暴力破解法：

```java
class Solution {
  public int findMaxLength(int[] nums) {
    return bruce(nums);

  }
  private int bruce(int[] nums) {

    int[] preSum = new int[nums.length + 1];
    for (int i = 0; i < nums.length; i++) {
      preSum[i + 1] = preSum[i] + nums[i];
    }

    int res = 0;
    for(int i = 0; i < nums.length; i++) {
      for (int j = 0; j < i; j++) {
        // 长度必然是偶数
        if((i - j + 1) % 2 == 0) {
          // 区间和必然是长度的一半
          if(preSum[i + 1] - preSum[j] == (i - j + 1) / 2) {
            res = Math.max(res, i - j + 1);
          }
        }
      }
    }
    return res;
  }
}
```

本来是想用HashMap继续优化的，发现目标值preSum[i+1] - preSum[j] 是根据区间长度来变化的，即 (i - j + 1) / 2。与325的情况不一样，我们明确知道一个区间应该去匹配一个固定的k值，所以如果要用map，我们得对区间定义一个明确的值，如果要保证一个区间中0和1始终是相等的，除了其和是长度一半，还可以看0和1的数量差值（**减法也是一种加法**），满足条件的区间其差值始终是0。这个0就满足我们要的固定值。 

因此，我们会构造一个map，key是0和1的个数差值，value是其第一次出现的位置。

$ preDiff[i]=\sum_{j=0}^{i}\{nums[j] == 0 \quad? \quad-1 : 1\} $

$ \sum_{i=0}^{m-1}\sum_{j=0}^{i}max(i-j) \quad if \quad (preDiff[i]-preDiff[j]==0) $

第一步：把「数量相同」变成「和为 0」

原题要数 0 和 1 的个数，这是两个计数器，不好维护。但如果把每个 0 看成 -1：

一段里 0 和 1 一样多 ⟺ 这段的和恰好为 0

一下就变成了「求和为 0 的最长子数组」，这才是前缀和能上场的前提。

第二步：和为 0 ⟺ 两端前缀和相等

记 pre[i] 为前 i 个元素的和，那么子数组 (i, j] 的和 = pre[j] - pre[i]。

要它等于 0，就是 pre[j] == pre[i]。

所以问题彻底变成了：在前缀和序列里，找两个值相同的位置，让它们离得最远。

```java
class Solution {
  /**
  preSum[i + 1] := nums[0:i] 的1和0的数量之差
  preSum[i + 1] = 
  1. preSum[i] + 1 when nums[i] == 1
  2. preSum[i] - 1 when nums[i] == 0
  
  preSum[i + 1] - preSum[j] = rangeSum[j + 1 : i + 1]
  实际上就是区间中的 1和0的数量之差, 等于0的就是满足要求的区间
*/ 
  public int findMaxLength(int[] nums) {

    int[] preSum = new int[nums.length + 1];
    for (int i = 0; i < nums.length; i++) {
      preSum[i + 1] = nums[i] == 1 ? preSum[i] + 1 : preSum[i] - 1;;
    }
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 0);
    int maxLen = 0;
    for(int i = 0; i < nums.length; i++) {
      maxLen = Math.max(maxLen, i + 1 - map.getOrDefault(preSum[i + 1], i + 1));
      map.putIfAbsent(preSum[i + 1], i + 1);

    }
    return maxLen;
  }
}
```

空间优化版本：

```java
class Solution {
  /**
    preSum[i + 1] := nums[0:i] 的1和0的数量之差
    preSum[i + 1] = 
    1. preSum[i] + 1 when nums[i] == 1
    2. preSum[i] - 1 when nums[i] == 0
    
    preSum[i + 1] - preSum[j] = rangeSum[j + 1 : i + 1]
    实际上就是区间中的 1和0的数量之差, 等于0的就是满足要求的区间
  */

    int n = nums.length;
    int preDiff = 0;
    Map<Integer, Integer> map = new HashMap<>();

        preDiff++;
      } else {
        preDiff--;
      }
      if(map.containsKey(preDiff)) {

      }
      map.putIfAbsent(preDiff, i);
    }
    return result;
  }
}
```

### [523. Continuous Subarray Sum](https://leetcode.cn/problems/continuous-subarray-sum/)
同余定理：(b - a) % k  <-> b % k == a % k

证明：

正着推：(b - a) % k -> b % k == a % k

b = x * k + r1, a = y * k + r2

b - a = (x - y) * k + r1 - r2

(b - a) % k = r1 - r2 

当(b - a)%k == 0时， r1 = r2。

有：b % k == a % k

反着推： b % k == a % k -> (b - a) % k 

b = x * k + r1, a = y * k + r2

r1 == r2

b - a = (x - y) * k

(b - a ) % k = 0

如果利用同余定理，判断子数组`[j : i]`能够被`k`整除就等价于判断

$ preSum[j] \% k == preSum[i+1] \% k $

因此我们将$ preSum[i] \% k $作为key，记录第一次出现的位置作为value存起来。之所以记录第一次，是因为长度至少为2

[0,i] 和 [0, j]的前缀和模K的余数相等时，说明[i+1, j]的区间和模K的余数等于0

因此前缀状态为「前缀和模K的余数数」，值为第一次出现的索引位置。

```java
class Solution {
  public boolean checkSubarraySum(int[] nums, int k) {
    // key: preSum[i] % k, value : 第一次出现的位置

    int[] preMod = new int[nums.length + 1];
    int preSum = 0;
    for(int i = 0; i < nums.length; i++) {
      preSum += nums[i];
      preMod[i + 1] = preSum % k;
    }
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 0);
    for(int i = 0; i < nums.length; i++) {
      if(map.containsKey(preMod[i + 1])){
        if(i - map.get(preMod[i + 1]) >= 1) {
          return true;
        }
      }
      map.putIfAbsent(preMod[i + 1], i + 1);
    }
    return false;
  }
}
```

空间优化：

```python
(a + b) % k = (x * k + r1 + y * k + r2) % k
			= ((x + y) * k + r1 + r2) % k
        	= (r1 + r2) % k
        	= (a % k + b % k) % k
```

```java
class Solution {
  public boolean checkSubarraySum(int[] nums, int k) {
    // key: preSum[i] % k, value : 第一次出现的位置

    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 0);
    int preMod = 0;
    for(int i = 0; i < nums.length; i++) {
      // (a + b) % k = (a % k + b % k) % k，证明见数学篇：同余定理的分配律
      preMod = (preMod + nums[i] % k) % k;
      if(map.containsKey(preMod)){
        if(i - map.get(preMod) >= 1) {
          return true;
        }
      }
      map.putIfAbsent(preMod, i + 1);
    }
    return false;
  }
}
```

时间复杂度O(m)

### [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)
前缀状态：前缀和；value为前缀和出现的次数。

325是求「和等于k」的最长子数组长度，因此前缀和HashMap保存的是键是**前缀和**，值**第一次索引出现的次数**，但这道题是求的「和为k」的子数组的个数，因此HashMap保存的值就是「和为k」出现的次数。

需要注意的是，我们不能直接将和等于k的个数先全部存下来，而是要边遍历边保存，因为索引为i的`preSum[i + 1] - k`只考虑`[0, i]`的区间存在的个数。

```java
class Solution {
  public int subarraySum(int[] nums, int k) {
    // <preSum, totalNumber>
    Map<Integer, Integer> map = new HashMap<>();
    // -1的位置就代表前缀和0，-1的位置表明已经出现了一次，因此0的次数初始化为1
    map.put(0, 1);
    int preSum = 0;
    int res = 0;
    for(int i = 0; i < nums.length; i++) {
      preSum += nums[i];
      res += map.getOrDefault(preSum - k, 0);
      map.put(preSum, map.getOrDefault(preSum, 0) + 1);
    }

    return res;
  }
}
```

时间复杂度：O(N)

### [1248. 统计「优美子数组」](https://leetcode.cn/problems/count-number-of-nice-subarrays/)
HashMap存储的键是**「奇数个数」**，值是出现的次数。

举例：nums = [2, 1,  1,  2,  2,  1] , k = 2

1. 遍历到索引为2的时候，map中存储的键值对为{0:2, 1: 1, 2: 1}，此时奇数个数为2，如果要找到[0,2]之间包含了nums[2]的奇数个数为2的子数组，只需找到奇数个数为2-2=0的索引位置有多少个，答案是2个。
    1. 为什么奇数为0的有两个，因为-1的位置奇数也为0，这样才能把[2, 1, 1]数组包括起来。
2. 遍历到索引为3的时候，map中存储的键值对为{0:2, 1: 1, 2: 1, 3:1}，此时奇数个数为3，如果要找到[0,3]之间包含了nums[3]的奇数个数为2的子数组，只需要找到奇数个数为1的索引位置有多少个，答案是2个。
3. 所以直到[0: 3]的子数组中，共有三个奇数个数为4的子数组。

```java
class Solution {
    /**
* nums = [2, 2, 2, 1, 2, 2, 1, 2, 2, 2]
* preOddNum= [0, 0, 0, 1, 1, 1, 2, 2, 2, 2] k = 2
* */
  public int numberOfSubarrays(int[] nums, int k) {
```

### [974. 和可被 K 整除的子数组](https://leetcode.cn/problems/subarray-sums-divisible-by-k/)
跟523题类似。

由同余定理：(a - b) % k 等价于 a % k == b % k，那么我们只需要将preSum[i] % k 作为key存储下来，当两个位置key相同时，说明该区间的和就是可被k整除的子数组，value存储的是key出现的次数。

需要注意的是这道题中nums[i]可能为负数，那么preSum[i]也可能为负数，比如nums = [-1, 2, 3]，k = 2。其preSum = [-1, 1, 4]，由于子数组[2]必然是答案，按照上面说的，那preSum % k = [1, 1, 0]，但是如果Java代码这样写`(preSum + nums[i]) % k`，那就会有问题，因为Java中，负数取模是倾向于让商更大一点（[https://ceeji.net/blog/mod-in-real/](https://ceeji.net/blog/mod-in-real/)），所以负数的余数还是负数，比如-1%2 = -1，但我们希望的是-1%2的余数是1。

> java中取余：-1 = 0 * 2 + (-1)
>
> 余数倾向于正数：-1 = (-1) * 2 + 1
>

让负数的余数为正数的操作为：-a % k =>  (-a%k + k) % k

即`((preSum + nums[i]) % k + k) % k = [1,1,0]`，就能将子数组[2]给找出来。 

$ (a - b)\%k = (a\%k-b\%k+k)\%k $

```java
class Solution {
    public int subarraysDivByK(int[] nums, int k) {

      Map<Integer, Integer> map = new HashMap<>();
      map.put(0, 1);
      int preMod = 0;
      int cnt = 0;
      int preSum = 0;
      for(int i = 0; i < nums.length; i++) {
        preSum += nums[i];
        preMod = (preSum % k + k) % k;
        // 实际上可以用这一行来替代：preMod = (preMod + nums[i] % k + k) % k;
        // 因为(a + b) % k = (a % k + b % k) % k
        cnt += map.getOrDefault(preMod, 0);
        map.put(preMod, map.getOrDefault(preMod, 0) + 1);
      }
      return cnt;
    }
}
```

### [2588. 统计美丽子数组数目](https://leetcode.cn/problems/count-the-number-of-beautiful-subarrays/)
当subnums = [3, 1, 2]，其二进制位为[011, 001, 010]，一个数减去2^k，其实就是二进制的第k位减1。

题中每两个数**同时**减去2^k，最后所有的数都变为0。这意味着美丽子数组中所有数的第k个二进制位为1的数量必须是偶数个。如果不是偶数个，那每一次同一比特位同时减去1，最后一定不会都为0。

由于$ A \oplus A=0 $，所以每一个二进制位为1的数量为偶数个就等价于这个子数组的所有数异或起来为0，

根据1310题的公式：

$ nums[j] \oplus nums[j+1] \oplus ... \oplus nums[i] = preXor[j] \oplus preXor[i+1]  =0
 $ 

其实就是求区间异或为0，那就等价于找前缀异或相等的索引。

因为答案是求美丽子数组的个数，所以需要使用到key为前缀异或, value出现次数的HashMap

```java
class Solution {
  public long beautifulSubarrays(int[] nums) {
    
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);
    int preXor = 0;
    // xor 
    long count = 0;
    for(int i = 0; i < nums.length; i++) {
      preXor = preXor ^ nums[i];
      count = count + map.getOrDefault(preXor, 0);
      map.put(preXor, map.getOrDefault(preXor,0) + 1);
    }
    return count;
  }
}
```

### [6952.Count of Interesting Subarrays](https://leetcode.cn/problems/count-of-interesting-subarrays/)
`s[r]-s[l]) % m = k`

`(s[r] % m - s[l] % m + m) % m = k`

`(s[r] % m - k + m) % m = s[l] % m`

```java
class Solution {
    public long countInterestingSubarrays(List<Integer> nums, int modulo, int k) {
      //  s[r]-s[l]) % m = k
      // (s[r] % m - s[l] % m + m) % m = k
      // (s[r] % m - k + m) % m = s[l] % m
      int n = nums.size();
      Map<Integer, Integer> map = new HashMap<>();
      map.put(0, 1);
      long cnt = 0;
      int preMod = 0;
      int presum = 0;
      for(int i = 0; i < n; i++) {
        presum += (nums.get(i) % modulo == k ? 1 : 0);
        preMod = presum % modulo;
        cnt += map.getOrDefault((preMod - k + modulo) % modulo, 0);
        map.put(preMod, map.getOrDefault(preMod, 0) + 1);
      }
      
      return cnt;
    }
}
```

### [1314. Matrix Block Sum](https://leetcode.cn/problems/matrix-block-sum/)

```java
class Solution {
  public int[][] matrixBlockSum(int[][] mat, int k) {

    int m = mat.length;
    int n = mat[0].length;
    int[][] ans = new int[m][n];
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        ans[i][j] = sumWithKrange(mat, i, j, k);
      } 
    }

    return ans;

  }
  private int sumWithKrange(int[][] mat, int row, int col, int k) {
    int sum = 0;
    int m = mat.length;
    int n = mat[0].length;
    for(int i = row - k; i <= row + k; i++) {
      for(int j = col - k; j <= col + k; j++) {
        if(i >= 0 && i < m && j >= 0 && j < n) {
          sum = sum + mat[i][j];
        }
      }
    }
    return sum;
  }
}
```

```java
class Solution {
  public int[][] matrixBlockSum(int[][] mat, int k) {
    int m = mat.length;
    int n = mat[0].length;
    int[][] ans = new int[m][n];
    if(k == 0) {
      return ans;
    }

    int[][] preSum = new int[m+1][n+1];
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        preSum[i+1][j+1] = preSum[i][j+1] + preSum[i+1][j] - preSum[i][j] + mat[i][j];
      } 
    }

    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        int rowEnd = i + 1 + k > m ? m : i + 1 + k;
        int colEnd = j + 1 + k > n ? n : j + 1 + k;
        int rowStartMinusOne = i - k < 1 ? 0: i - k;
        int colStartMinusOne = j - k < 1 ? 0 : j - k;

        ans[i][j] = preSum[rowEnd][colEnd] - preSum[rowEnd][colStartMinusOne] 
          - preSum[rowStartMinusOne][colEnd] +  preSum[rowStartMinusOne][colStartMinusOne];
      } 
    }
    return ans;
  }
}
```

```java
class Solution {
  public int[] getMaxMatrix(int[][] matrix) {

    int m = matrix.length;
    int n = matrix[0].length;

    int[] maxIndex = new int[4];
    int maxSum = matrix[0][0];

    for(int rowStart = 0; rowStart < m; rowStart++) {
      int[] dp = new int[n];
      for(int row = rowStart; row < m; row++) {
        for(int j = 0; j < n; j++) {
          dp[j] = dp[j] + matrix[row][j];
        }

        int[] subMax = new int[2];
        int res = maxSubArray(dp, subMax);
        if(maxSum < res) {
          maxSum = res;
          maxIndex[0] = rowStart;
          maxIndex[1] = subMax[0];
          maxIndex[2] = row;
          maxIndex[3] = subMax[1];
        }
      }
    }

    return maxIndex;
  }

  // 53题 一维的最大子矩阵和：动态规划版本
  private static int[] getMaxSubArray(int[] nums) {
    int maxsum = Integer.MIN_VALUE;
    int[] dp = new int[nums.length + 1];
    int[] ans = new int[3];
    int begin = 0;
    for(int i = 0; i < nums.length ; i++ ){
      // dp[i + 1] = Math.min(dp[i] + nums[i], nums[i]) = Math.max(dp[i], 0) + nums[i]
        if(dp[i] > 0) {  
          dp[i + 1] = dp[i] + nums[i];
        } else {              
          dp[i + 1] = nums[i];
          begin = i;     
        }
        if(dp[i + 1] > maxsum){
            maxsum = dp[i + 1];
            ans[0] = maxsum;
            ans[1] = begin;//记录下起始和终止位置
            ans[2] = i;
        }  
    }
    return ans;
  }
  
  // 一维的最大子矩阵和：前缀和版本
  private int[] getMaxSubArray(int[] nums) {
    int[] preSum = new int[nums.length + 1];
    // dp[i] = min(dp[i - 1] + nums[i], nums[i])
    int max = Integer.MIN_VALUE;
    int[] res = new int[3];
    for(int i = 0; i < nums.length; i++) {
      preSum[i + 1] = preSum[i] + nums[i];
    }
    TreeMap<Integer, Integer> treeMap = new TreeMap<>();
    treeMap.put(0, -1);
    for(int i = 0; i < nums.length; i++) {
      int rangeSum = preSum[i + 1] - treeMap.firstKey();
      if (rangeSum > max) {
        max = rangeSum;
        res[0] = max;
        res[1] = treeMap.get(treeMap.firstKey()) + 1;
        res[2] = i;
      }
      treeMap.putIfAbsent(preSum[i + 1], i);
    }
    return res;
  }
}
```

### [437. Path Sum III](https://leetcode.cn/problems/path-sum-iii/)

```java
class Solution {
  public int pathSum(TreeNode root, int targetSum) {
    if(root == null) {
      return 0;
    }
    int ret = rootSum(root, 0, targetSum);
    ret += pathSum(root.left, targetSum);
    ret += pathSum(root.right, targetSum);
    return ret;
  }

  // 以root结点为起点向下满足路径总和为targetSum的路径数目
  private int rootSum(TreeNode root, long sum, long targetSum) {

    if(root == null) {
      return 0;
    }
    int ret = 0;
    // 当前单个结点就满足
    if(sum + root.val == targetSum) {
      ret++;
    }
    ret += rootSum(root.left, sum + root.val, targetSum);
    ret += rootSum(root.right, sum + root.val, targetSum);
    return ret;
  }
}
```

```java
    // preSum: count
    Map<Long, Integer> preSumToCountMap = new HashMap<>();
    preSumToCountMap.put(0L, 1);
    return dfs(root, preSumToCountMap, 0L, targetSum);

  private int dfs(TreeNode root, Map<Long, Integer> map, Long preSum, int targetSum) {
    if(root == null) {
      return 0;

    res += dfs(root.right, map, preSum, targetSum);
```
