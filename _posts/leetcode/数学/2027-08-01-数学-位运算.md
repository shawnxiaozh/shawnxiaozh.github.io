# [LCR 004. 只出现一次的数字 II](https://leetcode.cn/problems/WGki4K/)
```java
class Solution {
  public int singleNumber(int[] nums) {
    int ans = 0;
    /**
            10
            10
            10
            11
            41
         */
    for(int i = 0; i < 32; i++) {
      int cnt = 0;
      for(int x : nums) {
        // (x >> i) & 1 得到x的第i个二进制位
        cnt += x >> i & 1;
      }
      if(cnt % 3 != 0) {
        // 1左移动i位，相当于添加元素i
        ans |= (1 << i);
      }
    }
    return ans;
  }
}
```

# [LCR 005. 最大单词长度乘积](https://leetcode.cn/problems/aseY1I/)
```java
class Solution {
  public int maxProduct(String[] words) {
    int ans = 0;
    for(int i = 0; i < words.length; i++) {
      for(int j = 0; j < i; j++) {
        if(!isContain(words[i], words[j])) {
          ans = Math.max(ans, words[i].length() * words[j].length());
        }
      }
    }
    return ans;
  }
  private boolean isContain(String a, String b) {
    Set<Character> set = new HashSet<>();
    for(int i = 0; i < a.length(); i++) {
      set.add(a.charAt(i));
    }
    for(int i = 0; i < b.length(); i++) {
      if(set.contains(b.charAt(i))){
        return true;
      }
    }
    return false;
  }
}
```

时间复杂度`O(N^3)`

判断两个字符串是否有相同字母

我们可以用一个二进制来表示一个字符串在`a~z`位置上是否存在，如果两个字符串有相同的字母，那么它们&一定不为0。

```java
class Solution {
  public int maxProduct(String[] words) {
    int n = words.length;
    int[] masks = new int[n];
    for(int i = 0; i < n; i++) {
      String word = words[i];
      int t = 0;
      for(int j = 0; j < word.length(); j++) {
        t |= (1 << (word.charAt(j) - 'a'));
      }
      masks[i] = t;
    }
    int ans = 0;
    for(int i = 0; i < words.length; i++) {
      for(int j = 0; j < i; j++) {
        if((masks[i] & masks[j]) == 0) {
          ans = Math.max(ans, words[i].length() * words[j].length());
        }
      }
    }
    return ans;
  }
}
```
