## (b - a) % k = 0  <-> b % k == a % k
同余定理：(b - a) % k  <-> b % k == a % k

证明：

正着推：(b - a) % k -> b % k == a % k

b = x * k + r1, a = y * k + r2

b - a = (x - y) * k + r1 - r2

(b - a) % k = r1 - r2 

当(b - a)%k == 0时， r1 = r2。

有：b % k == a % k

反着推： b % k == a % k -> (b - a) % k 

b = x * k + r1, a = y * k + r2

r1 == r2

b - a = (x - y) * k

(b - a ) % k = 0

## (a+b)%k = ((a%k) + (b%k)) % k
这是取模运算的分配律,我们可以通过取模的定义来证明这个定理：

因为取模运算是将一个数除以另一个数，然后取余数，所以我们可以将 a 和 b 表示为：

`a = x * k + r1`,

`b = y * k + r2`

所以

```python
(a + b) % k = (x * k + r1 + y * k + r2) % k
			= ((x + y) * k + r1 + r2) % k
        	= (r1 + r2) % k
        	= (a % k + b % k) % k
```
