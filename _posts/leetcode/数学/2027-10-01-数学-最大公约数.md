用gcd(a,b)表示a和b的最大公约数

> Greatest Common Divisor
>

## 辗转相除法
辗转相除法也叫做欧几里得算法。

求a和b的最大公约数c，

$ a/b = k...r 
\\
r = a - b*k $

因为d是a、b的一个公约数，所以

$ r/c = a/c-b/c*k \in N $

所以c也是r的一个公约数

c是a、b、a%b三个数的公约数

即

$ gcd(a,b)=gcd(b, a\%b) $

假设a=36, b=24，那么辗转相除下去，就有

| a | b |
| --- | --- |
| 36 | 24 |
| 24 | 36 % 24 = 12 |
| 12 | 24 % 12 = 0 |

于是有：

$ gcd(36, 24)=gcd(24,36\%24=12)=gcd(12, 24\%12=0) $

求gcd(36,24)，就是在求gcd(24,12)

求gcd(24,12)，就是在求gcd(12,0) 

任何数和0的最大公约数都是它本身，所以gcd(36,24)的最大公约数为12。这就是辗转相除法。

其实如果将a、b换个顺序求解，值也是一样的。

如果用代码表示出来，就是

```java
// 递归版本，时间复杂度为O(log Max(a,b))
public int gcdRecursion(int a, int b) {
  if(b == 0) {
    return a;
  }
  if(a == 0) {
    return a;
  }
  return gcdRecursion(b, a % b);
}
// 迭代版本，时间复杂度为
public int gcdIteration(int a, int b) {
  if(b == 0) {
    return a;
  }
  if(a == 0) {
    return a;
  }

  while(b != 0) {
    int mod = a % b;
    a = b;
    b = mod;
  }
  return a;
}
```

但需要注意gcd(0, 0)是没有解的，0和0是没有公约数的，因为0是没有约数的。

### [1979. Find Greatest Common Divisor of Array](https://leetcode.cn/problems/find-greatest-common-divisor-of-array/)
```java
class Solution {
  public int findGCD(int[] nums) {
    Arrays.sort(nums);

    int minimum = nums[0];
    int maximum = nums[nums.length - 1];

    return gcd(maximum, minimum);
  }

  public int gcd(int a, int b) {
    if(b == 0) {
      return a;
    }
    if(a == 0) {
      return a;
    }

    while(b != 0) {
      int mod = a % b;
      a = b;
      b = mod;
    }
    return a;
  }
}
```

### [2427. Number of Common Factors](https://leetcode.cn/problems/number-of-common-factors/)
可以利用最大公约数来减小时间复杂度。

```java
class Solution {
  public int commonFactors(int a, int b) {
    int gcd = gcd(a, b);
    int count = 0;
    for(int i = 1; i <= gcd; i++) {
      if(gcd % i == 0) {
        count++;
      }
    }
    return count;
  }

  public int gcd(int a, int b) {
    if(b == 0) {
      return a;
    }
    if(a == 0) {
      return b;
    }
    return gcd(b, a % b);
  }
}
```
