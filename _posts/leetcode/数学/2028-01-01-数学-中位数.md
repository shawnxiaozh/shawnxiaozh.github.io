定义：对于一个长度为n的数组

$ x_0, x_1, x_2, ..., x_{n-1} $

当数组长度为奇数时，中位数为

$ x_{n/2} $

当数组长度为偶数时，中位数为

$ (x_{n/2} + x_{(n-2)/2}) /2 $

中位数定理：

令$ f(x)=|x_0-x| + |x_1-x|+...+|x_{n-1}-x| $，当x为中位数时，f(x)最小。

### [462. Minimum Moves to Equal Array Elements II](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)
如上，根据中位数的性质，将所有的数都移动到中位数时，所需要的步数是最小的。

当数组长度为奇数时，中位数为$ x_{n/2} $；

当数组长度为偶数时，中位数为$ (x_{n/2} + x_{(n-2)/2}) /2 $，但我们必须保证中位数为整数，所以当数组长度为奇数时，中位数可以在$ x_{n/2}  $和$ x_{(n-2)/2} $中随机选择一个，所以为了不考虑数组长度是奇数还是偶数，中位数即为$ x_{n/2} $。

```java
class Solution {
  public int minMoves2(int[] nums) {
    Arrays.sort(nums);
    int res = 0;
    int len = nums.length;
    // odd -> nums[len/2]
    // even -> nums[len/2] or nums[(len-2)/2]
    int median = nums[len/2];

    for(int i = 0; i < nums.length; i++) {
      res = res + Math.abs(nums[i] - median);
    }
    return res;

  }
}
```
