广度优先遍历/搜索（我们简称BFS）呈现出 「一层一层向外扩张"」的特点，先看到的结点先遍历，后看到的结点后遍历，常常借助队列实现。

![](https://cdn.nlark.com/yuque/0/2023/gif/32473878/1678097021195-cb7e6ff6-9d81-4656-8789-969be47ffd33.gif)

用队列实现时，如果根结点有左右孩子结点，依次将它们加入队列等待下一层作为根结点继续遍历。

比如要返回某个结点和根结点最短的距离，如下的模版：

```java
/**
* Return the length of the shortest path between root and target node.
*/
public class test {

    public int BFS(Node root, Node target) {
        Queue<Node> queue;  // store all nodes which are waiting to be processed
        int step = 0;       // number of steps neeeded from root to current node
        // initialize
        add root to queue;
        // BFS
        while (queue is not empty) {
            step = step + 1;
            // iterate the nodes which are already in the queue
            int size = queue.size();
            for (int i = 0; i < size; ++i) {
                Node cur = the first node in queue;
                remove the first node from queue;
                return step if cur is target;
                for (Node next : the neighbors of cur) {
                    add next to queue;
                }
            }
        }
        return -1;          // there is no path from root to target
    }
}
```

这个就是BFS的基本模版，重在理解，不死记硬背，卡壳的时候可以借助模版梳理思路。

有时候可以不用书写size循环。

要理解BFS，从树开始是最直观的。

## 树的遍历
### [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)
作为入门BFS的第一道题，非常经典，尝试思考将每一层加入到队列，完全不需要背模版。

```java
class Solution {
  public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) {
      return res;
    }
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while(!queue.isEmpty()) {
      int size = queue.size();
      List<Integer> level = new ArrayList<>();
      for(int i = 0; i < size; i++) {
        TreeNode cur = queue.pop();
        level.add(cur.val);
        if(cur.left != null) {
          queue.offer(cur.left);
        } 
        if(cur.right != null) {
          queue.offer(cur.right);
        }
      }
      res.add(level);
    }
    return res;
  }
}
```

## 二维平面上的搜索
### [200. 岛屿数量](https://leetcode.cn/problems/number-of-islands/)
在用BFS的时候，常常会使用一个标记遍历过的点的矩阵 来记录遍历时遍历过的点，防止重复遍历和提高效率，这道题中就是用了一个boolean来记录。

```java
class Solution {
  public int numIslands(char[][] grid) {
    int m = grid.length;
    int n = grid[0].length;
    boolean[][] visited = new boolean[m][n];
    int count = 0;
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(grid[i][j] == '1' && !visited[i][j]) {
          bfs(grid, i, j, visited);
          count++;
        }
      }
    }
    return count;
  }
  private void bfs(char[][] grid, int i, int j, boolean[][] visited) {
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(new int[]{i, j});
    visited[i][j] = true;
    int m = grid.length;
    int n = grid[0].length;
    int[][] directions = {{1,0}, {-1, 0}, {0, 1}, {0, -1}};
    while(!queue.isEmpty()) {
      int size = queue.size();
      for(int k = 0; k < size; k++) {
        int[] point = queue.poll();
        int x = point[0];
        int y = point[1];
        for(int[] direction: directions) {
          int nextX = x + direction[0];
          int nextY = y + direction[1];
          if(!isBorderOrWater(grid, nextX, nextY, m, n) && !visited[nextX][nextY]){
            queue.offer(new int[] {nextX, nextY});
            visited[nextX][nextY] = true;
          }
        }

      }
    }
  }

  private boolean isBorderOrWater(char[][] grid, int x, int y, int m, int n) { 
    return x < 0 || x >= m || y < 0 || y >= n || grid[x][y] == '0';
  }
}
```

```java
class Solution {
  private static int[][] directions = {{1, 0}, {-1,0}, {0, 1}, {0, -1}};

    boolean[][] visited = new boolean[m][n];  
    return bfs(0, 0, m, n, k, visited);

  }

    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(new int[]{i, j});
    visited[i][j] = true;
    int res = 1;
    while(!queue.isEmpty()) {
      int size = queue.size();
      for(int s = 0; s < size; s++) {
        int[] cur = queue.poll();
        for(int[] direction : directions) {

          int newY = cur[1] + direction[1];
          if(inGrid(newX, newY, m, n, k) && !visited[newX][newY]) {
            queue.offer(new int[]{newX, newY});
            visited[newX][newY] = true;
            res++;
          }
        }

      }
    }
    return res;

  }

    return i >= 0 && i < m && j >= 0 && j < n && (sumNum(i) + sumNum(j)) <= k;
  }

    int res = 0;
    while(i != 0) {
      res = i % 10 + res;
      i = i / 10;
    }
    return res;
  }
```

### [1254. 统计封闭岛屿的数目](https://leetcode.cn/problems/number-of-closed-islands/)
广度优先搜索

```java
class Solution {
  public int closedIsland(int[][] grid) {

    int m = grid.length;
    int n = grid[0].length;

    boolean[][] visited = new boolean[m][n];
    int cnt = 0;
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(!visited[i][j] && grid[i][j] == 0) {
          cnt += bfs(grid, i, j, visited);

        }
      }
    }

    return cnt;
  }
  private int bfs(int[][] grid, int x, int y, boolean[][] visited) {
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(new int[]{x, y});
    visited[x][y] = true;

    int m = grid.length;
    int n = grid[0].length;
    // 标记是否是封闭岛屿
    boolean enclose = true;
    if(isEdge(m, n, x, y)) {
      enclose = false;
    }

    int[][] directions = new int[][]{{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    while(!queue.isEmpty()) {
      int[] xy = queue.poll();

      for(int[] direction : directions) {
        int nextX = xy[0] + direction[0];
        int nextY = xy[1] + direction[1];
        if(!offGrid(m, n, nextX, nextY) && grid[nextX][nextY] == 0 && !visited[nextX][nextY]) {
          queue.offer(new int[]{nextX, nextY});
          visited[nextX][nextY] = true;
          if(isEdge(m, n, nextX, nextY)) {
            enclose = false;
          }
        }
      }
    }


    return enclose ? 1 : 0;
  }

  private boolean offGrid(int m, int n, int x, int y) {
    return x < 0 || x >= m || y < 0 || y >= n;
  }

  private boolean isEdge(int m, int n, int x, int y) {
    return x == 0 || x == m - 1 || y == 0 || y == n - 1;
  }
}
```

### [490. 迷宫](https://leetcode.cn/problems/the-maze/)
```java
class Solution {

  private int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
  public boolean hasPath(int[][] maze, int[] start, int[] destination) {
    return bfs(maze, start, destination);
  }

  private boolean bfs(int[][] maze, int[] start, int[] destination) {
    boolean[][] visited = new boolean[maze.length][maze[0].length];
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(start);
    visited[start[0]][start[1]] = true;
    while(!queue.isEmpty()) {
      int size = queue.size();
      for(int i = 0; i < size; i++) {
        int[] node = queue.poll();

        for(int j = 0; j < 4; j++) {
          int currentX = node[0];
          int currentY = node[1]; 
          int[] next = new int[2];
          int nextX= currentX + directions[j][0];
          int nextY = currentY + directions[j][1];
          while(!isEgde(nextX, nextY, maze) && !isWall(nextX, nextY, maze)) {
            nextX += directions[j][0];
            nextY += directions[j][1];
          }
          nextX -= directions[j][0];
          nextY -= directions[j][1];
          if(currentX == nextX && currentY == nextY) {
            continue;
          }

          if(isHole(nextX, nextY, destination)) {
            return true;
          }
          if(visited[nextX][nextY]) {
            continue;
          }
          visited[nextX][nextY] = true;
          next[0] = nextX;
          next[1] = nextY;
          queue.offer(next);
        }
      }
    }
    return false;
  }

  private boolean isEgde(int x, int y, int[][] maze) {
    int m = maze.length;
    int n = maze[0].length;
    return x  > m - 1 || x < 0 || y > n - 1 || y < 0;
  }

  private boolean isWall(int x, int y, int[][] maze) {
    return (maze[x][y] == 1);
  }

  private boolean isHole(int x, int y, int[] destination) {
    return x == destination[0] && y == destination[1];
  }
}
```

+ 空间复杂度：O(MN)

### [505. 迷宫 II](https://leetcode.cn/problems/the-maze-ii/)
```java
class Solution {

  private int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
  public int shortestDistance(int[][] maze, int[] start, int[] destination) {
    return bfs(maze, start, destination);
  }
  private void dfs(int[][] maze, int[] destination, int currentX, int currentY, int[][] distance) {
    if(currentX == destination[0] && currentY == destination[1]) {
      return ;
    }
    for(int[] direction : directions) {
      int nextX = currentX + direction[0];
      int nextY = currentY + direction[1];
      int count = 0;

      while(!isEgde(nextX, nextY, maze) && !isWall(nextX, nextY, maze)) {
        nextX = nextX + direction[0];
        nextY = nextY + direction[1];
        count++;
      }

      nextX = nextX - direction[0];
      nextY = nextY - direction[1];

      if(distance[currentX][currentY] + count < distance[nextX][nextY]) {
        distance[nextX][nextY] = distance[currentX][currentY] + count;
        dfs(maze, destination, nextX, nextY, distance);
      }
    }      
  }
  private int bfs(int[][] maze, int[] start, int[] destination) {
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(start);

    int[][] distances = new int[maze.length][maze[0].length];
    for(int[] dis : distances) {
      Arrays.fill(dis, Integer.MAX_VALUE);
    }
    distances[start[0]][start[1]] = 0;
    while(!queue.isEmpty()) {
      int size = queue.size();
      for(int i = 0; i < size; i++) {
        int[] node = queue.poll();

        for(int[] direction : directions) {
          int currentX = node[0];
          int currentY = node[1]; 
          int nextX= currentX + direction[0];
          int nextY = currentY + direction[1];
          int count = 0;
          while(!isEdge(nextX, nextY, maze) && !isWall(nextX, nextY, maze)) {
            nextX += direction[0];
            nextY += direction[1];
            count++;
          }
          nextX -= direction[0];
          nextY -= direction[1];
          if(distances[currentX][currentY] + count < distances[nextX][nextY] ) {
            distances[nextX][nextY] = distances[currentX][currentY] + count;
            int[] next = new int[2];
            next[0] = nextX;
            next[1] = nextY;
            queue.offer(next);
          }

        }
      }
    }
    return distances[destination[0]][destination[1]] == Integer.MAX_VALUE ?  -1 : distances[destination[0]][destination[1]];
  }

  private boolean isEdge(int x, int y, int[][] maze) {
    int m = maze.length;
    int n = maze[0].length;
    if (x  > m - 1 || x < 0 || y > n - 1 || y < 0) {
      return true;
    }
    return false; 
  }

  private boolean isWall(int x, int y, int[][] maze) {
    return (maze[x][y] == 1);
  }
  private boolean isHole(int x, int y, int[] destination) {
    return x == destination[0] && y == destination[1];
  }
}
```

### [499. 迷宫 III](https://leetcode.cn/problems/the-maze-iii/)

```java
class Solution {

  private int[][] directions = {{0,-1},{-1,0},{0,1},{1,0}};
  private char[] way = {'l', 'u', 'r', 'd'};

  public String findShortestWay(int[][] maze, int[] ball, int[] hole) {
    int m = maze.length;
    int n = maze[0].length;

    // 记录了每一个点的最短距离
    Map<Integer, String> minPathMap = new HashMap<>();
    bfs(maze, ball, hole, minPathMap);
    String res = minPathMap.getOrDefault(hole[0] * n + hole[1], "impossible");
    return res.isEmpty() ? "impossible" : res;
  }

  private int bfs(int[][] maze, int[] start, int[] destination, Map<Integer, String> minPathMap) {
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(start);

    int n = maze[0].length;
    // distances记录的每一个转折点到起点的距离
    int[][] distances = new int[maze.length][maze[0].length];
    for(int[] dis : distances) {
      Arrays.fill(dis, Integer.MAX_VALUE);
    }
    distances[start[0]][start[1]] = 0;
    while(!queue.isEmpty()) {
      int size = queue.size();
      for(int i = 0; i < size; i++) {
        int[] node = queue.poll();

        for(int j = 0; j < 4; j++) {
          int[] direction = directions[j];
          int currentX = node[0];
          int currentY = node[1]; 
          String currentPath = minPathMap.getOrDefault(currentX * n + currentY, "");
          int nextX= currentX + direction[0];
          int nextY = currentY + direction[1];
          int count = 0;


          while(!isEdge(nextX, nextY, maze) && !isWall(nextX, nextY, maze) && !isHole(nextX, nextY, destination)) {
            nextX += direction[0];
            nextY += direction[1];
            count++;
          }
          if(!isHole(nextX, nextY, destination)) {
            nextX -= direction[0];
            nextY -= direction[1];
          }
          // 记录行走的方向
          String nextPath = currentPath + way[j];

          if(distances[currentX][currentY] + count < distances[nextX][nextY]) {
            distances[nextX][nextY] = distances[currentX][currentY] + count;
            int[] next = new int[2];
            next[0] = nextX;
            next[1] = nextY;
            minPathMap.put(nextX * n + nextY, nextPath);

            queue.offer(next);
          } else if(distances[currentX][currentY] + count ==  distances[nextX][nextY] && nextPath.compareTo(minPathMap.getOrDefault(nextX * n + nextY, "")) < 0) {
            minPathMap.put(nextX * n + nextY, nextPath);
            int[] next = new int[2];
            next[0] = nextX;
            next[1] = nextY;
            queue.offer(next);
          }

        }
      }
    }
    return distances[destination[0]][destination[1]] == Integer.MAX_VALUE ?  -1 : distances[destination[0]][destination[1]];
  }

  private boolean isEdge(int x, int y, int[][] maze) {
    return x < 0 || x > maze.length - 1 || y < 0 || y > maze[0].length - 1;
  }

  private boolean isWall(int x, int y, int[][] maze) {
    return maze[x][y] == 1;
  }

  private boolean isHole(int x, int y, int[] hole) {
    return (x == hole[0] && y == hole[1]);
  }
```

### [752. 打开转盘锁](https://leetcode.cn/problems/open-the-lock/)
四位数abcd每个位上有两种选择，(a-1)bcd, a(b-1)cd, ab(c-1)d, abc(d-1),(a+1)bcd, a(b+1)cd, ab(c+1)d, abc(d+1)，共8种选择；既然是找最短的，那可以用bfs遍历，遇到deadends时就停止那一路的分叉，如果找到target，就停止，当前层数就是答案。

```java

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Objects;
import java.util.Set;

//leetcode submit region begin(Prohibit modification and deletion)
class Solution {
  public int openLock(String[] deadends, String target) {
    // 如果已经到达目的地
    if(Objects.equals(target, "0000")) {
      return 0;
    }
    // 转成Set，运算快
    Set<String> deadendsSets = new HashSet<>();
    for (String deadend : deadends) {
      deadendsSets.add(deadend);
    }
    // 如果deadends包含终点，意味着不可到达
    if(deadendsContains(deadendsSets, "0000")) {
      return -1;
    }
    return bfs(deadendsSets, target);

  }
  private int bfs(Set<String> deadendsSets, String target) {
    Deque<String> queue = new ArrayDeque<>();
    Set<String> visited = new HashSet<>();

    queue.offer("0000");
    visited.add("0000");

    int step = 0;

    while(!queue.isEmpty()) {
      int size = queue.size();
      step++;
      for(int k = 0; k < size; k++) {
        String cur = queue.pop();
        for(int i = 0; i < 4; i++) {
          for(int direction = 0; direction < 2; direction++) {
            String newString = changeString(cur, i, direction);
            if (Objects.equals(target, newString)) {
              return step;
            }
            if(!deadendsContains(deadendsSets, newString) && !visited.contains(newString)) {
              queue.offer(newString);
              visited.add(newString);
            }
          }

        }
      }
    }
    return -1;
  }
  // i 位置
  // direction 0 代表向上， 1代表向下
  private String changeString(String str, int i, int direction) {
    StringBuilder stringbuilder = new StringBuilder();
    for (int j = 0; j < str.length(); j++) {
      if (i == j) {
        char nextchar = nextChar(str.charAt(j), direction);
        stringbuilder.append(nextchar);
      } else {
        stringbuilder.append(str.charAt(j));
      }

    }
    return stringbuilder.toString();
  }

  private char nextChar(char c, int direction) {
    int nextCharInt = (int) (c - 48);
    if (direction == 0) {
      if (nextCharInt == 9) {
        nextCharInt = 0;
      } else {
        nextCharInt = nextCharInt + 1;
      }
    } else {
      if (nextCharInt == 0) {
        nextCharInt = 9;
      } else {
        nextCharInt = nextCharInt - 1;
      }
    }
    return  (char) (nextCharInt + 48);
  }
  private boolean deadendsContains(Set<String> deadendsSets, String newString) {
    return deadendsSets.contains(newString);
  }
}
```

### 总结
其实BFS的模板是非常好记的，每次写BFS的题只要有思路都是非常流畅、一气呵成的。只要能够理解齐头并进的BFS，基本上都是能写出来BFS的。其中，可以总结一下BFS标准的一个流程：

1. 创建队列、visited 数组；
2. 把初始化的结点加入队列，标记初始化结点已经访问；
3. 暂存当前队列中的结点总数 size；
4. 将队列中的结点从队首出队 size 次，每一次出队的时候，把结点的后继结点都加入队尾，注意：加队尾的时候马上标记为已经访问。

## 多源BFS
上面我们讲到的BFS有一个特点，就是每次入队的都是一个点，然后在这个点上进行扩散。下面我们将尝试多个点一起扩散的BFS。

### [994. 腐烂的橘子](https://leetcode.cn/problems/rotting-oranges/)
腐烂的橘子就是多源点的BFS最好的入门例子，腐烂的橘子就是源点，齐头并进的BFS就是感染在感染临近的橘子。

```java
class Solution {

  public int orangesRotting(int[][] grid) {
    int m = grid.length;
    int n = grid[0].length;

    Deque<int[]> queue = new ArrayDeque<>();
    boolean[][] visited = new boolean[m][n];
    
    int freshCnt = 0;
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(grid[i][j] == 2) {
          queue.offer(new int[]{i, j});
          visited[i][j] = true;
        }
      }
    }
    int res =  bfs(grid, queue, visited);
    return isAllRot(grid) ? res : -1;
  }
  private int bfs(int[][] grid, Deque<int[]> queue, boolean[][] visited) {
    // 最小经过多少分钟没有新鲜橘子
    if(queue.isEmpty()) {
      return 0;
    }
    int m = grid.length;
    int n = grid[0].length;
    int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int step = -1;
    while(!queue.isEmpty()) {
      int size = queue.size();
      step++;
      for(int i = 0; i < size; i++) {
        int[] cur = queue.poll();
        for(int[] direction : directions) {
          int newX = cur[0] + direction[0];
          int newY = cur[1] + direction[1];
          if (inGrid(m, n, newX, newY) && grid[newX][newY] == 1 && !visited[newX][newY]) {
            queue.offer(new int[]{newX, newY});
            visited[newX][newY] = true;
            grid[newX][newY] = 2;
          }

        }
      }
    }
    return step;
  }
  private boolean inGrid(int m , int n, int i, int j) {
    return i >= 0 && i < m && j >= 0 && j < n;
  }
  private boolean isAllRot(int[][] grid) {
    int m = grid.length;
    int n = grid[0].length; 
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(grid[i][j] == 1) {
          return false;
        }
      }
    }
    return true;
  }
}
```

### [542. 01 矩阵](https://leetcode.cn/problems/01-matrix/)
这道题如果用单源的BFS，也是能做出来的，不过对大尺寸、只有一个0或一个1的矩阵，它会很低效、最后超时。

所以必须要使用多源的BFS，所有的0就是源点，然后多点一起齐头并进，得到的自然就是距离0的最短距离，这个思路需要仔细品味消化，理解后会对BFS的理解更深。

```java
class Solution {
  public int[][] updateMatrix(int[][] mat) {
    return bfs(mat);
  }
  private int[][] bfs(int[][] mat) {
    int m = mat.length;
    int n = mat[0].length;
    Deque<int[]> queue = new ArrayDeque<>();
    boolean[][] visited = new boolean[m][n];
    int[][] result = new int[m][n];
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(mat[i][j] == 0) {
          queue.offer(new int[]{i, j});
          visited[i][j] = true;
          result[i][j] = 0;
        }
      }
    }

    int step = 0;
    int[][] directions = new int[][]{{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    while(!queue.isEmpty()) {

      int size = queue.size();
      step++;
      for(int i = 0; i < size; i++) {
        int[] xy = queue.poll();
        for(int[] direction : directions) {
          int nextX = xy[0] + direction[0];
          int nextY = xy[1] + direction[1];
          if(!offGrid(m, n, nextX, nextY) && mat[nextX][nextY] == 1 && !visited[nextX][nextY]) {
            result[nextX][nextY] = step;
            queue.offer(new int[]{nextX, nextY});
            visited[nextX][nextY] = true;
          }
        }
      }
    }


    return result;
  }
  private boolean offGrid(int m, int n, int x, int y) {
    return x < 0 || x >= m || y < 0 || y >= n;
  }
}
```

```java
class Solution {

  public void wallsAndGates(int[][] rooms) {

    bfs(rooms);

  }
  private void bfs(int[][] rooms) {
    int m = rooms.length;
    int n = rooms[0].length;
    Deque<int[]> queue = new ArrayDeque<>();
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(rooms[i][j] == 0){
          queue.offer(new int[]{i, j});
        } 
      }
    }

    int[][] directions = new int[][]{{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int step = 0; 
    while(!queue.isEmpty()) {
      int size = queue.size();
      step++;
      for(int i = 0; i < size; i++) {
        int[] point = queue.pop();
        for(int[] direction : directions) {
          int nextX = point[0] + direction[0];
          int nextY = point[1] + direction[1];
          if(!isBorder(rooms, nextX, nextY) && !isWall(rooms, nextX, nextY)) {
            if(rooms[nextX][nextY] > step) {
              rooms[nextX][nextY] = step;
              queue.offer(new int[]{nextX, nextY});
              // System.out.println(nextX + " " + nextY + " " + step);
            }
          }
        } 
      }
    }
  }
  private boolean isBorder(int[][] rooms, int x, int y) {
    return x < 0 || x >= rooms.length || y < 0 || y >= rooms[0].length;
  }
  private boolean isWall(int[][] rooms, int x, int y) {
    return rooms[x][y] == -1;
  }
}
```

### [279. 完全平方数](https://leetcode.cn/problems/perfect-squares/)
预先找到可以做减法的完全平方数，然后用bfs一层一层遍历下面这棵树，最先遇到0就是需要最少的平方数，遇到负数则说明不能满足。

<!-- 这是一个文本绘图，源码为：graph TD 
	 A(12) --> |-9| B(3);
	 A(12) --> |-4| C(8);
	 A(12) --> |-1| D(11);
	 B --> |-1| E(2);
	 C --> |-4| F(4);
	 C --> |-1| G(7); -->
![](https://cdn.nlark.com/yuque/__mermaid_v3/176b352336e4b30d927d5449672ab905.svg)

如果不注意遍历平方数的顺序，从最小1开始遍历就会超时，优化方案是把最大的平方数放到前面去遍历。

```java
class Solution {
  public int numSquares(int n) {

    return bfs(n);

  }
  private int bfs(int n) {
    Deque<Integer> queue = new ArrayDeque<>();
    queue.add(n);
    List<Integer> squareNums = new ArrayList<>();
    for(int i = 1; i <= n; i++) {
      squareNums.add(i*i);
    }
    Set<Integer> existInteger = new HashSet<>();

    int step = 0;
    while(!queue.isEmpty()) {
      int size = queue.size();
      step++;
      for(int i = 0; i < size; i++) {
        int integer = queue.pop();
        if(existInteger.contains(integer)) {
          continue;
        }
        // 小技巧，先从最大值开始算，比从最小值算更容易找到答案
        for(int j = squareNums.size() - 1; j >= 0; j--) {
          int tmp = integer - squareNums.get(j);
          if(tmp > 0) {
            queue.offer(tmp);
          } else if(tmp == 0) {
            return step;
          } else {
            existInteger.add(integer);
          }
        }
      }
    }
    return step;
  }
}
```

时间复杂度：O(n^2)
