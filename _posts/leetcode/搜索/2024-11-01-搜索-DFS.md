数据结构与算法-深度优先遍历

## 简介
深度优先遍历比较形象的理解就是：一条路走到底，不到南墙不回头。

深度优先遍历是选择了一条路后，就会一直往前走，直到无路可走。

无路可走有两种情况：

1. 遇到了墙
2. 遇到了曾经走过的路

在无路可走的时候，沿着原路返回，直到回到了还有未走过路的路口，继续尝试没有走过的路。

# 二维平面的搜索
## [130. 被围绕的区域](https://leetcode.cn/problems/surrounded-regions/)
这道题不难，但突破点很难一下想到。

从边界开始找O，然后做标记，搭上标记了的就是没有被包围的O。

这道题的精髓就一句话：**正着想很难，反着想很简单。**

**为什么正着想难**

如果你站在某个 O 上问「我被包围了吗？」，是没法只看四周就回答的——得看它所在的整块 O
有没有任何一个格子能通到外面。判断一个连通块要遍历，遍历完还得回头把整块改掉，很麻烦。

**反过来想**

换个问法：**哪些 O 是「安全」的（不该被改）？**

答案很干脆：**能走到边界的 O**。因为一个 O 只要能顺着上下左右一路走到棋盘边上，说明它
这块区域是「漏气」的，没被围住。而边界上的 O 本身，天然就是安全的。

于是：从边界上的每个 O 出发做 DFS，凡是能走到的 O 全打上标记，剩下没被标记的 O，就是被
围住的。

一个通俗的比喻：**想象棋盘外面是一片水，X 是墙，O 是空地，让水从四周往里灌**，能被淹到
的空地就是通外界的（保留），淹不到的就是封闭的洼地（填成 X）。

> **In short:** asking "is this `O` surrounded?" is hard — you'd have to walk its whole
> blob and check if any part touches the edge. Ask the opposite instead: an `O` is *safe*
> if it can reach the border. So flood in from the border `O`s with DFS, mark everything
> the flood reaches, and whatever stays dry is surrounded.

```java
class Solution {
  private int[][] directions = new int[][]{{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
  public void solve(char[][] board) {
    int m = board.length;
    int n = board[0].length;
    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(isEdge(i, j, m, n) && board[i][j] == 'O') {
          board[i][j] = '#';
          dfs(board, i, j, m, n);
        }
      }
    }

    for(int i = 0; i < m; i++) {
      for(int j = 0; j < n; j++) {
        if(board[i][j] == '#') {
          board[i][j] = 'O';
        } else if(board[i][j] == 'O') {
          board[i][j] = 'X';
        }
      }
    }
  } 

  private void dfs(char[][] board, int x, int y, int m, int n) {
    for(int[] direction : directions) {
      int newX = x + direction[0];
      int newY = y + direction[1];
      if(!invalid(newX, newY, m, n) && board[newX][newY] == 'O') {
        board[newX][newY] = '#';
        dfs(board, newX, newY, m, n);
      }    
    } 
  }

  private boolean isEdge(int x, int y, int m, int n) {
    return x == 0 || x == m - 1 || y == 0 || y == n - 1;
  }

  private boolean invalid(int x, int y, int m, int n) {
    return x < 0 || x >= m || y < 0 || y >= n;
  }
}
```

## [129. 求根节点到叶节点数字之和](https://leetcode.cn/problems/sum-root-to-leaf-numbers/)
```java
class Solution {
  public int sumNumbers(TreeNode root) {
    if(root == null) {
      return 0;
    }
    return dfs(root, 0);      
  }

  // 叶子结点返回root-to-leaf number；空结点返回0
  private int dfs(TreeNode node, int preRootToLeafNumber){
    if(node == null) {
      return 0;
    }

    int newVal = preRootToLeafNumber * 10 + node.val;
    if(node.left == null && node.right == null) {
      return newVal;
    }

    return dfs(node.left, newVal) + dfs(node.right, newVal);
  }
}
```

## [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

分类讨论：

1. 根结点是空节点时，LCA也为空结点：
2. 根结点是p或q时，因为必然包含p或q，所以另一个p或q一定在左子树或者右子树中，故LCA也必然就是当前的根结点
3. 根结点不是p或q时，p或q有三种情况：
    1. p和q分别在右子树和左子树：LCA还是根结点
    2. p和q都在左子树：返回最先遇到的p或q
    3. p和q都在右子树：返回最先遇到的p或q

```java
class Solution {
  public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if(null == root || root == p || root == q) {
      return root;
    }

    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if(null != left && null != right) {
      return root;
    }
    return null != left ? left : right;
  }
}
```

### 递归解法
定义子问题：左右子树分别包括p、q

有两种可能使得访问到的某个结点x是p、q的公共祖先。

第一种可能：当该结点的左子树包含p或q，且右子树包含p或q，该结点必然是p和q的公共祖先

第二种可能：该结点本身就是p或q，其右子树或者左子树包含另外一个q或p

这两种可能即:

$ (f_{lson} \&\& f_{r_son}) ||((x == p || x==q) \&\&(f_{lson} || f_{rson})) $

包含p、q即：

$ f_{lson} ||f_{rson}||x==p||x==q $

时间复杂度O(N)，空间复杂度O(N)

```java
class Solution {
  private TreeNode res = null;
  public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    dfs(root, p, q);
    return res;
  }

  // 如果root包含p或者q，就返回true
  private boolean dfs(TreeNode root, TreeNode p, TreeNode q) {
    if(root == null) {
      return false;
    }
    boolean flson = dfs(root.left, p, q);
    boolean frson = dfs(root.right, p, q);
    if(flson && frson) {
      res = root;
    }
    // root 满足最近公共祖先
    if((root == p  || root == q) && (flson || frson)) {
      // 最后找到的一定是最近的
      res = root;
    }
    return flson || frson || root == p || root == q;
  }
}
```

### 存储父结点。
用哈希表存储所有的结点的父结点。

先向上找出p的所有的祖先结点记录下来，然后再向上找q的祖先结点，遇到的第一个即是最近公共祖先

```java
/**
* Definition for a binary tree node.
* public class TreeNode {
*     int val;
*     TreeNode left;
*     TreeNode right;
*     TreeNode(int x) { val = x; }
* }
*/
class Solution {
  Map<TreeNode, TreeNode> childToAncestorMap = new HashMap<>();

  public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if(root == null) {
      return null;
    }
    dfs(root);

    Set<TreeNode> container = new HashSet<>();
    TreeNode pA = p;
    while(pA != null) {
      container.add(pA);
      pA = childToAncestorMap.get(pA);
    }

    TreeNode pB = q;
    while(pB != null) {
      if(container.contains(pB)) {
        return pB;
        break;
      }
      pB = childToAncestorMap.get(pB);
    }
    return null;
  }

  private void dfs(TreeNode root) {
    if(root.left != null) {
      childToAncestorMap.put(root.left, root);
      dfs(root.left);
    }
    if(root.right != null) {
      childToAncestorMap.put(root.right, root);
      dfs(root.right);
    }
  }
}
```

时间复杂度O(N)

空间复杂度O(N)，递归存储O(N)，哈希表需要的是O(N)

```java
class Solution {
  public TreeNode buildTree(int[] preorder, int[] inorder) {
    int n = preorder.length;
    Map<Integer, Integer> map = new HashMap<>(n);
    for(int i = 0; i < n; i++) {
      map.put(inorder[i], i);
    }
    return dfs(preorder, 0, n, inorder, 0, n, map);
  }

  // [left, right)
  private TreeNode dfs(int[] preorder, int preL, int preR, int[] inorder, int inL, int inR, Map<Integer, Integer> map) {
    if(preL == preR) {
      return null;
    }
    // 左子树的大小
    int leftSize = map.get(preorder[preL]) - inL;
    TreeNode left = dfs(preorder, preL + 1, preL + 1 + leftSize, inorder, inL, inL + leftSize, map);
    TreeNode right = dfs(preorder, preL + 1 + leftSize, preR, inorder, inL + leftSize + 1, inR, map);
    return new TreeNode(preorder[preL], left, right);
  }
}
```

### [106. Construct Binary Tree from Inorder and Postorder Traversal](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/)
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
  public TreeNode buildTree(int[] inorder, int[] postorder) {
    int n = inorder.length;
    Map<Integer, Integer> map = new HashMap<>(n);
    for(int i = 0; i < n; i++) {
      map.put(inorder[i], i);
    }
    return dfs(inorder, 0, n, postorder, 0, n, map);

  }
  // [left, right)
  private TreeNode dfs(int[] inorder, int inL, int inR, int[] postorder, int postL, int postR, Map<Integer, Integer> map) {
    if(inL == inR) {
      return null;
    }

    int leftSize = map.get(postorder[postR - 1]) - inL;
    TreeNode left = dfs(inorder, inL, inL + leftSize, postorder, postL, postL + leftSize, map);
    TreeNode right = dfs(inorder, inL + leftSize + 1, inR, postorder, postL + leftSize, postR - 1, map);
    return new TreeNode(postorder[postR - 1] ,left, right);
  }
}
```

对于任意一颗树而言，而中序遍历的形式总是

[ [左子树的中序遍历结果], 根节点, [右子树的中序遍历结果] ]

后序的形式总是：

[ [左子树的后序遍历结果], [右子树的后序遍历结果]，根节点 ]即最后一个结点总是根结点。

思路跟105一样，只是根结点的位置不同。

```java
class Solution {
  public TreeNode buildTree(int[] inorder, int[] postorder) {
    int n = postorder.length;
    return dfs(inorder, postorder, 0, n-1, 0, n - 1);

  }
  // 中序遍历：[[左子树的中序遍历结果], 根节点, [右子树的中序遍历结果]]
  // 后序遍历：[[左子树的后序遍历结果], [右子树的后序遍历结果]，根节点]
  // postorder: [9, 15, 7, 20, 3] [postLeft, postRight, ]
  // postorder : [左子树区间左边界,                     左子树区间右边界 ; 右子树区间左边界                       右子树区间右边界;      root]
  //             [postLeft, postRight - (inRight - inOrderRoot) -1 ; postRight - (inRight - inOrderRoot), postRight - 1; postRight]
  // inorder:    [左子树区间;    root;      右子树区间]
  //             [inLeft, inorderRoot - 1; inorderRoot; inorderRoot + 1, inRight]
  // postRight - x = (inRight - inOrderRoot) 
  // x = postRight - (inRight - inOrderRoot);
  private TreeNode dfs(int[] inorder, int[] postorder, int inLeft, int inRight, int postLeft, int postRight) {
    if(postLeft > postRight) {
      return null;
    }
    TreeNode root = new TreeNode(postorder[postRight]);
    int inorderRoot = inLeft;
    while(inorder[inorderRoot] != postorder[postRight]) {
      inorderRoot++;
    }
    // int leftSubtreeLen = inorderRoot - inLeft;
    root.left = dfs(inorder, postorder, inLeft, inorderRoot - 1, postLeft, postRight + inorderRoot - inRight - 1);
    root.right = dfs(inorder, postorder, inorderRoot+1, inRight, postRight + inorderRoot - inRight, postRight - 1);
    return root;
  }
}
```

### [889. Construct Binary Tree from Preorder and Postorder Traversal](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-postorder-traversal/)
preorder:  [根结点,                    [左子树的中序遍历],     [右子树的中序遍历]]

postorder: [[左子树的后序遍历],  [右子树的后序遍历],                       根结点]

前序遍历子树的根结点在最左侧，后序遍历子树的根结点在最右侧。所以无法直接根据根结点确定左子树和右子树在数组中的长度。

但是前序遍历中，左子树的根结点就是左子树的左边界perLeft+1，对应的在后序遍历中，就是左子树的最右边界index。

因此index == preLeft + 1，我们找到了index，就可以推出左子树和右子树的长度。

如下：

preorder:  [preLeft,               [preLeft + 1, preLeft + 1 + index - postLeft], [preLeft + 2 + index - postLeft, preRight]]

postorder: [[postLeft, index],  [index + 1,                           postRight - 1],                                               postRight]

```java
class Solution {

  // preorder:  [根结点,           [左子树的中序遍历], [右子树的中序遍历]]
  // postorder: [[左子树的后序遍历], [右子树的后序遍历],           根结点]

  // preorder:  [preLeft,          [preLeft + 1, preLeft + 1 + index - postLeft], [preLeft + 2 + index - postLeft, preRight]]
  // postorder: [[postLeft, index],[index + 1,                    postRight - 1],                                  postRight]

  public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
    return dfs(preorder, 0, preorder.length - 1, postorder, 0, postorder.length - 1);
  }
  // preorder:  [1,2,4,5,3,6,7]
  // postorder: [4,5,2,6,7,3,1]
  public TreeNode dfs(int[] preorder, int preLeft, int preRight, int[] postorder, int postLeft, int postRight) {
    // System.out.print("preorder: "+ preLeft + " " + preRight + "; postorder: " + postLeft + " " + postRight);
    // System.out.println();
    if(preLeft > preRight || postLeft > postRight) {
      return null;
    }
    TreeNode root = new TreeNode(preorder[preLeft]);
    // 这里有点差别，需要细品
    if(preLeft == preRight) {
      return root;
    }
    // 前序遍历中，左子树的根结点是preLeft+1
    int index = postLeft;
    while(postorder[index] != preorder[preLeft + 1]) {
      index++;
    }
    // index就是后序遍历中等于左子树根结点的位置
    // 找到后序遍历中等于前序遍历左子树根结点的位置
    root.left  = dfs(preorder, preLeft + 1,                    preLeft + 1 + index - postLeft, postorder,  postLeft,           index);
    root.right = dfs(preorder, preLeft + 2 + index - postLeft,                       preRight, postorder, index + 1,   postRight - 1);

    return root;
  }
}
```

## [543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)
二叉树的直径定义为树中任意两个结点之间的最长路径，解决这个问题的核心是要拆解问题。

求二叉树的直径问题可以转化为：

寻找二叉树中 所有结点中（以左儿子结点在左子树中为终点的最大边数$ f_{lson}{node} $+ 以右儿子结点在右子树中为终点的最大边数$ f_{rson}{node} $ + 2）的最大值，加2是因为加一个结点会加两条边。

$ max_{node\in tree}\{f_{lson}{node}+f_{rson}{node}+2\} $

> 如果左/右子树为空，最大边数为-1；
>
> 如果左/右子树是叶子结点，最大边数为0
>

注意「以左结点在左子树中为终点的最大直径」，表明了递归的返回条件是必须以根结点为终点的最大直径，所以返回值为：

$ max_{node\in tree}\{f_{lson}{node}, f_{rson}{node}\} +1 $

```java
class Solution {

  private int maxDiameter = 0;
  public int diameterOfBinaryTree(TreeNode root) {
    dfs(root);
    return maxDiameter;
  }
  // 定义为以root结点为结束点的最大边数
  private int dfs(TreeNode root) {
    if(root == null) {
      // 叶子结点边数为0，所以空结点边数为-1
      return -1;
    }
    int left = dfs(root.left);
    int right = dfs(root.right);

    // 求最大直径
    maxDiameter = Math.max(left + right + 2, maxDiameter);

    return Math.max(left, right) + 1;
  }
}
```

## [124. Binary Tree Maximum Path Sum](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)
跟543题是一样的思想，一个是路径，一个路径和。

二叉树中最大路径和 可以转化为：

在二叉树中，最大路径和必然是包含某个结点的，那就是遍历所有的结点，找到能使下列公式为最大值的结点。

$ Max\\\{ 左子树以左结点为结束点的最大路径和, \\
右子树中以右结点为结束点的最大路径和, \\
左子树以左结点为结束点的最大路径和 + 右子树中以右结点为结束点的最大路径和,, \\
0\} + root.val $

可以看出，有四种情况：

1. 左子树中以左结点为结束点的最大路径和 + root.val
2. 右子树中以右结点为结束点的最大路径和, + root.val
3. 左子树中以左结点为结束点的最大路径和 + 右子树中以右结点为结束点的最大路径和, + root.val
4. root.val
    1. 因为可能有负数和的存在

```java
class Solution {

  private int result = -Integer.MIN_VALUE;

  public int maxPathSum(TreeNode root) {
    dfs(root);
    return result;
  }

  // 定义以root为终点的最大路径和
  private int dfs(TreeNode root) {
    if (root == null) {
      return 0;
    }
    int left = dfs(root.left);
    int right = dfs(root.right);

    // res 定义为包含root结点的最大路径和，那就有四种可能
    // 1. 左子树中以左结点为结束点的最大路径和 + root.val
    // 2. 右子树中以右结点为结束点的最大路径和 + root.val
    // 3. 左子树中以左结点为结束点的最大路径和 + 右子树中以右结点为结束点的最大路径和 + root.val
    // 4. root.val

    // 可以归纳为：max(左子树中以左结点为结束点的最大路径和, 右子树中以右结点为结束点的最大路径和, 左子树中以左结点为结束点的最大路径和 +
    // 右子树中以右结点为结束点的最大路径和, 0) + root.val
    result = Math.max(left + root.val, result);
    result = Math.max(right + root.val, result);
    result = Math.max(left + right + root.val, result);
    result = Math.max(root.val, result);

    return Math.max(Math.max(left, right) + root.val, root.val);
  }
}
```

## [549. Binary Tree Longest Consecutive Sequence II](https://leetcode.cn/problems/binary-tree-longest-consecutive-sequence-ii/)
dfs的返回值定义为包含该结点的 最长连续递增序列的长度increase和最长连续递减的长度decrease。

如果root的左结点和右结点都不存在，那包含该结点的dfs的 increase就为1、decrease就为1。

如果存在左结点或者右结点，且存在递增序列，那increase就在以前最大的基础上加1；

如果存在递减序列，那decrease就在以前最大的基础上加1；

```java
class Solution {
  private int res;
  public int longestConsecutive(TreeNode root) {
    if(root == null) {
      return new int[]{0, 0};
    }
    dfs(root);
    return res;

  }
  // 包含该结点的最长连续递增和连续递减的路径长度
  private int[] dfs(TreeNode root) {

    int increase = 1;
    int decrease = 1;
    if(root.left != null) {
      // 左结点的最长连续递增和连续递减的路径长度
      int[] left = dfs(root.left);
      if(root.val == root.left.val + 1) {
        increase = left[0] + 1;
      } 
      if(root.val == root.left.val - 1) {
        decrease = left[1] + 1;
      }
    }
    if(root.right != null) {
      // 右结点的最长连续递增和连续递减的路径长度
      int[] right = dfs(root.right);
      if(root.val == root.right.val + 1) {
        increase = Math.max(increase, right[0] + 1);
      } 
      if(root.val == root.right.val - 1) {
        decrease = Math.max(decrease, right[1] + 1);
      }
    }

    int temp = 0;
    if(root.left != null && root.right != null) {
      if(root.val == root.left.val + 1 && root.val == root.right.val - 1) {
        temp = increase + decrease - 1;
      }
      else if(root.val == root.left.val - 1 && root.val == root.right.val + 1) {
        temp = increase + decrease - 1;
      }
    } 
    if(temp == 0) {
      temp = Math.max(increase, decrease);
    }
    res = Math.max(res, temp);
    // System.out.println(increase + " " + decrease);
    return new int[] {increase, decrease};
  }
}
```

```java
    private int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    public int shortestDistance(int[][] maze, int[] start, int[] destination) {
        int m = maze.length;
        int n = maze[0].length;
        int x = start[0];
        int y = start[1];
        int[][] distance = new int[m][n];
        for(int[] dis : distance) {
            Arrays.fill(dis, Integer.MAX_VALUE);
        }
        distance[x][y] = 0;
        dfs(maze, destination, x, y, distance);
        return distance[destination[0]][destination[1]] == Integer.MAX_VALUE ? -1 : distance[destination[0]][destination[1]];

    private void dfs(int[][] maze, int[] destination, int currentX, int currentY, int[][] distance) {

            return ;

            int nextY = currentY + direction[1];

                nextY = nextY + direction[1];
                count++;

        }
```

```java
class Solution {
    public String findShortestWay(int[][] maze, int[] ball, int[] hole) {
        dfs(maze, ball[0], ball[1], hole, 0, 0, 0, "");
        return ans;
    }

    private String ans = "impossible";
    private int minSteps = Integer.MAX_VALUE;

    // dx dy代表了移动的方向
    private void dfs(int[][] maze, int i, int j, int[] hole, int dx, int dy, int steps,
                     final String path) {
        if (steps >= minSteps)
            return;

        if (dx != 0 || dy != 0) { // Both are zero for the initial ball position
            while (isValid(i+dx, j+dy, maze)) {
                i += dx;
                j += dy;
                ++steps;
                // 达到终点 且 步数最小
                if (i == hole[0] && j == hole[1] && steps < minSteps) {
                    minSteps = steps;
                    ans = path;
                }
            }
        }

        if (maze[i][j] == 0 || steps + 2 < maze[i][j]) {
            maze[i][j] = steps + 2; // +2 to because of maze[i][j] == 0 || 1
            // down
            if (dx == 0)
                dfs(maze, i, j, hole, 1, 0, steps, path + "d");
            // left
            if (dy == 0)
                dfs(maze, i, j, hole, 0, -1, steps, path + "l");
            // right
            if (dy == 0)
                dfs(maze, i, j, hole, 0, 1, steps, path + "r");
            // up
            if (dx == 0)
                dfs(maze, i, j, hole, -1, 0, steps, path + "u");
        }
    }
    private boolean isValid(int x, int y, int[][] maze) {
        return (x >= 0 && x < maze.length && y >= 0 && y < maze[0].length &&
                maze[x][y] != 1);

    }
}
```

### [499. 迷宫 III](https://leetcode.cn/problems/the-maze-iii/)
迷宫3要求记录下最短的路径是什么，但要注意这道题的一些细节与迷宫2不一样，迷宫2中，球是经过目的地，如果没有遇到边界和墙壁，是不会停的，但迷宫3中，目的地是一个洞，经过了就算到达了。

还是采用深度优先遍历的算法，依然用int[][] distance记录每一个转折点到初始位置的距离，用一个map记录下每一个转折点到起始点的距离最小的具体路径，答案就是map中key为目的地的值。

记录路径的map不记录所有的路径，然后最后做比较，而是在遍历的过程中，当发现最小的路径时，就进行更新，发现更大的路径时，就跳过这个遍历。

```java
class Solution {

    private int[][] directions = {{0,-1},{-1,0},{0,1},{1,0}};
    private char[] way = {'l', 'u', 'r', 'd'};

    public String findShortestWay(int[][] maze, int[] ball, int[] hole) {
        int m = maze.length;
        int n = maze[0].length;

        // distance记录的每一个转折点到起点的距离
        int[][] distance = new int[m][n];
        for(int[] dis : distance) {
            Arrays.fill(dis, Integer.MAX_VALUE);
        }

        int startRow = ball[0];
        int startCol = ball[1];
        distance[startRow][startCol] = 0;

        // 记录了每一个点的最短距离
        Map<Integer, String> minPathMap = new HashMap<>();
        dfs(maze, startRow, startCol, hole, distance, minPathMap);
        String res = minPathMap.getOrDefault(hole[0] * n + hole[1], "impossible");
        return res.isEmpty() ? "impossible" : res;
    }


    private void dfs(int[][] maze, int currentX, int currentY, int[] hole, int[][] dists, Map<Integer, String> minPathMap) {
        // 到达目的地
        if(isHole(currentX, currentY, hole)) {
            return ;
        }
        int m = maze.length;
        int n = maze[0].length;
        // 四个方向遍历
        for(int k = 0; k < 4; ++k) {
            // 当前点的路径
            String currentPath = minPathMap.getOrDefault(currentX * n + currentY, "");
            // 移动直到停下的下一个点
            int nextX = currentX;
            int nextY = currentY;

            int count = 0;
            while(!isEdge(nextX, nextY, maze) && !isWall(nextX, nextY, maze) && !isHole(nextX, nextY, hole)) {
                nextX += directions[k][0];
                nextY += directions[k][1];
                count++;
            }
            // 如果跑到了墙或者边界外，回退一步
            if(!isHole(nextX, nextY, hole)) {
                nextX -= directions[k][0];
                nextY -= directions[k][1];
                count--;
            }

            // 记录行走的方向
            String nextPath = currentPath + way[k];
            // 如果遇到阻碍没有走；或者是 如果停下的点已经访问过，且距离 比之前访问的路径更长时，这条路径再遍历就没有任何意义
            if (count == 0 || dists[nextX][nextY] < dists[currentX][currentY] + count) {
                continue;
            }

            // 停下的点比以前访问的点 路径更短，更新路径长度，继续遍历
            if(dists[nextX][nextY] > dists[currentX][currentY] + count) {
                dists[nextX][nextY] = dists[currentX][currentY] + count;
                minPathMap.put(nextX * n + nextY, nextPath);
                dfs(maze, nextX, nextY, hole, dists, minPathMap);
            } else if(dists[nextX][nextY] == dists[currentX][currentY] + count &&  nextPath.compareTo(minPathMap.getOrDefault(nextX * n + nextY, "")) < 0) {
                // 停下的点的路径与之前访问的路径一样，但是路径的字典顺序更短时，
                minPathMap.put(nextX * n + nextY, nextPath);
                dfs(maze, nextX, nextY, hole, dists, minPathMap);
            }
        }
    }

    private boolean isEdge(int x, int y, int[][] maze) {
        return x < 0 || x > maze.length - 1 || y < 0 || y > maze[0].length - 1;
    }

    private boolean isWall(int x, int y, int[][] maze) {
        return maze[x][y] == 1;
    }

    private boolean isHole(int x, int y, int[] hole) {
        return (x == hole[0] && y == hole[1]);
    }
}
```
