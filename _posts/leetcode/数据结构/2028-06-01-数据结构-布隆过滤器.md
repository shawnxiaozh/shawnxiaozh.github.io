误判的场景：a不是输入对象，但是却错误的认为是输入对象

false positives: the element is not there but the bloom filter says it is

> false positives are occurrences where a test or algorithm incorrectly identifies an instance as belonging to a certain category or group when it actually does not.
>

false negatives: the element is there but the bloom filter says it is not

> false negatives refer to instances where a test or algortihm fails to identify a certain category or group when it actually belongs to that category or group.
>

trade off:

less memory  -- less accurate

many Nosql databases use bloom filters to reduce the disk reads for keys that don't exist with an LSM-tree-based database, searching for a key that doesn't exist requires looking through many files and is very costly
