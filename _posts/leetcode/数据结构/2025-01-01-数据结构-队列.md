## 基本性质
队列是一个先进先出的数据结构。

<!-- 这是一张图片，ocr 内容为：BACK FRONT ENQUEUE DEQUEUE -->
![](https://cdn.nlark.com/yuque/0/2023/png/32473878/1678097940368-c37ccac0-60ba-4c24-8fb9-a89c8e3be7ff.png)

添加一个元素进入队列称为入队（enqueue），新元素始终被添加到队列的末尾；

删除一个元素被称为出队（dequeue），只能删除队头的元素。

## 循环队列
普通的队列一旦队列满了之后，就无法再在队尾插入新值，只有等到队头再移除一个元素后才有位置继续插入。循环队列则是自动化了这一过程，队列满的时候队尾插入一元素，会自动从队头移除一元素。

## 阻塞队列
阻塞队列是在队列的基础上增加了阻塞操作，队列为空的时候，从队头取数据会被阻塞，直到队列中有了数据才能返回；队列满的时候，插入数据会被阻塞，直到队列中有空闲位置后再插入数据，然后再返回。

<!-- 这是一张图片，ocr 内容为：阻塞队列 PRODUCER THREAD THREAD ONSUMER PUT TAKE -->
![](https://cdn.nlark.com/yuque/0/2023/png/32473878/1678109069716-6ce70809-7ddc-40a2-91af-b83bf4dfbf6f.png)

阻塞队列能实现生产者-消费者模型，可以有效地协调生产和消费的速度。当“生产者”生产数据的速度过快，“消费者”来不及消费时，存储数据的队列很快就会满了。这个时候，生产者就阻塞等待，直到“消费者”消费了数据，“生产者”才会被唤醒继续“生产”。

#### LinkedList
LinkedList是双向链表，用的链表节点（Node）存储元素，Node中有前驱节点prev，后驱节点next。

队头节点指针first、队尾节点指针last。

LinkedList是线程不安全的。

```java
public class LinkedList<E>
  extends AbstractSequentialList<E>
  implements List<E>, Deque<E>, Cloneable, java.io.Serializable
  {
    transient int size = 0;

    /**
* Pointer to first node.
*/
    transient Node<E> first;

    /**
* Pointer to last node.
*/
    transient Node<E> last;

  }
private static class Node<E> {
  E item;
  Node<E> next;
  Node<E> prev;

  Node(Node<E> prev, E element, Node<E> next) {
    this.item = element;
    this.next = next;
    this.prev = prev;
  }
}
```

#### ArrayDeque
ArrayDeque是采用的对象数组存储元素。

队头指针head，队尾指针tail。

线程不安全。

```java
public class ArrayDeque<E> extends AbstractCollection<E>
  implements Deque<E>, Cloneable, Serializable
  {

    transient Object[] elements;

    transient int head;

    transient int tail;
  }
```

### API
Queue的基本API：

| **方法** | **描述** | **边界处理** |
| :--- | :--- | :--- |
| add | 队尾添加一个元素 | 如果队列已满，抛出IllegalStateException异常 |
| offer | 队尾添加一个元素 | 如果队列已满，返回false |
| remove | 返回队头的元素并移除 | 如果队列为空，抛出NoSuchElementException异常 |
| poll | 返回队头的元素并移除 | 如果队列为空，返回null |
| element | 返回队头的元素 | 如果队列为空，抛出NoSuchElementException异常 |
| peek | 返回队头的元素 | 如果队列为空，返回null |
| | | |
| | | |

其实就三个API，对应着添加元素、移除元素、查看队头元素。至于用抛出异常的add/remove，还是用返回false/null的offer/poll，目前来说没啥区别，因为一般来说，使用都是会用List或者Array的isEmpty()做预先判断，再做增删操作。习惯的话，还是使用offer/poll，返回队头的元素，也常使用peek。

### [111. Minimum Depth of Binary Tree](https://leetcode.cn/problems/minimum-depth-of-binary-tree/)
```java
class Solution {
    public int minDepth(TreeNode root) {
      if(root == null) {
        return 0;
      }
      // BFS
      Deque<TreeNode> queue = new ArrayDeque<>();
      queue.offer(root);
      int depth = 0;
      while(!queue.isEmpty()) {
        int size = queue.size();
        depth++;
        for(int i = 0; i < size; i++) {
          TreeNode node = queue.poll();
          if(node.left == null && node.right == null) {
            return depth;
          }
          if(node.left != null) {
            queue.offer(node.left);
          }
          if(node.right != null) {
            queue.offer(node.right);
          }
        }
      }
      return depth;
    }
}
```

### [622. 设计循环队列](https://leetcode.cn/problems/design-circular-queue/)
```java
class MyCircularQueue {

  private int front;
  private int rear;

  private int capacity;
  private int[] arr;

  public MyCircularQueue(int k) {
    capacity = k + 1;
    arr = new int[capacity];
    front = 0;
    rear = 0;
  }

  public boolean enQueue(int value) {
    if (isFull()) {
      return false;
    }
    arr[rear] = value;
    rear = (rear + 1) % capacity;
    return true;
  }

  public boolean deQueue() {
    if(isEmpty()) {
      return false;
    }
    front = (front + 1) % capacity;
    return true;

  }

  public int Front() {
    if(isEmpty()) {
      return -1;
    }
    return arr[front];
  }

  public int Rear() {
    if(isEmpty()) {
      return -1;
    }

    return arr[(rear - 1 + capacity) % capacity];
  }

  public boolean isEmpty() {
    return rear == front;
  }

  public boolean isFull() {
    return ((rear + 1) % capacity)  == front;
  }
}
```

### [54. 螺旋矩阵](https://leetcode.cn/problems/spiral-matrix/)
![画板](https://cdn.nlark.com/yuque/0/2023/jpeg/32473878/1678112439978-657c6a36-22fe-4b6a-81ef-be22708b777b.jpeg)

螺旋矩阵走的顺序遵循右 下 左 上，遇到障碍后再调转方向。

```java
class Solution {
  public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> result = new ArrayList<>();
    int m = matrix.length;
    int n = matrix[0].length;
    if(m == 0) {
      return result;
    }
    // 右 -> 下 -> 左 -> 上
    int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
    boolean[][] visited = new boolean[m][n];
    int direction = 0;

    int x = 0; 
    int y = 0;
    for(int i = 0; i < m * n; i++) {
      result.add(matrix[x][y]);
      visited[x][y] = true;
      int ex = x + directions[direction][0];
      int ey = y + directions[direction][1];
      if(ex < 0 || ex >= m || ey < 0 || ey >= n || visited[ex][ey]) {
        direction = (direction + 1) % 4;
      }
      x = x + directions[direction][0];
      y = y + directions[direction][1];

    }
    return result;
  }

}
```
