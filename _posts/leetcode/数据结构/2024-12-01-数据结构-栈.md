栈是一种后入先出的数据结构，插入元素被称为入栈，取出元素被称为出栈。

<!-- 这是一张图片，ocr 内容为：2 2 2 1 1 1 PUSH PUSH PUSH EMPTY POP STACK -->
![](https://cdn.nlark.com/yuque/0/2023/png/32473878/1681226916324-f5433149-2036-4b01-a15c-b4ff44fc0053.png)

栈最经典的应用应该就是函数栈，函数的调用和销毁伴随着入栈出栈，如果某个函数中的函数调用链过长，比如递归函数没有写对边界，无限的进行递归，超过了栈内存的限制，就会出现栈溢出，栈溢出也就是大名鼎鼎的stack overflow。

## Java API
JDK中是有Stack类的，继承自Vector，但早期设计的并不是很完善，因此doc都推荐使用我们在[队列篇](http://139.198.106.15/index.php/%e6%95%b0%e6%8d%ae%e7%bb%93%e6%9e%84%e4%b8%8e%e7%ae%97%e6%b3%95-%e9%98%9f%e5%88%97/)中讲到的双端队列Deque来作为栈的API使用。

`Deque<Integer> stack = new ArrayDeque<>();`

Stack类的缺陷归为两点：

1. 当初继承了Vector为了复用Vector的方法，来实现入栈push、出栈pop操作，Vector是基于数组实现的，里面很多方法为了线程安全，都使用了synchronized，因此整体上的效率并不高。
2. Stack和Vector其实没多少关系，但却可以复用vector大多数方法，设计上也不规范。

其实我们的双端队列也是有栈的api的：

|  |  |  |
| --- | --- | --- |
| void push(E e); | 添加一个元素入栈 | 栈已满的情况下，抛出IllegalStateException异常 |
| void addFirst(E e); | 添加一个元素入栈 | 栈已满的情况下，抛出IllegalStateException异常 |
| boolean offerFirst(E e); | 添加一个元素入栈 | 栈已满的情况下，返回false； |
| E pop(); | 返回栈顶元素并移除 | 栈为空的情况下，抛出NoSuchElementException异常 |
| E removeFirst(); | 返回栈顶元素并移除 | 栈为空的情况下，抛出NoSuchElementException异常 |
| E pollFirst(); | 返回栈顶元素并移除 | 栈为空的情况下，返回null |
| E peek(); | 返回栈顶元素 | 栈为空的情况下，返回null |
| E getFirst(); | 返回栈顶元素 | 栈为空的情况下，抛出NoSuchElementException异常 |

push入栈方法实际上是用的是addFirst()，意味着在数组中，栈顶在数组的前面，栈底在数组的后面。

```java
public void push(E e) {
    addFirst(e);
}
```

### [155. 最小栈](https://leetcode.cn/problems/min-stack/)
题目：设计一个支持push, pop, top操作，并能在常数事件内检索到最小元素的栈。

求解：

一个栈stack用来正常元素的出入栈，另外再利用一个辅助栈minStack来存储当前栈顶中最小的元素。

比如5, 2, 3, 1, -1正常入栈，stack的元素则为[5, 2, 3, 1, -1]，从左到右为栈底到栈顶；minStack的元素为[5, 2, 2, 1, -1]，从左到右为栈底到栈顶。

当stack中栈顶元素出栈时，minStack也跟着出栈，这样minStack就始终是stack中最小的元素。

```java
class MinStack {

  Deque<Integer> stack;
  // 用一个辅助栈来保证栈顶的元素始终是最小的。
  Deque<Integer> minStack;

  public MinStack() {
    stack = new ArrayDeque<>();
    minStack = new ArrayDeque<>();
  }

  public void push(int val) {
    stack.push(val);
    if(!minStack.isEmpty() && minStack.peek() < val) {
      minStack.push(minStack.peek());
    } else {
      minStack.push(val);
    }
  }

  public void pop() {
    stack.pop();
    minStack.pop();
  }

  public int top() {
    return stack.peek();
  }

  public int getMin() {
    return minStack.peek();
  }
}
```

有没有不使用额外空间实现的方法呢？

我们可以用一个变量始终记录最小值；

再用一个辅助栈插入元素，插入时减去最小值后存入栈中，其差值大于等于0时说明插入值大于最小值，其差值小于0时说明插入值小于最小值。

出栈时的值如果大于等于0，说明插入时不是最小值，那加上最小值就是原始值；

> 插入值为x，最小值为min，diff  = x - min => x = diff + min
>

如果小于0，说明插入时就是最小值，min - diff就是原始值

> 插入值为min，当时最小值为previous_min，min - previous_min = diff => previous_min = min - diff
>
> 更新min = previous_min;
>

```java
class MinStack {

  Integer min;
  Deque<Long> stack;

  /**
* initialize your data structure here.
*/
  public MinStack() {
    min = Integer.MAX_VALUE;
    stack = new ArrayDeque<>();
  }

  public void push(int x) {
    if (stack.isEmpty()) {
      min = x;
    } 
    stack.push(Long.valueOf(x) - min);
    min = Math.min(x, min);
  }

  public void pop() {
    Long diff = stack.pop();
    if (diff < 0) {
      min = (int) (min - diff);
    }
  }

  public int top() {
    Long diff = stack.peek();
    if (diff >= 0) {
      return (int) (min + diff);
    } else {
      return min;
    }
  }

  public int getMin() {
    return min;
  }
}
```

### [20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)
```java
class Solution {
  public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> map = new HashMap<>();
    map.put(')', '(');
    map.put(']', '[');
    map.put('}', '{');
    char[] chars = s.toCharArray(); 
    for(char ch : chars) {
      if(ch == '(' || ch == '{' || ch == '[') {
        stack.push(ch);
      }
      if(ch == ')' || ch == '}' || ch == ']') {
        if(stack.peek() == map.get(ch)) {
          stack.pop();
        } else {
          return false;
        }
      }
    }
    return stack.isEmpty();
  }
}
```

```java
class Solution {
  public int evalRPN(String[] tokens) {
    Deque<String> stack = new LinkedList<>();
    for(String token : tokens) {
      if(!"+".equals(token) && !"-".equals(token) && !"*".equals(token) && !"/".equals(token)) {
        stack.push(token);
      } else {
        String s1 = stack.pop();
        String s2 = stack.pop();
        if("+".equals(token)) {
          stack.push(String.valueOf(Integer.valueOf(s2) + Integer.valueOf(s1)));

        } else if ("/".equals(token)) {
          stack.push(String.valueOf(Integer.valueOf(s2) / Integer.valueOf(s1)));
        }
      }
    }

  }
```

```java
class Solution {
  public String decodeString(String s) {
    Deque<Character> stack = new LinkedList<>();
    Deque<Character> tempStack = new LinkedList<>();
    for(int i = 0; i < s.length(); i++) {
      char cur = s.charAt(i);
      if(Character.isDigit(cur)) {
        stack.push(cur);
      } else {
        if(s.charAt (i) != ']') {
          stack.push(s.charAt(i));
        } else {
          while(!('[' == stack.peek())) {
            tempStack.addFirst(stack.pop());
          }
          stack.pop();  

          StringBuilder str = new StringBuilder();
          while(!tempStack.isEmpty()) {
            str.append(tempStack.pop());
          }

          int num = 0;
          int count = 0;
          while(stack.peek() != null && Character.isDigit(stack.peek())) {
            num = Integer.parseInt(String.valueOf(stack.pop())) * (int) Math.pow(10, count) + num;
            count++;
          }
          String repeatStr = str.toString().repeat(num);

          for(int j = 0; j < repeatStr.length(); j++) {
            stack.push(repeatStr.charAt(j));
          }
        }
      }
    }
    StringBuffer res = new StringBuffer();
    while(!stack.isEmpty()) {
      res.append(stack.removeLast());
    }

    return res.toString();

  }
}
```

```java
class MyQueue {

      inStack = new ArrayDeque<>();
      outStack = new ArrayDeque<>();

    }
    
    public void push(int x) {
      inStack.push(x);
    }
    
    public int pop() {
      if (!outStack.isEmpty()) {
        return outStack.pop();
      } else {
        while(!inStack.isEmpty()){
          outStack.push(inStack.pop());
        }
        return outStack.pop();
      }

      if(!outStack.isEmpty()) {
        return outStack.peek();
      } else {
        return inStack.peekLast();
      }

    }
    
    public boolean empty() {
      return inStack.isEmpty() && outStack.isEmpty();
    }
}
```

```java
class Solution {
  public String simplifyPath(String path) {
    // 不包含"/"，包含的有"","..",".","str"
    // "",".": 代表的是当前路径，不需要改变
    // "..": 回到上一个路径，出栈
    // "str': 代表真实的路径，直接加入栈中
    String[] names = path.split("/");
    Deque<String> stack = new ArrayDeque<>();
    for(String name : names) {
      // 回退
      if("..".equals(name)) {
        if(!stack.isEmpty()) {
          stack.pop(); 
        }
      } else if(name.length() > 0 && !".".equals(name)){
        // 
        stack.push(name);
      }
    }
    if(stack.isEmpty()) {
      return new String("/");
    }
    StringBuilder stringBuilder = new StringBuilder();
    while(!stack.isEmpty()) {
      stringBuilder.append("/");
      stringBuilder.append(stack.removeLast());
    }

    return stringBuilder.toString();
  }
}
```

### [716. 最大栈](https://leetcode.cn/problems/max-stack/)
最重要的是peekMax()，popMax()

#### 双栈
```java
class MaxStack {
  Deque<Integer> stack;
  Deque<Integer> maxStack;

  public MaxStack() {
    stack = new ArrayDeque();
    maxStack = new ArrayDeque();
  }

  public void push(int x) {

    if(maxStack.isEmpty()) {
      maxStack.push(x);
    } else {
      int max = maxStack.peek();
      maxStack.push(Math.max(max, x));
    }
    stack.push(x);
  }

  public int pop() {
    maxStack.pop();
    return stack.pop();
  }

  public int top() {
    return stack.peek();
  }

  public int peekMax() {
    return maxStack.peek();
  }

  public int popMax() {
    int max = peekMax();
    Deque<Integer> buffer = new ArrayDeque();
    while (top() != max) {
      buffer.push(pop());
    }
    pop();
    while (!buffer.isEmpty()) {
      push(buffer.pop());
    }
    return max;
  }
}
```

时间复杂度O(N)，超时

#### 双向链表 + 红黑树
```java
class MaxStack {
  
  DoubleLinkedList dll;
  TreeMap<Integer, List<Node>> treemap;
    

    public MaxStack() {
        dll = new DoubleLinkedList();
        treemap = new TreeMap<>();
    }

    public void push(int x) {
      Node node = dll.add(x);
      if(!treemap.containsKey(x)) {
        treemap.put(x, new ArrayList<Node>());
      } 
      treemap.get(x).add(node);
    }

    public int pop() {
      int val = dll.pop();
      List<Node> list = treemap.get(val);
      list.remove(list.size() - 1);
      if(list.isEmpty()) {
        treemap.remove(val);
      }
      return val;
    }

    public int top() {
        return dll.peek();
    }

    public int peekMax() {
        return treemap.lastKey();
    }

    public int popMax() {
      int max = peekMax();
      List<Node> list = treemap.get(max);
      Node node = list.remove(list.size() - 1);
      dll.unlink(node);
      if(list.isEmpty()) {
        treemap.remove(max);
      }
      return max;
    }
}

class DoubleLinkedList {
  Node head, tail;

  public DoubleLinkedList () {
    head = new Node(0);
    tail = new Node(0);
    head.next = tail;
    tail.prev = head;
  }


  public Node add(int val) {
    Node x = new Node(val);
    x.next = tail;
    x.prev = tail.prev;
    x.prev.next = x;
    tail.prev = x;
    return x;
  }

  public int pop() {
    Node popNode = unlink(tail.prev);
    int val = popNode.val;
    popNode = null;
    return val;
  }

  public int peek() {
    return tail.prev.val;
  }

  public Node unlink(Node node) {
    node.prev.next = node.next;
    node.next.prev = node.prev;
    return node;
  }
}

class Node {
  int val;
  Node prev;
  Node next;
  public Node(int v) {
    val = v;
  }
}
```

### [1209. 删除字符串中的所有相邻重复项](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string-ii/)

```java
class Solution {
  public String removeDuplicates(String s, int k) {
    char[] charArray = s.toCharArray();
    Deque<Character> stack = new ArrayDeque<>();
    Deque<Integer> countStack = new ArrayDeque<>();
    int[] count = new int[26];
    for(int i = 0; i < charArray.length; i++) {
      if(!stack.isEmpty() && stack.peek() == charArray[i]) {
        countStack.push(countStack.pop() + 1);
      } else {
        countStack.push(1);
      }
      stack.push(charArray[i]);

      if(!stack.isEmpty() && charArray[i] == stack.peek() && countStack.peek() == k) {
        int tmp = k;
        while(tmp > 0) {
          stack.pop();
          popOfCount(countStack);
          tmp--;
        }
      }
    }

    StringBuilder stringBuilder = new StringBuilder();
    while(!stack.isEmpty()) {
      stringBuilder.append(stack.removeLast());
    }

    return stringBuilder.toString();
  }

  private void popOfCount(Deque<Integer> countStack) {
    if(countStack.peek() > 1) {
      countStack.push(countStack.pop() - 1);
    } else {
      countStack.pop();;
    }
  }
}
```

#### 单栈：
把元素和计数放到一个栈中：

```java
class Solution {
  class Pair {
    int cnt;
    char ch;
    public Pair(int cnt, char ch) {
      this.cnt = cnt;
      this.ch = ch;
    }
  }

  public String removeDuplicates(String s, int k) {
    char[] charArray = s.toCharArray();
    Deque<Pair> stack = new ArrayDeque<>();

    for(int i = 0; i < charArray.length; i++) {
      if(stack.isEmpty() || stack.peek().ch != charArray[i]) {
        stack.push(new Pair(1, charArray[i]));
      } else {
        stack.peek().cnt++;
      }
      if(!stack.isEmpty() && charArray[i] == stack.peek().ch && stack.peek().cnt == k) {
        stack.pop();
      }
    }

    StringBuilder stringBuilder = new StringBuilder();
    while(!stack.isEmpty()) {
      Pair pair = stack.removeLast();
      for(int i = 0; i < pair.cnt; i++) {
        stringBuilder.append(pair.ch);
      }
    }

    return stringBuilder.toString();
  }
}
```

时间复杂度O(N)，空间复杂度O(N)
