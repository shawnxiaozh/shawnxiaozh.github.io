Binary Index Tree，also called Fenwick Tree, or just BIT abbreviated.

## 前置知识
### lowbit
lowbit指的是一个数对应的二进制中最低的非零位所对应的十进制值。

比如10的二进制位是1010，最低的非零位为右边第二个，对应的十进制值为2，即10的lowbit为2。

那如何用代码进行计算lowbit呢？

Java中Integer类中有该方法：

```java

public final class Integer extends Number implements Comparable<Integer> {
	/**
   * Returns an {@code int} value with at most a single one-bit, in the
   * position of the lowest-order ("rightmost") one-bit in the specified
   * {@code int} value.  Returns zero if the specified value has no
   * one-bits in its two's complement binary representation, that is, if it
   * is equal to zero.
   *
   * @param i the value whose lowest one bit is to be computed
   * @return an {@code int} value with a single one-bit, in the position
   *     of the lowest-order one-bit in the specified value, or zero if
   *     the specified value is itself equal to zero.
   * @since 1.5
   */
  public static int lowestOneBit(int i) {
    // HD, Section 2-1
    return i & -i;
  }
}
```

计算原理：

> 将 x 的二进制所有位全部取反，再加 1，就可以得到 -x 的二进制编码。例如，6 的二进制编码是 110，全部取反后得到 001，加 1 得到 010。 
>
> 设原先 x 的二进制编码是 (...)10...00，全部取反后得到 [...]01...11，加 1 后得到 [...]10...00，也就是 -x 的二进制编码了。这里 x 二进制表示中第一个 1 是 x 最低位的 1。 
>
> (...) 和 [...] 中省略号的每一位分别相反，所以 x & -x = (...)10...00 & [...]10...00 = 10...00，得到的结果就是 lowbit。
>

## 引入
### 适用场景
树状数组是一种支持单点修改和区间查询的，代码量最小的数据结构。

常常对一个数组会有这样的操作：查询某个子区间（长度为N）的和，修改某个子区间(长度为M)的值。

暴力法下，查询的时间复杂度为O(N)，修改的时间复杂度为O(M)。

「前缀和」能够将查询时间复杂度降为O(1)，「差分」能够将修改时间复杂度降为O(1)

+ [基础 - 前缀和](https://www.yuque.com/xiaozhang-exnvh/tvmypy/gecgly08ae2un90f)适用场景：频繁对原始数组的子区间和进行查询
    - 查询的时间复杂度O(1)，
    - 但如果要修改某个值，需要修改所有包含这个值的前缀和，修改的时间复杂度为O(N)
+ [基础 - 差分](https://www.yuque.com/xiaozhang-exnvh/tvmypy/gh3fpuz03ent9mqz)适用场景：频繁对子区间的值进行统一加减，
    - 修改的时间复杂度为O(1)；
    - 但查询的时间复杂度为O(N)。

而树状数组能解决的就是，查询和修改的时间复杂度都稳定到$ O(log_2N) $。一般大小的数组，也许是不需要这样的优化，但如果数组大小超百万，且修改和查询的频率都很频繁，那树状数组的优势就能体现出来了。

那么问题就来了，如何确定tree中某个值代表的原数组区间？

### 管辖区间 

从下往上数，每一行的区间长度正好是tree索引的lowbit，所以序号为i的序列正好就是序列为lowbit(i)且以i结尾的序列。比如下标索引为12的10，对应的子区间长度为lowbit(12) = 4，区间索引结尾为12.

因此x的管辖区间c[x]为:

$ c[x]=|x-lowbit(x)+1, x| $

每个树状数组的值都代表了一个子区间，我这里把它称为**树状子区间**。

### 区间查询
区间查询必然带有边界[l, r]，求子区间和利用前缀和

$ preSum[r]-preSum[l-1] $

`preSum[r]`、`preSum[l-1]`用树状数组的性质来求。

从树状数组的角度上看，前缀和 就是 原数组的子区间和相加的结果，原数组的子区间和已经由树状数组进行了映射。

前面提到，树状数组中每个数`tree[r]`都指代了某个子区间范围的和，子区间范围就是`[r-lowbit(r)+1, r]`。

求`preSum[r]`时，r必然在某个树状子区间上，只要不断地往前找接壤的树状子区间，就能够囊括原数组r前的所有值。`[1, ...],...,[r-lowbit-lowbit(r-lowbit(r))-1, r-lowbit(r)],[r-lowbit(r)+1, r]`区间的和。

```java
// 求位置p的前缀和
publc int preSumOf(int p) {
    int res = 0; 
    while(x > 0) {
        res += tree[p];
        p -= lowbit(p);
    }
    return res;
}
```

模拟这个过程的话，可以使用队列 加上 优先队列判断是否队头是否是最小值。

```java
class Solution {
  public long countOperationsToEmptyArray(int[] nums) {
    // 维护一个最小堆
    PriorityQueue<Integer> priorityQueue = new PriorityQueue<>();
    for(int num : nums){
      priorityQueue.add(num);
    }

    // 维护一个队列
    Deque<Integer> queue = new LinkedList<>();
    for(int num : nums) {
      queue.add(num);
    }
    long count = 0;
    while(!queue.isEmpty()) {
      int num = queue.poll();
      if(priorityQueue.peek() == num) {
        priorityQueue.poll();
      } else {
        queue.add(num);
      }
      count++;
    }
    return count;
  }
}
```

但这样对于一个很大的降序数组说来，时间复杂度为O(N^2)

重新审视这个过程，如果把删除的地方看成队头的话，每次删除的是一定最小的值，如果不是，那就出队然后入队。

这个出队入队的过程其实可以看成一个循环，一个圈，假设各个结点没有动，而是有一个指针，一直在这个圈中走，那跟我们显式的移动位置是一个道理的，指针指向的始终是队头，出队入队就相当于没有删除、指针向前移动了一步；

删除可以看作打了个标记、然后指针向前移动了一步，我们重新来模拟这个过程。

```java
class Solution {
    public long countOperationsToEmptyArray(int[] nums) {
      // 维护一个最小堆保存最小值
      PriorityQueue<Integer> priorityQueue = new PriorityQueue<>();
      for(int num : nums){
        priorityQueue.add(num);
      }

      int n = nums.length;
      boolean[] deleted = new boolean[nums.length];
      long count =0;
      int step = 0;
      while(!priorityQueue.isEmpty()) {
        while(deleted[step % n]) {
          step++;
        }
        int num = nums[step % n];
        if(num == priorityQueue.peek()) {
          deleted[step % n] = true;
          priorityQueue.poll();
          
        }
        step++;
        count++;
      }
      
      return count;
    }
}
```

时间复杂度还是没有变。因为已经删除的点在数组中还存在，仍然需要遍历才能跳过，这个遍历的时间复杂度还是O(N)。尝试过用过一个记录下标下次访问的下标数组，但是时间复杂度还是无法降低。

这里面有两个点可以优化：

1. 一步一步的去找下一个点，对于降序数组来说，时间复杂度仍然是最坏的O(N)，既然每次删除的都是最小值，那其实是知道删除最小值后去的目标位置就是次小值的位置。中间的元素无论是否删除，都可以直接跳过到达下一个目标位置。
    1. 如何优化？我们可以用一个下标数组记录数组值从小到大的下标索引。
    2. 另一种方法是把数组构造成一个二维数组，int[][] data，data[][0] 存数组值，data[][1]存下标索引，然后按照数组值进行排序，
2. 既然可以直接跳到目标位置，那中间的步数到底是多少呢，由于我们在数组中使用的逻辑删除，所以也需要知道当前最小值（已经排除了删除的）到目标位置中有多少被删除的元素，所以区间被删除的个数可以转化为区间和。
    1. 区间和就可以利用到前缀和、差分、树状数组，我们不仅要查询，也需要更新，所以自然用树状数组能够将时间复杂度降到`logN`。
    2. 记录被删除的元素，不如记录未被删除的元素，这能让代码更易读，因为不需要再做复杂的减法（减去删除的个数），所以用树状数组记录未被删除的元素。

树状数组记录删除的元素个数：

```java

import java.util.Arrays;
import java.util.Comparator;

class Solution {
  static class BitTree {

    private final int[] tree;

    public BitTree(int n) {
      // 下标+1记录
      tree = new int[n + 1];
    }

    private int lowbit(int p) {
      return p & -p;
    }

    // 将下标p上的数加上x
    private void add(int p, int x) {
      while (p < tree.length) {
        tree[p] += x;
        p += lowbit(p);
      }
    }

    // 返回闭区间 [1, x] 的元素和
    private int preSum(int p) {
      int res = 0;
      while (p > 0) {
        res += tree[p];
        p -= lowbit(p);
      }
      return res;
    }

    // 返回闭区间 [left, right] 的元素和
    public int rangeSum(int left, int right) {
      return preSum(right) - preSum(left - 1);
    }
  }
  public long countOperationsToEmptyArray(int[] nums) {

    int n = nums.length;

    // 下标数组
    // nums = [3, 2, 4, 1]
    // id = [3, 1, 0, 2]
    Integer[] id = new Integer[n];
    for (int i = 0; i < n; i++) {
      id[i] = i;
    }

    // 从大到小排序: Arrays.sort(id, (i, j) -> nums[i] - nums[j]);
    Arrays.sort(id, Comparator.comparingInt(i -> nums[i]));

    long ans = 0;
    BitTree bit = new BitTree(n);

    // 上一个最小值的位置, 下面的下标和描述都是从1开始
    int prev = 1;
    for (int i = 0; i < n; i++) {
      int next = id[i] + 1;
      // 从 pre 移动到 next 的步数，跳过已经删除的数
      if (next >= prev) {
        ans += next - prev - bit.rangeSum(prev, next - 1);
      } else {
        // 从 pre 移动到 n，再从 1 移动到 next，跳过已经删除的数
        ans += ((n - prev - bit.rangeSum(prev, n)) + (next - bit.rangeSum(1, next)));
      }

      // 删除元素，树状数组记录下删除的元素个数
      bit.add(next, 1);
      // 删除也是一步
      ans++;
      prev = next;
    }
    return ans;
  }
}

```

树状数组记录未被删除的元素个数：

```java

import java.util.Arrays;
import java.util.Comparator;

class Solution {

  static class BitTree {

    private final int[] tree;

    public BitTree(int n) {
      // 下标+1记录
      tree = new int[n + 1];
    }

    private int lowbit(int p) {
      return p & -p;
    }

    // 将下标p上的数加上x
    private void add(int p, int x) {
      while (p < tree.length) {
        tree[p] += x;
        p += lowbit(p);
      }
    }

    // 返回闭区间 [1, x] 的元素和
    private int preSum(int p) {
      int res = 0;
      while (p > 0) {
        res += tree[p];
        p -= lowbit(p);
      }
      return res;
    }

    // 返回闭区间 [left, right] 的元素和
    public int rangeSum(int left, int right) {
      return preSum(right) - preSum(left - 1);
    }
  }

  public long countOperationsToEmptyArray(int[] nums) {

    int n = nums.length;
    // nums = [3, 2, 4, 1]
    // 下标数组 id = [3, 1, 0, 2]
    Integer[] id = new Integer[n];
    for (int i = 0; i < n; i++) {
      id[i] = i;
    }

    // 记录的是未被删除的元素个数
    BitTree bit = new BitTree(n);
    for(int i = 0; i < n; i++) {
      bit.add(i + 1, 1);
    }

    // 从大到小排序: Arrays.sort(id, (i, j) -> nums[i] - nums[j]);
    Arrays.sort(id, Comparator.comparingInt(i -> nums[i]));
    long ans = 0;

    // prev: 上一个最小值的位置，next:下一个最小值的最值。下标的计算和描述都是以从1开始的
    int prev = 1;
    for (int i = 0; i < n; i++) {
      int next = id[i] + 1; 
      if (next >= prev) {
        // [prev, next - 1] 未被删除的元素个数
        ans += bit.rangeSum(prev, next - 1);
      } else {
        // 移动 [prev, n] 和 [1, next - 1] 中未被删除的元素个数
        ans += (bit.rangeSum(prev, n) + bit.rangeSum(1, next - 1)) ;
      }

      // 删除元素，未被删除的元素个数-1
      bit.add(next, -1);
      // 删除prev，也是一步
      ans++;
      prev = next;
    }
    return ans;
  }
}

```
