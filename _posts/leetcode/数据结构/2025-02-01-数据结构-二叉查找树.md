## 定义
二叉查找树（Binary Search Tree, BST）是一种特殊的二叉树，又称为二叉排序树（Binary Sorted Tree）：

1. 若任意节点的左子树不空，则左子树上所有节点的值均小于它的根节点的值；
2. 若任意节点的右子树不空，则右子树上所有节点的值均大于它的根节点的值；
3. 任意节点的左、右子树也分别为二叉查找树；

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isValidBST(TreeNode root) {

      if (root == null) {
        return true;
      }
      return helper(root, null, null);
    }
    /**
    @param min root及其子树中所有结点都必须大于min
    @param max root及其子树中所有结点都必须小于max
     */
    private boolean helper(TreeNode root, Integer min, Integer max) {
      if (root == null) {
        return true;
      }
      // System.out.println("helper: " + root.val + "; min: " + min + "; max = "+max);
      int val = root.val;
      if(null != min) {
        if(val <= min) {
          return false;
        }
      }
      if(null != max) {
        if(val >= max) {
          return false;
        }
      }
      //左子树时，最小值为min，最大值为父结点的值：(min, root.val)
      boolean left = helper(root.left, min, root.val);
      //右子树时，最小值为父结点的值，最大值为max: (root.val, max)
      boolean right = helper(root.right, root.val, max);

      return left && right;
    }
}
```

时间复杂度O(n)；空间复杂度O(n)

### remove
删除指定结点t并使删除后仍保持查找树性质。

1. 结点t有左右两个子结点：用右子树中最小的值替代结点t，并删除右子树中最小值的结点
    1. 如果删除的右子树最小值结点是叶子结点：直接删除，不会影响右子树的查找树性质
    2. 如果删除的右子树最小值结点不是叶子结点，就需要递归的调用删除方法
2. 结点t只有左子结点：直接用左子树直接替代t
3. 结点t只有右子结点：直接用右子树替代即可
4. 结点t没有子结点：直接删除

```java
        return null;
```

```java
      return search(root, k);

        return null;

      int leftNodeCount = node.left != null ? node.left.count : 0;
      int rightNodeCount = node.right != null ? node.right.count : 0;
      // 向右寻找
      if (k <= rightNodeCount) {
        return search(node.right, k);
      } else if(k > node.count - leftNodeCount) {
         // 向左寻找
        return search(node.left, k - (node.count - leftNodeCount));
      } else  {
        return node;
      }
    }

      bst.add(nums[i]);
    }
  }

    bst.add(val);

  }
```

```java
      int cmp2 = q.val - rootVal;
```

## 平衡二叉树
非常好的资料：[https://time.geekbang.org/column/article/287289](https://time.geekbang.org/column/article/287289)

数据结构与算法分析-java描述：[https://users.cs.fiu.edu/~weiss/#dsaajava3](https://users.cs.fiu.edu/~weiss/#dsaajava3)

平衡树的左右两颗子树的树高之差不会超过1，因此整个树高就维持在$ log_2(N+1) $。

普通的二叉查找树无法保证树高为$ O(nlogn) $，则查找的时间复杂度无法保证到$ O(nlogn) $，能够高度为$ O(nlogn) $的二叉查找树被称为平衡查找树。

树的高度是根的节点到叶子节点最长的长度；

节点的深度是该节点到根的长度；

平衡二叉树是如何维持自身的树高的？

右旋操作：把二叉树的左孩子作为根进行的旋转操作。

左旋操作：把二叉树的右孩子作为根进行的旋转操作

平衡因子：右子树的高度减去左子树的高度。平衡树中，平衡因子只可能有三个值：

1. +1 ： 右子树的高度比左子树高1
2. -1:  右子树的高度比左子树低1
3. 0: 两边高度一致

### AVL
AVL（Adelson-Velskii和Landis）树是最早提出的自平衡二叉查找树。每个结点的左子树和右子树的高度最多差1的二叉查找树。

AVL树以「旋转」操作保证任意结点的左右子树高度差不超过1，使得树的深度总保持为$ O(logn) $，

#### 插入
插入一个结点x后，平衡被破坏的结点$ y_1,y_2,... $只可能在x到根结点的路径上，因此只需要沿着此路径恢复平衡，不难证明，只需要在第一个平衡被破坏的结点$ y $上重新平衡这颗树，即能保证整颗树恢复为AVL树。

破坏平衡的插入必然是下列四种情形之一：

1. （左-左）：插入点在y的左儿子的左子树；
2. （右-右）：插入点在y的右儿子的右子树；
3. （左-右）：插入点在y的左儿子的右子树；
4. （右-左）：插入点在y的右儿子的左子树；

其中，1、2只需通过**单旋转**恢复平衡，3、4需要通过**双旋转**恢复平衡。

##### 右单旋转：
如上图，X子树上插入了一个结点，导致k2为第一个平衡被破坏的结点，插入的结点表现为k2的右左儿子的左子树，故这种情形为「左-左」，则需要单旋转失衡的结点k2：

> k2.left = k1.right;
>
> k1.left = k2;
>

```java
private AvlNode<E> rotationWithLeftChild(AvlNode<E> k2) {
  AvlNode<E> k1 = k2.left;
  k2.left = k1.right;
  k1.right = k2;
  k2.height = Math.max(height(k2.left), height(k2.right));
  k1.height = Math.max(height(k1.left), height(k1.right));
  // 返回调整后的根结点
  return k1;
}
```

##### 左单旋转：
如上图，Z树上插入了一个结点，导致k1为第一个平衡被破坏的结点，插入的结点表现为k1的右儿子的右子树，故这种情形为「右-右」，则需要单旋转失衡的结点k1：

> K1.right = k2.left;
>
> k2.left = k1;
>

```java
private AvlNode<AnyType> rotateWithRightChild(AvlNode<AnyType> k1 )
{
  AvlNode<AnyType> k2 = k1.right;
  k1.right = k2.left;
  k2.left = k1;
  k1.height = Math.max( height( k1.left ), height( k1.right ) ) + 1;
  k2.height = Math.max( height( k2.right ), k1.height ) + 1;
```

##### [110. 平衡二叉树](https://leetcode.cn/problems/balanced-binary-tree/)
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isBalanced(TreeNode root) {
      // return balanced(root);
      return heightBalance(root) >= 0;
    }

    private boolean balanced(TreeNode root) {
      if(null == root) {
        return true;
      }
      return isBalanced(root.left) && isBalanced(root.right) && Math.abs(height(root.left) - height(root.right)) <= 1; 
    }
    /** 返回结点的高度*/
    private int height (TreeNode node) {
      if(node == null) {
        return -1;
      }
      int lh = height(node.left);
      int rh = height(node.right);
      return Math.max(lh, rh) + 1;
    }
    /** 平衡则返回「高度+1」，不平衡则返回-1；时间复杂度O(N)*/
    private int heightBalance(TreeNode node) {
      if(node == null) {
        return 0;
      }
      int lh = heightBalance(node.left);
      int rh = heightBalance(node.right);
      if(lh == -1 || rh == -1 || Math.abs(lh - rh) > 1) {
        return -1;
      }
      return Math.max(lh, rh) + 1;
       
    }
}
```

AVL树看起来已经完全满足平衡查找树了，但是AVL维护平衡的代价特别高，每次插入和删除都可能需要旋转平衡。对于有频繁写操作的数据集合，AVL的代价比较高。

近似平衡的红黑树（Red-Black Tree）就诞生了，工程应用上，红黑树在写和读操作上稳定的性能就合适。
