## 70. Climbing Stairs
`f[i]`表示爬到`i`级台阶的方案数，因为每次只能爬一步或者两步，所以爬到`i`级台阶的方案数由`i-1`和`i-2`的方案数决定，比如`f[3]`就是

1. 2级台阶的基础上爬一步
2. 1级台阶的基础上爬两步

所以`f(3) = f(1) + f(2)`，归纳为`f[i]= f[i-1] + f[i-2]`.

边界条件：因为0是起点，`f[0] = 1`；`f[1] = 1`.

```java
class Solution {
  public int climbStairs(int n) {
    /**
  dp[i] = dp[i-1] + dp[i-2] 0 <= j < i
  */
    if(n == 1) {
      return 1;
    }
    int[] dp = new int[n + 1];
    dp[0] = 1;
    dp[1] = 1;
    for(int i = 2; i <= n; i++) {
      dp[i] = dp[i-1] + dp[i-2];
    }

    return dp[n];
  }
  // 空间优化
  public int climbStairs(int n) {
    if(n == 1) {
      return 1;
    }
    int p = 1; 
    int q = 1;
    int r = 0;
    for(int i = 2; i <= n; i++) {
      r  = p + q;
      p = q;
      q = r;
    }
    return r;
  }
}
```

## [152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)
## [152. Maximum Product Subarray](https://leetcode.cn/problems/maximum-product-subarray/)
f(i)以i为结尾的最大乘积子数组。

$ max{f(i)} $

$ f(i)=max(f(i-1)*nums[i],nums[i]) $

很可惜，这个模型是错误的，因为遇到[-2, 2, -3]时，f(2)应该是12而不是-3.

考虑当前位置如果是一个负数的话，那么我们希望以它前一个位置结尾的某个段的积也是个负数，这样就可以负负得正，并且我们希望这个积尽可能「负得更多」，即尽可能小。如果当前位置是一个正数的话，我们更希望以它前一个位置结尾的某个段的积也是个正数，并且希望它尽可能地大。于是这里我们可以再维护一个`fmin(i)`，它表示以第 _i_ 个元素结尾的乘积最小子数组的乘积，那么我们可以得到这样的动态规划转移方程：

正确的模型为：

$ f_{max} = max_{}\{f_{max}{(i-1)}*nums[i], f_{min}{(i-1)}*nums[i], nums[i]\} \\
f_{min} = min_{}\{f_{max}{(i-1)}*nums[i], f_{min}{(i-1)}*nums[i], nums[i]\}  $

```java
class Solution {
  public int maxProduct(int[] nums) {

    int len = nums.length;
    int[] maxFun = new int[len];
    int[] minFun = new int[len];
    maxFun[0] = nums[0];
    minFun[0] = nums[0];

    for(int i = 1; i < len; i++) {
      maxFun[i] = Math.max(maxFun[i-1] * nums[i], Math.max( minFun[i-1]*nums[i], nums[i]));
      minFun[i] = Math.min(maxFun[i-1] * nums[i], Math.min(minFun[i-1]*nums[i], nums[i]));
    }
    int result = maxFun[0];
    for(int i = 1; i < len; i++) {
      result = Math.max(result, maxFun[i]);
    }

    return result;
  }
}
```

优化空间：

```java
class Solution {
  public int maxProduct(int[] nums) {

    int len = nums.length;

    int maxProduct = nums[0];
    int minProduct = nums[0];

    int res = maxProduct;
    int temp = 0;
    for(int i = 1; i < len; i++) {
      temp = maxProduct;
      maxProduct = Math.max(temp * nums[i], Math.max(minProduct * nums[i], nums[i]));
      minProduct = Math.min(temp * nums[i], Math.min(minProduct * nums[i], nums[i]));
      res = Math.max(res, maxProduct);
    }

    return res;
  }
}
```

## [1186. Maximum Subarray Sum with One Deletion](https://leetcode.cn/problems/maximum-subarray-sum-with-one-deletion/)
暴力：

```java
class Solution {
    public int maximumSum(int[] arr) {
      // f(i) = max(f(i-1), 0）+ arr[i]
      // delete i
      // f(i) = 
      int[] preSum = new int[arr.length + 1];
      for(int i = 0; i < arr.length; i++) {
        preSum[i + 1] = preSum[i] + arr[i];
      }
      int submax = Integer.MIN_VALUE;
      for(int i = 0; i < arr.length; i++) {
        for(int j = 0; j < i; j++) {
          // [j:i] sum
          int range = preSum[i + 1] - preSum[j]; 
          submax = Math.max(submax, range);
          for(int k = j; k <= i; k++) {
            submax = Math.max(submax, range - arr[k]);
          }
        }
      }
      return submax == Integer.MIN_VALUE ? arr[0] : submax;
    }
}
```

### 动态规划

枚举i：

`dp[i]` 表示选出了以i结尾的子数组。

1. `dp[i][0]`则为 没有选择删除一个元素的子数组的最大和，题目要求的是至多删除一个。
2. `dp[i][1]`则为 删除了这个子数组其中的一个元素后的最大和。

那最后的答案就是`max(dp[i][0], dp[i][1])`。

$ dp[i][0]=\max \begin {cases} 
dp[i-1][0] + arr[i] & \text 选i左边的子数组 \\
arr[i] & 不选i左边的子数组，只选i，因为左边的子数组贡献为负数 
\end{cases} $

$ dp[i][1]=\max \begin {cases} 
dp[i-1][0] & 选择删除i，数组不能为空，必须选择左侧的子数组 \\
dp[i-1][1] + arr[i] & 不选择删除i，那就是要选择左侧“以i-1结尾的子数组再删除一个元素”的子数组
\end{cases} $

实际上dp[i - 1][1]的可能有很多，可能是删除的i-1，也有可能不是删除i-1。但必须是最开始选出以i-1为结尾的子数组，这就说明可能是[j:i]的子数组，因为dp[j][0]可能只选择了arr[j]。这一点非常精妙，很难想到。

```java
class Solution {
  public int maximumSum(int[] arr) {

    // dp[i][0] [0:i] 选出以i结尾的子数组 然后没有删除一个元素的最大和
    // dp[i][1] [0:i] 选出以i结尾的子数组 然后删除一次元素后的最大和


    // dp[i][0] = max(dp[i-1][0] + arr[i], arr[i]); 选择不删除，不选i左边的数，因为左边的数的和是负贡献，选i左边的数
    // dp[i][1] = max(dp[i-1][0], dp[i - 1][1] + arr[i]); // 删除i，dp[i-1][0]; 不删除i，dp[i - 1][1] + arr[i]，dp[i - 1][1]有可能是删除i-1，也有可能不是删除i-1
    // [0 : i-1] 已删除过一次，dp[i - 1][1] + arr[i]

    // dp[1][0] = arr[0]
    // dp[1][1] = arr[0]
    if(arr.length == 1) {
      return arr[0];
    }
    int[][] dp = new int[arr.length][2];
    // 因为数组不能为空，所以dp[0][0] = arr[0]，但dp[0][1]其实是不存在的。dp[1][1]= max(dp[0][0], dp[0][1] + arr[1]) = max(arr[0], dp[0][1] + arr[1])，但如何设置dp[0][1]等于无穷小，遇到一个负数就很容易溢出，所以设置为arr[0] - arr[1] - 1
    dp[0][0] = arr[0];
    dp[0][1] = arr[0] - arr[1] - 1;
    int max = dp[0][0];
    for(int i = 1; i < arr.length; i++) {
      dp[i][0] = Math.max(dp[i - 1][0] + arr[i], arr[i]);
      dp[i][1] = Math.max(dp[i - 1][0], dp[i - 1][1] + arr[i]);
      max = Math.max(max, dp[i][0]);
      max = Math.max(max, dp[i][1]);
    }
    return max;

  }
}
```

## [823.带因子的二叉树](https://leetcode.cn/problems/binary-trees-with-factors/)  

```java
import java.math.BigInteger;
class Solution {
    public int numFactoredBinaryTrees(int[] arr) {
        // dp[i] := arr[i] 为root的二叉树的个数
        // dp[i] = sum(dp[l] * dp[r] * (l == r ? 1 : 2)) l < i, r < i
        int mod = (int) 1e9 + 7;
        Arrays.sort(arr);

        long[] dp = new long[arr.length];
        Arrays.fill(dp, 1);
        long ans = 0;
        for(int i = 0; i < arr.length; i++) {
            int l = 0;
            int r = i - 1;
            while(l <= r) {
                BigInteger mul = BigInteger.valueOf(arr[l]).multiply(BigInteger.valueOf(arr[r])) ;
                if(mul.compareTo(BigInteger.valueOf(arr[i])) < 0) {
                    l++;
                } else if(mul.compareTo(BigInteger.valueOf(arr[i])) > 0) {
                    r--;
                } else {
                    dp[i] = (dp[i] + dp[l] * dp[r] * (l == r ? 1 : 2)) % mod;
                    l++;
                    r--;
                }
            }
            // System.out.println(dp[i]);
            ans = (ans + dp[i]) % mod;
        }
        return (int) ans;
    }
}
```

```java
class Solution {
    int mod = (int) (1E9) + 7;
    Map<Integer, Long> dp;

    public int numFactoredBinaryTrees(int[] arr) {

        Map<Integer, Integer> map = new HashMap<>();
        Arrays.sort(arr);

        int n = arr.length;
        for (int i = 0; i < n; i++) {
            map.put(arr[i], i);
        }

        long ans = 0;
        dp = new HashMap<>();
        for (int i = 0; i < n; i++) {
            ans = (ans + dfs(i, map, arr)) % mod;
        }
        return (int)ans;
    }

    private Long dfs(int index, Map<Integer, Integer> map, int[] arr) {
        if (dp.containsKey(index)) {
            return dp.get(index);
        }

        long ans = 1;
        for (int i = index - 1; i >= 0; i--) {
            if (arr[index] % arr[i] != 0) {
                continue;
            }

            int t = arr[index] / arr[i];
            if (map.containsKey(t)) {
                ans = (ans + dfs(i, map, arr) * dfs(map.get(t), map, arr)) % mod;
            }
        }
        dp.put(index, ans);
        return ans;
    }  
}
```
