动态规划解决的是「有重叠子问题的最优（或可行性）问题」：把原问题拆成规模更小的同类子问题，子问题的答案只算一次、存起来复用。

写法上有两种，本质是同一张表：

- **记忆化搜索（自顶向下）**：先按 DFS 的思路把递归写出来，再加一个 `memo` 数组把算过的状态缓存下来。好处是状态转移就是递归调用本身，不用考虑遍历顺序。
- **递推（自底向上）**：把递归改成循环，从边界状态往目标状态推。省掉了递归栈，常数更小，但要自己想清楚填表顺序。

设计一个状态的三步：**状态定义 → 状态转移 → 边界**。状态定义里出现的所有变量就是 `memo` 的维度，时间复杂度约等于「状态数 × 单个状态的转移代价」。

> Dynamic programming = recursion + memoization. Define the state, write the transition,
> handle the base case; the number of states times the cost per transition is the runtime.

## Leetcode
### [678. 有效的括号字符串](https://leetcode.cn/problems/valid-parenthesis-string/)
题目：给定一个只包含 `(`、`)`、`*` 的字符串，`*` 可以被当作 `(`、`)` 或者空字符串，判断这个字符串是否是有效的括号字符串。

#### 记忆化搜索
比[20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)（见「数据结构 · 栈」一篇）多了一个 `*`，它有三种解释，所以没法像 20 题那样一遍扫描就得到答案，需要把三种可能都试一遍——这就是 DFS。

而 DFS 会重复计算：`(*)*(` 这种输入里，不同的 `*` 组合会走到「同一个下标、同一个未匹配左括号数量」的状态上，答案自然是一样的，所以加 `memo` 缓存。

- **状态定义**：`dfs(index, remainingLeftBracket)` 表示前面已经处理完 `[0, index)`，还剩 `remainingLeftBracket` 个左括号没有被匹配时，剩下的后缀能否让整个串合法。
- **状态转移**：
  - `s[index] == '('`：只能让计数加一，`dfs(index + 1, remaining + 1)`；
  - `s[index] == ')'`：只能让计数减一，`dfs(index + 1, remaining - 1)`；
  - `s[index] == '*'`：三种解释取或，`dfs(index + 1, remaining)`（空串）、`dfs(index + 1, remaining - 1)`（当右括号）、`dfs(index + 1, remaining + 1)`（当左括号），只要有一种可行就可行。
- **边界**：`remaining < 0` 说明右括号多了，提前剪枝返回 false；走到 `index == s.length()` 时，当且仅当 `remaining == 0` 才是合法的。

注意计数是「未匹配的左括号数量」，它天然保证了匹配的顺序性：右括号只有在前面还有左括号（`remaining > 0`）时才不会让计数变负，所以不需要额外记录括号的位置。

```java
class Solution {
  private Boolean[][] memo;

  public boolean checkValidString(String s) {
    int len = s.length();
    // remainingLeftBracket 最多是 len，所以两维都开 len + 1
    memo = new Boolean[len + 1][len + 1];
    return dfs(s, 0, 0);
  }

  private boolean dfs(String s, int index, int remainingLeftBracket) {
    // 右括号比左括号多，剪枝
    if(remainingLeftBracket < 0) {
      return false;
    }
    // 扫描结束，左括号全部匹配上了才算合法
    if(index == s.length()) {
      return remainingLeftBracket == 0;
    }

    if(memo[index][remainingLeftBracket] != null) {
      return memo[index][remainingLeftBracket];
    }

    char ch = s.charAt(index);
    if(ch == '(') {
      memo[index][remainingLeftBracket] = dfs(s, index + 1, remainingLeftBracket + 1);
    } else if(ch == ')') {
      memo[index][remainingLeftBracket] = dfs(s, index + 1, remainingLeftBracket - 1);
    } else {
      // '*' 三种解释：空串、右括号、左括号
      memo[index][remainingLeftBracket] = dfs(s, index + 1, remainingLeftBracket) ||
          dfs(s, index + 1, remainingLeftBracket - 1) ||
          dfs(s, index + 1, remainingLeftBracket + 1);
    }
    return memo[index][remainingLeftBracket];
  }
}
```

状态数是 O(N²)，每个状态最多三个分支，所以时间复杂度 O(N²)，空间复杂度 O(N²)。

#### 递推
把记忆化搜索翻过来写：`dp[i][j]` 表示前 `i` 个字符处理完之后，未匹配左括号数量为 `j` 是否可达。边界是 `dp[0][0] = true`，最后看 `dp[n][0]`。

```java
class Solution {
  public boolean checkValidString(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n + 1][n + 1];
    dp[0][0] = true;
    for(int i = 1; i <= n; i++) {
      char ch = s.charAt(i - 1);
      for(int j = 0; j <= n; j++) {
        if(ch == '(') {
          dp[i][j] = j > 0 && dp[i - 1][j - 1];
        } else if(ch == ')') {
          dp[i][j] = j < n && dp[i - 1][j + 1];
        } else {
          dp[i][j] = dp[i - 1][j] || (j > 0 && dp[i - 1][j - 1]) || (j < n && dp[i - 1][j + 1]);
        }
      }
    }
    return dp[n][0];
  }
}
```

第 `i` 行只依赖第 `i - 1` 行，用滚动数组可以把空间压到 O(N)。

#### 贪心：维护未匹配左括号的区间
DP 记录的是「所有可达的 `remaining` 值」，而观察一下会发现，这些可达值构成的集合始终是一个**连续区间**——每一步要么整体 +1，要么整体 -1，要么向两边各扩一格。既然是连续的，就不用存整张表，只维护区间的下界 `lo` 和上界 `hi` 就够了。

- `(`：`lo++`、`hi++`；
- `)`：`lo--`、`hi--`；
- `*`：`lo--`、`hi++`（最少当右括号，最多当左括号）。

`hi < 0` 意味着即使把所有 `*` 都当成左括号，右括号也多了，直接返回 false；`lo < 0` 时把它归零，因为未匹配的左括号数量不可能是负数——负的部分对应「`*` 当右括号当多了」的那些无效选择，丢掉即可。最后 `lo == 0` 说明存在一种解释让左括号全部匹配上。

```java
class Solution {
  public boolean checkValidString(String s) {
    // 未匹配左括号数量的可能取值区间 [lo, hi]
    int lo = 0, hi = 0;
    for(char ch : s.toCharArray()) {
      if(ch == '(') {
        lo++;
        hi++;
      } else if(ch == ')') {
        lo--;
        hi--;
      } else {
        lo--;
        hi++;
      }
      if(hi < 0) {
        return false;
      }
      lo = Math.max(lo, 0);
    }
    return lo == 0;
  }
}
```

时间复杂度 O(N)，空间复杂度 O(1)。

#### 双栈
另一种 O(N) 的写法，思路更接近 20 题：用两个栈分别存左括号和 `*` 的**下标**。

遇到 `)` 时优先消耗左括号，没有左括号就拿一个 `*` 当左括号用，两个栈都空就返回 false。扫描结束后，剩下的左括号只能靠剩下的 `*` 来配，而 `*` 必须出现在左括号右边才能当右括号用，所以要比较下标：如果栈顶的左括号下标比 `*` 的下标还大，说明配不上。

```java
class Solution {
  public boolean checkValidString(String s) {
    Deque<Integer> leftStack = new ArrayDeque<>();
    Deque<Integer> starStack = new ArrayDeque<>();
    for(int i = 0; i < s.length(); i++) {
      char ch = s.charAt(i);
      if(ch == '(') {
        leftStack.push(i);
      } else if(ch == '*') {
        starStack.push(i);
      } else {
        if(!leftStack.isEmpty()) {
          leftStack.pop();
        } else if(!starStack.isEmpty()) {
          starStack.pop();
        } else {
          return false;
        }
      }
    }
    // 剩下的左括号用 '*' 当右括号来匹配，'*' 必须在左括号的右边
    while(!leftStack.isEmpty() && !starStack.isEmpty()) {
      if(leftStack.pop() > starStack.pop()) {
        return false;
      }
    }
    return leftStack.isEmpty();
  }
}
```

> **678. Valid Parenthesis String** — `*` has three meanings, so a single scan is not enough.
> Memoize the DFS state `(index, unmatched '(' count)` for an O(N²) DP, or notice that the set
> of reachable counts is always a contiguous range and just track its bounds `[lo, hi]` for an
> O(N) / O(1) greedy solution. A two-stack variant (indices of `(` and `*`) also runs in O(N).
