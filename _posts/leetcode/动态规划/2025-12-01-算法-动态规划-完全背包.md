## 题意理解
unbound knapsack promblem

1. 01背包
    1. 有`n`个物品和一个容量为`w`的背包，每个物品有重量`w[i]`和价值`v[i]`两种属性，在背包容量为c的条件下，从中选出一些物品，限定每个物品最多只能选取0次或者1次，使得这些物品的价值和最大。
    2. 转移方程：`dfs(i, c) = max(dfs(i - 1, c), dfs(i - 1, c - w[i]) + v[i])`
2. 完全背包：
    1. 有`n`个物品和一个容量为`w`的背包，每个物品有重量`w[i]`和价值`v[i]`两种属性，在背包容量为c的条件下，从中选出一些物品，每个物品能选取无数次，使得这些物品的价值和最大。
    2. 转移方程：`dfs(i, c) = max(dfs(i - 1, c), dfs(i, c - w[i]) + v[i])`

完全背包与01背包的区别是，每种物品可以无限次重复选。

## 暴力回溯
先使用回溯的方法来做，回溯三问：

1. 当前操作：第i个物品选或者不选。选，剩余容量减少w[i]，价值增加v[i]；不选： 剩余容量不变
2. 子问题定义：dfs(i, c) := 表示w的下标[0:i]的区间的所有物品中，在剩余容量为c的条件下，从它们中选出一些物品，这些物品的最大的价值和。
3. 下一个子问题：
    1. 不选第i个物品，dfs(i, c) = dfs(i-1,c)
        1. 下标[0:i]的区间 就等价于下标[0:i-1]区间 的最大价值和。
    2. 选第i个物品：
        1. 剩余容量不够时，w[i] > c，dfs(i, c) = dfs(i-1, c)
        2. 剩余容量够时，w[i] <= c，dfs(i, c) = dfs(i, c-w[i]) + v[i]
            1. 最大价值和就等于 剩余容量为c-w[i]时，从下标[0 : i]区间 得到的最大价值和 加上物品i的价值。 

选第i个物品后的最大价值和必然是在选和不选之间 选取一个最大值，注意选择物品i不一定是最好的，因为：

> 在w[i] <= c的场景下：
>
> 1. dfs(i - 1, c) > dfs(i, c-w[i]) + v[i]: 选了i这个物品，可能是体积大但价值特别低，比如无穷小
> 2. dfs(i - 1, c) < dfs(i, c-w[i]) + v[i]：选了i这个物品，这个物品价值特别大，比如无穷大，那肯定选了价值更大
>

所以整合起来就是

1. `w[i] > c : dfs(i, c) = dfs(i-1, c)`
2. `w[i] <= c : dfs(i, c) = max(dfs(i-1, c), dfs(i, c-w[i]) + v[i])`

$$ dfs(i, c) = max(dfs(i-1,c), dfs(i, c-w[i]) + v[i]) $$

## [279. Perfect Squares](https://leetcode.cn/problems/perfect-squares/)
```java
class Solution {
  public int numSquares(int n) {
    /**
        squares = [1, 4, 9, 16, ...]
        等价于完全背包问题，容量为n，物品体积为squares = [1, 4, 9, 16, ...] 价值为 v = [1, 1, 1 ,1, ...]
        求恰好装n时的最小价值和

        dp[i + 1][j] := 从squares[0:i]中选出一些数，使其等于j，求这些数的最少数量
        
        1. not choose i: dp[i + 1][j] = dp[i][j]
        2. choose i, squares[i] <= j, dp[i + 1][j] = dp[i + 1][j - squares[i]] + 1

        if(squares[i] > j) {
          dp[i + 1][j] = dp[i][j];
        } else {
          dp[i + 1][j] = Math.min(dp[i][j], dp[i + 1][j - squares[i]] + 1);
        }

      squares = [1, 4, 9], n = 12

        edge : 
      1. dp[0][0] = 0;
      2. dp[0][j != 0] = inf, 空集中无法选出等于和等于j的数，inf代表不可能

        i\j 0   1    2    3  ...
        0   0   inf  inf  inf
        1   0   1    2

      dp[1][0] = 0; 
      dp[1][1] = 1 = min(dp[0][1], dp[1][0] + 1) 
      dp[1][2] = min(dp[0][2], dp[1][2-1] + 1) = 2

        return dp[len(squares)][n];
       */
    int[] squares = new int[(int) Math.sqrt(n)];
    for(int i = 1; i * i <= n; i++) {
      squares[i - 1] = i * i;
    }
    int len = squares.length;
    int[][] dp = new int[len + 1][n + 1];
    Arrays.fill(dp[0], Integer.MAX_VALUE / 2);
    dp[0][0] = 0;
    for(int i = 0; i < len; i++) {
      for(int j = 0; j <= n; j++) {
        if(squares[i] > j) {
          dp[i + 1][j] = dp[i][j];
        } else {
          dp[i + 1][j] = Math.min(dp[i][j], dp[i + 1][j - squares[i]] + 1);
        }
      }
    }
    return dp[len][n];
  }
}
```

```java
class Solution {
    public int numSquares(int n) {
      // 等价于完全背包问题，容量为n，物品体积为w [1, 4, 9, 16, ...] 价值为 v = [1, 1, 1 ,1, ...]
      // 求恰好装n时的最小价值和
      // dp[i][c] = min(dp[i-1][c], dp[i][c-w[i]] + 1)
      int m = (int) Math.sqrt(n);

       // w = [1, 4, 9]
      int[] w = new int[m];
      for(int i = 1; i <= m; i++) {
        w[i - 1] = i * i;
      }
     
      // dp[i][c] = min(dp[i-1][c], dp[i][c-w[i]] + 1)
      // dp[c] = min(dp[c], dp[c - w[i]] + 1)
      int[] dp = new int[n + 1];
      // 空集合中dp 空集合无法组成任何数，这里取一个取不到的极大值
      Arrays.fill(dp, n + 10);
      // 不选价值则为0
      dp[0] = 0;

      for(int i = 0; i < w.length; i++) {
        // 01背包是倒序，完全背包是正序
        for(int c = 0; c <= n; c++) {
          dp[c] = dp[c];
          if(w[i] <= c) {
            dp[c] = Math.min(dp[c], dp[c-w[i]] + 1);
          }
        }
      }
      return dp[n];
    }
}
```

## [322. Coin Change](https://leetcode.cn/problems/coin-change/)
回溯：

```java
class Solution {
    private static final int INF = Integer.MAX_VALUE;
    public int coinChange(int[] coins, int amount) {

        // 每一个硬币都可以选择多次，但是amount是固定了的，每选一次硬币，amount就少一次，也就是组合的次数是基于amount来定的
        // 如果我们能尝试性的选择每种硬币，就可以知道遍历所有的组合

        // dfs(i, c) := 前i个coin中选取一些coin，在总金额为c的情况下，能凑齐的最少硬币个数

        // 1. 不选i，dfs(i, c) = dfs(i - 1, c)
        // 2. 选i and coins[i] > c, dfs(i, c) = dfs(i - 1, c);
        //    选i and coins[i] <= c， dfs(i, c) = dfs(i, c - coins[i]) + 1
        
        // edge: dfs(-1, c != 0) = -1; dfs(-1, 0) = 0; dfs(i, c < 0) = 0;
        // return dfs(n - 1, amount);
        int n = coins.length;
        int[][] memo = new int[n][amount + 1];
        for(int[] item : memo) {
            Arrays.fill(item, INF);
        }
        return dfs(coins, n - 1, amount, memo);

    }
    private int dfs(int[] coins, int i, int amount, int[][] memo) {
        if (i == -1) {
            return amount == 0 ? 0 : -1;
        }
        if(memo[i][amount] != INF) {
            return memo[i][amount];
        }
        // 不选i
        int ans1 = dfs(coins, i - 1, amount, memo);          
        int ans2 = -1;
        // 选i
        if (coins[i] <= amount) {
            ans2 = dfs(coins, i, amount - coins[i], memo);
            if (ans2 != -1) {
                ans2 = ans2 + 1;
            }
        }
        if(ans1 != -1 && ans2 != -1) {
            return memo[i][amount] = Math.min(ans1, ans2);
        }

       return memo[i][amount] = (ans1 == -1 ? ans2 : ans1);
    }
}
```

```java
class Solution {
  public int coinChange(int[] coins, int amount) {
/*
    // 完全背包问题：刚好装amount，求其最小化个数
    // w = [1, 2, 5], v = [1, 1, 1]
    // dp[i + 1][c] := 前i个选，刚好amount等于j的最小个数
    // 第i个不选，dp[i + 1][c] = dp[i][c]
    // 第i个选，if(w[i] > c) -> dp[i + 1][c] = dp[i][c] 
           if(w[i] <= c) -> dp[i + 1][c] = min(dp[i][c], dp[i + 1][c - w[i]] + 1)
            
        coins = [2], amount = 3
        i\c 0   1    2    3 
        0   0  inf  inf inf
        1   0  inf  1   inf 
    // 边界条件：
    // 1. dp[0][c>0] 表示从空集合中无法选出任何硬币组成金额c>0, 设置为一个不可能取到的极大值，这里可以取amount+1，因为最小的面值为1，最多为amount个
    // 2. dp[0][0] = 0; 从空集合中不选任何硬币也可以得到0，方案为0
*/ 
    int[][] dp = new int[coins.length + 1][amount + 1];
    Arrays.fill(dp[0], amount + 1);
    dp[0][0] = 0;

    for(int i = 0; i < coins.length; i++) {
      for(int c = 0; c <= amount; c++) {
        if(coins[i] > c) {
          dp[i + 1][c] = dp[i][c]; 
        } else {
          dp[i + 1][c] = Math.min(dp[i][c], dp[i + 1][c - coins[i]] + 1);
          // dp[1][2] = min(dp[0][2], dp[1][2-2] + 1) = min(,1)
        }
      }
    }
    return dp[coins.length][amount] == amount + 1 ? -1 : dp[coins.length][amount];
  }
}
```
