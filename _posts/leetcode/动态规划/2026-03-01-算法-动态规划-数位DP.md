```java
public class Solution {
  private void dfs(int pos, int f) {
    if(dp[pos][f] != -1) {
      return dp[pos][f];
    }
    if(pos == 0) {
      return check(f);
    }
    int sum = 0;
    for(int i = 0; i <= 9; i++) {
      sum += dfs(pos - 1, change(f, i));
    }
    return dp[pos][f] = sum;
  }

} 
```

数位是指把一个数字按照个、十、百、千等等一位一位地拆开，关注它每一位上的数字。如果拆的是十进制数，那么每一位数字都是 0~9，其他进制可类比十进制。

数位 DP：用来解决一类特定问题，这种问题比较好辨认，一般具有这几个特征：

1. 要求统计满足一定条件的数的数量（即，最终目的为计数）；
2. 这些条件经过转化后可以使用「数位」的思想去理解和判断；
3. 输入会提供一个数字区间（有时也只提供上界）来作为统计的限制；
4. 上界很大（比如 10^{18}），暴力枚举验证会超时。

考虑人类计数的方式，最朴素的计数就是从小到大开始依次加一。但我们发现对于位数比较多的数，这样的过程中有许多重复的部分。例如，从 7000 数到 7999、从 8000 数到 8999、和从 9000 数到 9999 的过程非常相似，它们都是后三位从 000 变到 999，不一样的地方只有千位这一位，所以我们可以把这些过程归并起来，将这些过程中产生的计数答案也都存在一个通用的数组里。此数组根据题目具体要求设置状态，用递推或 DP 的方式进行状态转移。

数位 DP 中通常会利用常规计数问题技巧，比如把一个区间内的答案拆成两部分相减。

#### [233. 数字 1 的个数](https://leetcode.cn/problems/number-of-digit-one/)
数位DP的本质是对数进行`按位遍历`，比如求解 小于等于n的所有数中，数字1出现的个数。

比如13，1、10、11、12、13出现了6次1。

如果暴力求解，那就需要对1-n中的所有数进行一个计算，但实际上是不必要的。因为20-30和30-40的数有相同的特征，没必要都去计算一遍。

`按位遍历`的好处就是拆分到位，尽可能的根据数据特征进行复用。

自顶向下递归。第0位可以看作根结点，可以看作一颗树，来进行深度优先搜索，那就可以定义返回值，来做记忆化搜索，那就可以动态规划。

```java
package com.example.demo.leetcode;

import java.util.Arrays;

public class LC233 {
  public static void main(String[] args) {

    int res = countDigitOne(101);
    System.out.println(res);

  }

  public static int countDigitOne(int n) {

    String nStr = String.valueOf(n);
    int[] digits = new int[nStr.length()];
    for(int i = 0; i <nStr.length(); i++) {
      digits[i] = nStr.charAt(i) - '0';
    }

    int[][] dp = new int[digits.length][10];
    for(int i = 0; i < digits.length; i++) {
      Arrays.fill(dp[i], -1);
    }
    return dfs(0, 0, true, digits, dp);
  }

  /**
    dfs(bit, oneCnt)其实是自顶向下递归求解的，所以其返回值是从根结点 和 bit位下的所有子节点 构成的1的个数。
    从第0位（根结点）到第bit位的1的个数就是oneCnt，相当于从第0位到第bit位，不管其实是什么，只要看这其中有多少个1，就可以进行复用。就相当于记忆化搜索了，那自然可以用dp。
    * oneCnt其实是从第0位到bit位的路径上已经有的1的个数
	* */
  private static int dfs(int bit, int oneCnt, boolean isLimit, int[] digits, int[][] dp) {

    // 结束条件
    // 前文说过，结束时就表示一条完整的路径，即一个 <= n 的数字，而 ontCnt 则表示该数字中 1 的个数
    // 所以直接返回 oneCnt 即可！！

    if (bit == digits.length) {
      return oneCnt;
    }
    if (!isLimit && dp[bit][oneCnt] != -1) {
      return dp[bit][oneCnt];
    }
    int up = isLimit ? digits[bit] : 9;
    int res = 0;
    for (int d = 0; d <= up; d++) {
      res += dfs(bit + 1, oneCnt + (d == 1 ? 1 : 0), isLimit && d == up, digits, dp);
    }
    if (!isLimit) {
      dp[bit][oneCnt] = res;
    }
    //        System.out.println(bit + " " +  oneCnt + " " +res);
    return res;
  }

}
```

#### [1012. 至少有 1 位重复的数字](https://leetcode.cn/problems/numbers-with-repeated-digits/)

```java
class Solution {
  int[][] dp;

  public int numDupDigitsAtMostN(int n) {
    String sn = String.valueOf(n);
    dp = new int[sn.length()][1 << 10];
    for (int i = 0; i < sn.length(); i++) {
      Arrays.fill(dp[i], -1);
    }
    return n + 1 - f(0, sn, 0, true);
  }

  // same 表示是否限制了吧
  // i 第i位
  public int f(int mask, String sn, int i, boolean same) {
    if (i == sn.length()) {
      return 1;
    }
    if (!same && dp[i][mask] >= 0) {
      return dp[i][mask];
    }
    int res = 0;
    int t = same ? (sn.charAt(i) - '0') : 9;
    for (int k = 0; k <= t; k++) {
      // 如果k位已经是选择过
      if ((mask & (1 << k)) != 0) {
        continue;
      }
      // k位没有选择过， mask | (1 << k) 选择k位
      // mask == 0 && k == 0 说明前缀都是0
      res += f(mask == 0 && k == 0 ? mask : mask | (1 << k), sn, i + 1, same && k == t);
    }
    if (!same) {
      dp[i][mask] = res;
    }
    return res;
  }
}
```

```java
private char[] s;
private int[][] memo;
public int numDupDigitsAtMostN(int n) {
    s = Integer.toString(n).toCharArray();
    int m = s.length;
    memo = new int[m][1 << 10];
    for (int i = 0; i < m; i++) Arrays.fill(memo[i], -1);
    // 结果取反
    return n - f(0, 0, true, false);
}

/*
@param isNum 表示前面已经有选择过数字，防止00001这样的非法数字存在
 */
// 表示没有重复的字数的个数，最后 n - f() 即可
// mask 大小为 1024，长度为 10 位，记录 0 - 9 选择的情况，若 i 已选择，则 mask 中第 i 位为 1
private int f(int i, int mask, boolean isLimit, boolean isNum) {
    // 结束条件：如果 isNum 为 false，表示一直没有选择，直接返回 0；否则返回 1
    // 如果到结束条件时，isNum 仍为 false，还有一种表示含义，即表示 0
    if (i == s.length) {
      return isNum ? 1 : 0;
    }
    // isNum 同 isLimit，需要特判一下
    if (!isLimit && isNum && memo[i][mask] != -1) {
      return memo[i][mask];
    }
    // 下界
    int down = isNum ? 0 : 1;
    int up = isLimit ? s[i] - '0' : 9;
    // f(i + 1, mask, false, false) 表示仍然不选择
    int res = isNum ? 0 : f(i + 1, mask, false, false);
    for (int d = down; d <= up; d++) {
        // 检查当前数字d是否再mask中出现过，即判断mask的第d位是否为1
        if (((mask >> d) & 1) == 0) {
            // mask | (1 << d) 表示将mask的d位置为1
            res += f(i + 1, mask | (1 << d), isLimit && d == up, true);
        }
    }
    if (!isLimit && isNum) {
      memo[i][mask] = res;
    }
    return res;
}
```
