## 拓扑排序
拓扑排序 (Topological Sorting) 是针对于有向无环图(DAG, Directed Acyclic Graph)的一种算法，它是对图中所有顶点按照先后顺序的一种线性排序。意思就是说如果图中的两个顶点u和v，想到达到v，必须先到达u，那么在拓扑排序中，u必须在v的前面。

> 更准确地，拓扑排序是对图的一种遍历，在这种遍历中，对一个顶点 v 的访问只发生在它所依赖的顶点被访问之后。
>

要理解拓扑排序，还需要搞清楚入度和初度的概念，某个顶点的「入度」为指向该顶点的边的数量，「出度」为该顶点指向其他顶点的边的数量。

1. 拓扑排序的起点必须是入度为0的顶点，也就是图中至少有一个顶点没有前置顶点；
2. 如果图中的所有的顶点的入度都大于0，就意味着所有顶点都至少有一个前置顶点，那么就没有顶点作为拓扑排序的起点。

拓扑排序的主要实现为基于 BFS 的 **Kahn算法** 以及基于 DFS的 **Tarjan拓扑排序算法**。

### kahn算法：
kahn算法的优势就是能实现线性时间的复杂度计算。

算法过程：

1. 构建邻接表graph；
2. 计算所有顶点的入度indegree，然后将入度为 0 的顶点放入队列中；
3. 开始BFS遍历： 
    1. 每poll出一个当前顶点，加入到拓扑排序topSort中；
    2. 找出当前顶点的邻接顶点，入度减1；
    3. 遍历邻接顶点，如果发现有入度为0的，就加入队列。因为入度为0时说明所有指向该顶点的顶点都已经被标记了
4. bfs遍历完后，判断入度是否存在不为0的，有不为0的则说明图中有环；全部为0则输出拓扑排序。

时间复杂度O(V+E)

V表示顶点数，E表示边数

空间复杂度O(V+E)

#### [207. 课程表](https://leetcode.cn/problems/course-schedule/)
```java
class Solution {
  public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for(int i = 0; i < numCourses; i++) {
      graph.add(new ArrayList<>());
    }
    int[] indegree = new int[numCourses];
    for(int[] prerequisite : prerequisites) {
      int u = prerequisite[1];
      int v = prerequisite[0];
      graph.get(u).add(v);
      indegree[v]++;
    }
    Deque<Integer> queue = new ArrayDeque<>();
    for(int i = 0; i < indegree.length; i++) {
      if(indegree[i] == 0) {
        queue.offer(i);
      }
    }

    while(!queue.isEmpty()) {
      int u = queue.poll();
      for(Integer v : graph.get(u)) {
        indegree[v]--;
        if(indegree[v] == 0) {
          queue.offer(v);
        }
      }
    }

    for(int i = 0; i < indegree.length; i++) {
      if(indegree[i] != 0) {
        return false;
      }
    }
    return true;
  }
}
```

class Solution {
  public int[] findOrder(int numCourses, int[][] prerequisites) {

    // 1. build graph and indegree
    List<List<Integer>> graph = new ArrayList<>();
    for(int i = 0; i < numCourses; i++) {
      graph.add(new ArrayList<>());
    }
    int[] indegree = new int[numCourses];
    for(int[] prerequisite : prerequisites) {
      int u = prerequisite[1];
      int v = prerequisite[0];
      graph.get(u).add(v);
      indegree[v]++;
    }

    // 2. enqueue
    Deque<Integer> queue = new ArrayDeque<>();
    for(int i = 0; i < indegree.length; i++) {
      if(indegree[i] == 0) {
        queue.offer(i);
      }
    }
    // 3. kahn bfs
    int[] topSort = new int[numCourses];
    int visited = 0;
    int index = 0;
    while(!queue.isEmpty()) {
      int size = queue.size();
      for(int i = 0; i < size; i++) {
        int u = queue.poll();
        visited++;
        topSort[index++] = u;
        for(int v : graph.get(u)) {
          indegree[v]--;
          if(indegree[v] == 0) {
            queue.offer(v);
          }
        }
      }
    }
    // // 检测环还可以判断入度，如果还存在入度不为0点点，说明有环
    // for(int degree : indegree) {
    //     if(degree != 0) {
    //         return new int[0];
    //     }
    // }
    
    if(visited != numCourses) {
      // return new int[0];
      return new int[]{};
    }

    return topSort;
  }
  private void display(int[] array) {
    for(int arr : array) {
      System.out.println(arr);
    }
  }
}

#### [2603. 收集树中金币](https://leetcode.cn/problems/collect-coins-in-a-tree/)
拓扑排序不仅可以利用入度找依赖关系，还能还可以利用入度用来剪枝，做逻辑删除。

<!-- 这是一张图片，ocr 内容为：(A) (B) (E) (D) -->
![](https://cdn.nlark.com/yuque/0/2023/png/32473878/1683184694249-f60c96bd-fed9-4c31-8d2c-7deaaea05f1e.png)

首先，这是一棵树，不会出现环。

1. 没有金币的叶子结点，也就是图B中的蓝色结点，是不需要访问的，删除掉，留下所有的叶子结点都是含金币的；
2. 删除完后所有的叶子结点都是有金币的。有金币的叶子结点也是不需要访问的，因为我们可以在距离为2的地方采集到，所以删除掉。
3. 最后再把最外层的叶子结点都删除掉，因为我们可以在距离为1的地方采集到，剩下的就是必须要访问的了。

如何会用到拓扑排序呢？

首先建图和建「入度」数组，结点删除与否看入度是否为0。

第一步删除所有的不含金币的叶子结点，就可以利用拓扑排序，先将最外层的叶子结点入队，然后遍历邻接点减少邻接点的入度，继续看邻接点是否成为了新的叶子结点且不含金币。

第二步删除所有含金币的叶子结点。含金币的叶子结点入队然后邻接点入度减1；

第三步删除外层结点，即所有入度为1的结点的入度变为0。

因为是一棵树，所以最后剩下的结点N与剩下的边数E的关系是`(V-1)*2=E`

```java
class Solution {
  // 1. 删除所有不含金币的叶子结点
  // 2. 删除所有含金币的叶子结点
  // 3. 删除外层的所有叶子结点
  public static int collectTheCoins(int[] coins, int[][] edges) {
    int len = coins.length;

    // 构建图和入度
    int[] inDegree = new int[len];
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < len; i++) {
      graph.add(new ArrayList<>());
    }
    for(int[] edge : edges) {
      int u = edge[0];
      int v = edge[1];
      graph.get(u).add(v);
      graph.get(v).add(u);
      // 无向图，入度默认为1
      inDegree[u]++;
      inDegree[v]++;
    }

    // 无金币叶子入队
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < len; i++) {
      if (inDegree[i] == 1 && coins[i] == 0) {
        queue.add(i);
      }
    }

    // 1. 删除所有不含金币的叶子结点
    // 不含金币的叶子结点入度为0. 用拓扑排序「剪枝」：去掉没有金币的子树，即对应的入度为0
    while (!queue.isEmpty()) {
      int u = queue.poll();
      // u的邻接结点
      for (int v : graph.get(u)) {
        // 去掉无金币叶子结点，其相邻结点的入度自然也减1
        // 入度为0 且 coins[v] == 0实际上就是标记为删除了
        inDegree[v] = inDegree[v] - 1;
        // 如果这些结点成为了新的叶子结点，且无金币，继续加入队列
        if (inDegree[v] == 1 && coins[v] == 0) {
          queue.add(v);
        }
      }
    }

    // 2. 删除所有含金币的叶子结点
    for (int i = 0; i < len; ++i) {
      // 有金币的叶子加入队列
      if (inDegree[i] == 1 && coins[i] == 1) {
        queue.add(i);
      }
    }
    while(!queue.isEmpty()) {
      int u = queue.poll();
      for(int v : graph.get(u)) {
        inDegree[v] = inDegree[v] - 1;
      }
    }

    // 3. 删除外层的所有叶子结点
    for(int i = 0; i < inDegree.length; i++) {
      if(inDegree[i] == 1) {
        inDegree[i] = 0;
      }
    }

    // 因为剩下的是树，所以剩下的结点一定有（结点个数 - 1)* 2 条边，也就是最后的答案
    int res = 0;
    for(int i = 0; i < inDegree.length; i++) {
      if(inDegree[i] != 0) {
        res++;
      }
    }

    return res == 0 ? 0 : (res - 1) * 2;
  }
}
```

### Tarjan拓扑排序算法
Tarjan发明的算法非常多，这里说的实际上是指「强连通分量」算法。

```java
class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {

        // 1. build graph and indegree
        List<List<Integer>> graph = new ArrayList<>();
        for(int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        for(int[] prerequisite : prerequisites) {
            int u = prerequisite[1];
            int v = prerequisite[0];
            graph.get(u).add(v);
        }

        // tarjan dfs
        Deque<Integer> stack = new ArrayDeque<>();
        // 0 代表未访问； 1: 代表访问中；2:代表已访问
        int[] visited = new int[numCourses];
        for(int u = 0; u < numCourses; u++) {
            if(dfs(graph, u, visited, stack)) {
                return new int[]{};
            }
        }
        // dfs是先压入后继课程的，需要出栈的顺序才是拓扑排序
        int[] res = new int[numCourses];
        for(int i = 0; i < numCourses; i++) {
            res[i] = stack.pop();
        }
        return res;
     
    }
    // 是否有环
    private boolean dfs(List<List<Integer>> graph, int u, int[] visited, Deque<Integer> stack) {
        // 如果之前已经访问过，再次访问说明存在环
        if(visited[u] == 1) {
            return true;
        }
        if(visited[u] == 2) {
            // 这个结点已经访问过，没有环
            return false;
        }
        // 标记为访问中
        visited[u] = 1;
        for(int v : graph.get(u)) {
            if(dfs(graph, v, visited, stack)) {
                return true;
            }
        }
        // 完成搜索，表明在对u进行dfs的过程中未遇到正在搜索中的其他顶点
        visited[u] = 2;
        // 此时u所以来的顶点都在栈中「缓存」等待后续处理，因此可以将其放入此时结果栈的底部。 
        stack.push(u);
        return false;
    }

    private void display(int[] array) {
        for(int arr : array) {
            System.out.println(arr);
        }
    }
}
```
