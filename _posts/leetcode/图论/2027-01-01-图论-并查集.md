## 并查集起源

**并查集**的英文是Disjoint-set data structure， 直译就是不相交的数据结构，并查集专用于处理不相交的集合的合并和查询问题。

1. 合并（union）：合并两个顶点的集合，并将它们的根结点保持一致；
2. 查询（find）：查询某个元素属于哪个集合，返回集合中的代表元素，一般就是根结点。

因此这种数据结构也常被称为`Union-Find Data Structure`。

并查集的主要作用是用来解决**网络中的连通性**。

1. 并查集只回答两个结点是不是在一个连通分量中，并不回答路径问题；
2. 如果一个问题具有传递性，可以考虑使用并查集。

并查集只是解决两个结点的连通性，非常朴素的思想就是把这些结点按照连通性放到不同的集合中，两个顶点在一个集合中就说明这两个结点是连通的。

下图就是网络中的各个结点，其实可以看成多个无向图。

并查集的第一种编程思想：

我们把所有的结点放到一个数组中，数组的下标索引代表顶点本身，数组值选择顶点的父顶点（虽然是无向图，谁是谁的父结点，无所谓随便选就是了，反正只看连不连通）。

<!-- 这是一张图片，ocr 内容为： -->
![](http://139.198.106.15/wp-content/uploads/2022/07/image-10.png)

根顶点的特征为父顶点为它自己（入度为0）

这样的数据结构要判断两个顶点是否连通时，分别找到两个顶点的所在的集合代表，集合代表当然是根顶点了。看两个根顶点是否相等，就能判断是否在一个集合中。

比如说，要找到顶点3属于哪个集合，就先找root[3] = 1  != 3，因此继续找root[1] = 0 != 1，继续找root[0] = 0 == 0，因此顶点3的根顶点为0，属于0为代表的集合。

从这个过程看，判断两个顶点是否连通的时间复杂度为O(N)

连接：如果要连接2跟4，只需要将顶点4点父顶点改为2即可。连接的复杂度为O(1)

并查集的两个实现方式：

1. Quick Find 实现方式：它指的是实现「并查集」时，find 函数时间复杂度很低为 O(1)，但对应的 union 函数就需要承担更多的责任，它的时间复杂度为 O(N)。
2. Quick Union 实现方式：它指的是实现「并查集」时，相对于 Quick Find 的实现方式，我们通过降低 union 函数的职责来提高它的效率，但同时，我们也增加了 find 函数的职责。

## Quick Find
上面说到，查询连通的速度为O(N)，连接的速度为O(1)；

如果我们希望查询连通的速度能快一点呢？

那就进一步优化，直接将数组的值定义为根结点，这样每次查找的速度都为O(1）了。

<!-- 这是一张图片，ocr 内容为： -->
![](http://139.198.106.15/wp-content/uploads/2022/07/image-11.png)

虽然判断连通的速度快了，但是连接顶点2跟顶点4的操作步骤却多了，因为不仅需要将4的根顶点改为0，还需要遍历将顶点4的子顶点8的数组值同样改为根结点的值，同样需要改为0。

所以连接两个顶点的时间复杂度为O(N)

代码：

```java
public class UnionFind {
  int root[];
  // 初始化
  public UnionFind(int size) {
    root = new int[size];
    for (int i = 0; i < size; i++) {
      root[i] = i;
    }
  }

  // 查询顶点的根顶点
  public int find(int x) {
    return root[x];
  }

  // 合并两个顶点的集合	
  public void union(int x, int y) {
    // find(2) = 0, find(4) = 4;
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
      for (int i = 0; i < root.length; i++) {
        //y集合合并到x集合中，把所有根顶点为y的数组值改为x的根顶点
        if (root[i] == rootY) {
          root[i] = rootX;
        }
      }
    }
  }

  public boolean connected(int x, int y) {
    return find(x) == find(y);
  }
}
```

时间复杂度：

| | 构造函数 | find | union | connected | 连接N个顶点 |
| --- | --- | --- | --- | --- | --- |
| 时间复杂度 | O(N) | O(1) | O(N) | O(N) | N*O(N) = O(N^2) |

## Quick Union
Quick Find数组值是根结点；

Quick Union数组值父顶点，但是在初始化同一个集合的时候，会把一个集合中的所有顶点的父顶底都设置为根顶点。

`(0, 1), (1, 2), (1, 3), (4, 5), (4, 6), (1, 5)` 

<!-- 这是一张图片，ocr 内容为： -->
![](http://139.198.106.15/wp-content/uploads/2022/07/image-12-1024x235.png)

这样看起来似乎与Quick Find中的数组存储根顶点一样啊，但实际上还是有差别的，差别就体现在Union两个集合的时候其中一个集合的子顶点以下的点不会改为组合后的根顶点，比如连接2跟4，4的父节点改为0，但8的父节点仍然保持4不变。

```java
public class UnionFind {
  int root[];

  public UnionFind(int size) {
    root = new int[size];
    for (int i = 0; i < size; i++) {
      root[i] = i;
    }
  }

  public int find(int x) {
    while (x != root[x]) {
      x = root[x];
    }
    return x;
  }
  // 同一个集合中
  public void union(int x, int y) {
    // find(2) == 0, find(4) == 4
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
      // 连接x与y时，y的父顶点的父顶点（根顶点）设置为x的父顶点（根顶点）
      root[rootY] = rootX;
    }
  };

  public boolean connected(int x, int y) {
    return find(x) == find(y);
  }
}
```

这样做的好处是：

find、union、connected在最坏的情况下都是O(n)，最坏的情况就是指所有的顶点连成一根线形成一根线的图。下面模拟最坏的情况：

![](http://139.198.106.15/wp-content/uploads/2022/07/image-15.png)

```java

    // 0的父顶点设置为1
```

但整体来说，quick-union的算法比quick-find的算法更为高效，因为最坏的情况毕竟是少数。

| | 构造函数 | find | union | connected | 连接N个顶点 |
| --- | --- | --- | --- | --- | --- |
| quick-find | O(N) | O(1) | O(N) | O(N) | N*O(N) = O(N^2) |
| quick-union | O(N) | <=O(N) | <=O(N) | O(N) | <= N*O(N) = O(N^2) |

## 按秩合并 - Union函数优化

按秩合并是针对于「Quick Union」算法中「union」函数的一种优化。

前面我们说到，「Quick Union」在所有顶点连成一根线时，find的时间复杂度为O(N)。那为何我们不防止它连接成一根线呢？于是有了按秩合并的「Quick Union」。

这里的「秩」指的就是每个顶点所处的高度，我们每次Union两个顶点的时候，「Quick Union」算法选择根结点的时候是随机的选择某个顶点的根结点，「按秩合并」而是将「秩」大的那个根结点作为两个顶点的根结点，换句话说，我们将低的树合并到高的树之下，将高的树的根节点作为两个顶点的根节点。这样，我们就避免了所有的顶点连成一条线，同时最后构成的树的高度近似logN，这就是按秩合并优化的「并查集」。

```java
// UnionFind.class
public class UnionFind {
  int root[];
  // 其实也就是高度
  int rank[];

  public UnionFind(int size) {
    root = new int[size];
    rank = new int[size];
    for (int i = 0; i < size; i++) {
      root[i] = i;
      rank[i] = 1; 
    }
  }

  public int find(int x) {
    while (x != root[x]) {
      x = root[x];
    }
    return x;
  }

  public void union(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if(rootX == rootY) {
      return ;
    }
    // rootX的秩大于rootY，说明X的高度比Y高，于是将Y的父顶点设置为X
    if (rank[rootX] > rank[rootY]) {
      root[rootY] = rootX;
    } else if (rank[rootX] < rank[rootY]) {
      root[rootX] = rootY;
    } else {
      // 高度相当的情况下rootX作为根结点，rootX的高度就加1
      root[rootY] = rootX;
      rank[rootX] += 1;
    }
  };

  public boolean connected(int x, int y) {
    return find(x) == find(y);
  }
}

// App.java
// 测试样例
public class App {
  public static void main(String[] args) throws Exception {
    UnionFind uf = new UnionFind(10);
    // 1-2-5-6-7 3-8-9 4
    uf.union(1, 2);
    uf.union(2, 5);
    uf.union(5, 6);
    uf.union(6, 7);
    uf.union(3, 8);
    uf.union(8, 9);
    System.out.println(uf.connected(1, 5)); // true
    System.out.println(uf.connected(5, 7)); // true
    System.out.println(uf.connected(4, 9)); // false
    // 1-2-5-6-7 3-8-9-4
    uf.union(9, 4);
    System.out.println(uf.connected(4, 9)); // true
  }
}
```

时间复杂度：

| | 构造函数 | find函数 | union函数 | connected函数 |
| --- | --- | --- | --- | --- |
| 时间复杂度 | O(N) | O(logN) | O(logN) | O(logN) |

## 路径压缩优化的「并查集」

![](https://cdn.nlark.com/yuque/0/2024/png/32473878/1715326352258-277383dc-e4cb-47ef-b026-4f69406e77b8.png)

路径压缩是针对于「quick union」算法中「find」函数的一种优化。

从前面的「并查集」实现方式中，我们不难看出，要想找到一个元素的根节点，需要沿着它的父亲节点的足迹一直遍历下去，直到找到它的根节点为止。如果下次再查找同一个元素的根节点，我们还是要做相同的操作。那我们有没有什么办法将它升级优化下呢？

答案是可以的！如果我们在找到根节点之后，将所有遍历过的元素的父节点都改成根节点，那么我们下次再查询到相同元素的时候，我们就仅仅只需要遍历两个元素就可以找到它的根节点了，这是非常高效的实现方式。那么问题来了，我们如何将所有遍历过的元素的父节点都改成根节点呢？这里就要拿出「递归」算法了。这种优化我们称之为「路径压缩」优化，它是对 find 函数的一种优化。

```java
// UnionFind.class
public class UnionFind {
  int root[];

  public UnionFind(int size) {
    root = new int[size];
    for (int i = 0; i < size; i++) {
      root[i] = i;
    }
  }
  // 用递归的方式改变find中的路径的顶底的父顶点
  public int find(int x) {
    if (x == root[x]) {
      return x;
    }
    // int rootX = find(root[x]);
    // root[x] = rootX;
    // return rootX;
    return root[x] = find(root[x]);
  }

  public void union(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
      root[rootY] = rootX;
    }
  };

  public boolean connected(int x, int y) {
    return find(x) == find(y);
  }
}

// App.java
// 测试样例
public class App {
  public static void main(String[] args) throws Exception {
    UnionFind uf = new UnionFind(10);
    // 1 2 3 4 5 
    uf1.union(1, 0);
    uf1.union(2, 1);
    uf1.union(3, 2);
    uf1.union(4, 3);
    uf1.union(5, 4);
    uf1.find(0);
    System.out.println(uf.connected(4, 9)); // true
  }
}
```

| --- | --- | --- | --- | --- | --- | --- |
| 顶点 | 0 | 1 | 2 | 3 | 4 | 5 |

使用find后，root数组长这样：

| 父结点 | 5 | 5 | 5 | 5 | 5 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 顶点 | 0 | 1 | 2 | 3 | 4 | 5 |

| --- | --- | --- | --- | --- |
| 时间复杂度 | O(N) | O(logN) | O(logN) | O(logN) |

## 「Quick-Union」路径压缩  和 按秩合并 的组合版本
按秩合并是在Union的时候降低树的高度，

路径压缩是在find的时候降低树的高度。

按秩合并针对于「quick-union」算法的union，路径压缩针对于find，两者是可以合并的，

合并的时间复杂度:

| | 构造函数 | find函数 | union函数 | connected函数 |
| --- | --- | --- | --- | --- |
| 时间复杂度 | O(N) | O(alpha(N)) | O(alpha(N)) | O(alpha(N)) |

alpha(N)是一个增长非常慢的函数。

由于路径压缩采用「一边查询，一边修改树结构」的策略，并且 修改树的结构是不可逆的，合并之前需要先查询再合并。如果次数非常多的话，最后并查集里所有的树的高度都只有 2，平均到每一次「合并」和「查询」操作，步骤是常数次的。

```java
// UnionFind.class
public class UnionFind {
  int root[];
  // 添加了 rank 数组来记录每个顶点的高度，也就是每个顶点的「秩」
  int rank[];

  public UnionFind(int size) {
    root = new int[size];
    rank = new int[size];
    for (int i = 0; i < size; i++) {
      root[i] = i;
      rank[i] = 1; // 一开始每个顶点的初始「秩」为1，因为它们只有自己本身的一个顶点。
    }
  }

  // 此处的 find 函数与路径压优化缩版本的 find 函数一样。
  public int find(int x) {
    if (x == root[x]) {
      return x;
    }
    return root[x] = find(root[x]);
  }

  // 按秩合并优化的 union 函数
  public void union(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
      if (rank[rootX] > rank[rootY]) {
        root[rootY] = rootX;
      } else if (rank[rootX] < rank[rootY]) {
        root[rootX] = rootY;
      } else {
        root[rootY] = rootX;
        rank[rootX] += 1;
      }
    }
  };

  public boolean connected(int x, int y) {
    return find(x) == find(y);
  }
}

// App.java
// 测试样例
public class App {
  public static void main(String[] args) throws Exception {
    UnionFind uf = new UnionFind(10);
    // 1-2-5-6-7 3-8-9 4
    uf.union(1, 2);
    uf.union(2, 5);
    uf.union(5, 6);
    uf.union(6, 7);
    uf.union(3, 8);
    uf.union(8, 9);
    System.out.println(uf.connected(1, 5)); // true
    System.out.println(uf.connected(5, 7)); // true
    System.out.println(uf.connected(4, 9)); // false
    // 1-2-5-6-7 3-8-9-4
    uf.union(9, 4);
    System.out.println(uf.connected(4, 9)); // true
  }
}
```

## 并查集数据结构总结
### 并查集代码基本结构

```java
public class UnionFind {
  // UnionFind 的构造函数，size 为 root 数组的长度
  public UnionFind(int size) {}
  public int find(int x) {}
  public void union(int x, int y) {}
  public boolean connected(int x, int y) {}
}
```

### 并查集的Find函数
它主要是用于查找顶点 x 的根结点。

find函数的基本实现，数组值是父结点的时候。

```java
public int find(int x) {
    while (x != root[x]) {
        x = root[x];
    }
    return x;
}
```

find函数的优化 - 路径压缩

```java
public int find(int x) {
    if (x == root[x]) {
        return x;
    }
    return root[x] = find(root[x]);
}
```

### 并查集的Union函数
它主要是连接两个顶点 x 和 y 。将它们的根结点变成相同的，即代表它们来自于同一个根节点。

union的基本实现：

```java
// 连接顶点x和y，让x的根结点作为y的根结点
public void union(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if(rootX == rootY) {
        return ;
    }
    root[rootY] = x;
}
```

union函数的优化 - 按秩合并：

```java
public void union(int x, int y) {
  int rootX = find(x);
  int rootY = find(y);
  if (rootX != rootY) {
    if (rank[rootX] > rank[rootY]) {
      root[rootY] = rootX;
    } else if (rank[rootX] < rank[rootY]) {
      root[rootX] = rootY;
    } else {
      root[rootY] = rootX;
      rank[rootX] += 1;
    }
  }
}
```

### 并查集的connected函数
它主要是检查两个顶点 x 和 y 的「连通性」。这个函数通过顶点 x 和 y 的根结点是否相同来判断 x 和 y 的「连通性」。如果 x 和 y 的根结点相同，则为连通。反之，则为不连通。

如果find函数是路径优化的版本，connected也是会改变root数组的结构的。

```java
public boolean connected(int x, int y) {
    return find(x) == find(y);
}
```

## LeetCode
### [547. 省份数量](https://leetcode.cn/problems/number-of-provinces/)
```java
class Solution {
  public int findCircleNum(int[][] isConnected) {
    // 1. 并查集
    // 2. 图的dfs，bfs遍历
    /**
      1 1 0
      1 1 1
      0 0 1
    */
    int n = isConnected.length;
    UnionFind uf = new UnionFind(n);
    for(int i = 0; i < n; i++) {
      // n*n无向图，isConnected必然是对称的
      for(int j = i; j < n; j++) {
        if(isConnected[i][j] == 1) {
          uf.union(i, j);
        } 
      }
    }
    return uf.getCount();
  }
}
class UnionFind {
  int[] root;
  int[] rank;
  int count;
  UnionFind(int n) {
    root = new int[n];
    rank = new int[n];
    for(int i = 0; i < n; i++) {
      root[i] = i;
      rank[i] = 1;
    }
    count = n;
  }

  public int find(int x) {
    if(x == root[x]) {
      return x;
    }
    return root[x] = find(root[x]);
  }

  public void union(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if(rootX == rootY) {
      return ;
    }
    if(rank[rootX] < rank[rootY]) {
      root[rootX] = rootY; 
    } else if(rank[rootX] > rank[rootY]) {
      root[rootY] = rootX;
    } else {
      root[rootX] = rootY;
      rank[rootY]++;
    }
    // 节点数初始化为N 合并一次少一个
    count--;
  }

  public boolean connected(int x, int y) {
    return find(x) == find(y);
  }

  public int getCount() {
    return this.count;
  }

}
```

### [990. 等式方程的可满足性](https://leetcode.cn/problems/satisfiability-of-equality-equations/)
每个等式中的变量都看成一个顶底，先识别所有的「==」做一个union连接，再识别「a != b」，如果a的根结点和b的根结点已经相等了，就说明已经在一个集合，就与这个不等式冲突了。

```java
class Solution {
  /**
        - a - b - c
        a 1 - 1 - 0
        b 1 - 1 - 0
        c 1 - 0 - 1

        a a 
        a b c
    */
  public boolean equationsPossible(String[] equations) {
    UnionFind uf = new UnionFind();
    for(int i = 0; i < equations.length; i++) {
      String equation = equations[i];
      if(isEqual(equation)) {
        Character x = equation.charAt(0);
        Character y = equation.charAt(3);
        uf.union(x, y);
      }
    }

    for(int i = 0; i < equations.length; i++) {
      String equation = equations[i];
      if(!isEqual(equation)) {
        Character x = equation.charAt(0);
        Character y = equation.charAt(3);
        if(uf.find(x) == uf.find(y)){
          return false;
        }
      }
    }
    return true;

  }
  private boolean isEqual(String equation){
    return equation.charAt(1) == '=';
  }
  class UnionFind {
    Map<Character, Character> root;
    Map<Character, Integer> rank;
    UnionFind() {
      root = new HashMap<>();
      rank = new HashMap<>();
    }
    private Character find(Character x) {
      if(x == root.getOrDefault(x, x)) {
        return x;
      }
      Character rootX = find(root.getOrDefault(x, x));
      root.put(x, rootX);
      return rootX;
    }
    private void union(Character x, Character y) {
      Character rootX = find(x);
      Character rootY = find(y);
      if(rootX != rootY) {
        if(rank.getOrDefault(rootX, 1) > rank.getOrDefault(rootY, 1)) {
          root.put(rootY, rootX);
        } else if(rank.getOrDefault(rootX, 1) < rank.getOrDefault(rootY, 1)){
          root.put(rootX, rootY);
        } else {
          root.put(rootY, rootX);
          int high = rank.getOrDefault(rootX, 1);
          rank.put(rootX, high + 1);
        }
      }
    }
  }
}
```

### [399. 除法求值](https://leetcode.cn/problems/evaluate-division/)
除法具有传递性，如果一个问题具有传递性，可以考虑使用并查集。

变量之间的倍数关系具有传递性。

我们用并查集来维护这个背书关系。

```java
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Solution {

  /**
  a / b = c
  a -> b, w = c
   */

  public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {
    int equationsSize = equations.size();

    UnionFind unionFind = new UnionFind(2 * equationsSize);
    // 第 1 步：预处理，将变量的值与 id 进行映射，使得并查集的底层使用数组实现，方便编码
    Map<String, Integer> hashMap = new HashMap<>(2 * equationsSize);
    int id = 0;
    for (int i = 0; i < equationsSize; i++) {
      List<String> equation = equations.get(i);
      String u = equation.get(0);
      String v = equation.get(1);
      int value = values[i];
      // u / v = value

      if (!hashMap.containsKey(u)) {
        hashMap.put(u, id);
        id++;
      }
      if (!hashMap.containsKey(v)) {
        hashMap.put(v, id);
        id++;
      }

      unionFind.union(hashMap.get(u), hashMap.get(v), values[i]);
      unionFind.displayRoot();
      unionFind.displayWeight();
      System.out.println("--");
    }
    // unionFind.displayRoot();
    System.out.println("query");

    // 第 2 步：做查询
    int queriesSize = queries.size();
    double[] res = new double[queriesSize];
    for (int i = 0; i < queriesSize; i++) {
      String u = queries.get(i).get(0);
      String v = queries.get(i).get(1);

      Integer id1 = hashMap.get(u);
      Integer id2 = hashMap.get(v);

      if (id1 == null || id2 == null) {
        res[i] = -1.0d;
      } else {
        res[i] = unionFind.isConnected(id1, id2);
        unionFind.displayRoot();
        unionFind.displayWeight();
        System.out.println("--");
      }
    }
    // unionFind.displayRoot();
    return res;
  }

  private class UnionFind {

    private int[] parent;
    /**
         * 指向的父结点的权值
         */
    private double[] weight;


    public UnionFind(int n) {
      this.parent = new int[n];
      // 到父节点的有向边的权重
      this.weight = new double[n];
      for (int i = 0; i < n; i++) {
        parent[i] = i;
        weight[i] = 1.0d;
      }
    }

    // 正常的union
    public void union(int x, int y, double value) {
      // displayRoot();
      int rootX = find(x);
      int rootY = find(y);
      if (rootX == rootY) {
        return;
      }

      parent[rootX] = rootY;
      /**
      x -> rootX
      y -> rootY
      x / y = value => x ->(value) y
      链接rootX和rootY

      x -> rootX -> rootY
      x -> y -> rootY
      w(x, rootX) * w(rootX * rootY) = w(x, y) * w(y, rootY)
       
      w(rootX * rootY) = w(x, y) * w(y, rootY) / w(x, rootX)
      w[rootX] = value * w[y] / w[x]
       */
      weight[rootX] = weight[y] * value / weight[x];
    }

    /**
    * 路径压缩
    */
    public int find(int x) {
      if(x == parent[x]) {
        return x;
      }
      // 父节点        
      int origin = parent[x];
      // 更新权值
      weight[x] *= weight[origin];
      return parent[x] = find(parent[x]);
    }

    /*
    返回链接的权重，不连通则返回-1
    **/
    public double isConnected(int x, int y) {
      int rootX = find(x);
      int rootY = find(y);
      if (rootX == rootY) {
        return weight[x] / weight[y];
      } else {
        return -1.0d;
      }
    }

    private void displayRoot() {
      for(int i = 0; i < parent.length; i++) {
        System.out.print(parent[i]+" ");
      }
      System.out.println();
    } 

    private void displayWeight() {
      for(int i = 0; i < weight.length; i++) {
        System.out.print(weight[i]+" ");
      }
      System.out.println();
    } 
  }
}
```

### [1319. 连通网络的操作次数](https://leetcode.cn/problems/number-of-operations-to-make-network-connected/)
1. 当顶点数为N时，至少需要`N - 1`条边才能将他们连接；
2. 连接K条边后，剩余的连通分量的个数 - 1 就是 全部顶点连通需要的边。 
    1. 同时，如果已有的操作形成的边不可能连通所有顶点就直接返回-1；
    2. 所以，边一定是大于等于n-1的，只需要计算出连通分量，连通分量-1就是最终的答案；

```java
class Solution {
  public int makeConnected(int n, int[][] connections) {
    int size = connections.length;
    // 少于n-1条边，则无法连接所有的顶点
    if(size < n - 1) {
      return -1;
    }
    UnionFind unionFind = new UnionFind(n);
    for(int[] connection: connections){
      int x = connection[0];
      int y = connection[1];
      unionFind.union(x,y);
    }
    return unionFind.getCount() - 1;
  }
  private class UnionFind{
    // 剩余连通分量的个数
    private int count;
    private int[] root;
    private int[] rank;

    public UnionFind(int n){
      this.count = n;
      root = new int[n];
      rank = new int[n];
      for(int i = 0;i < n;i++){
        root[i] = i;
        rank[i] = 1;
      }
    }
    // 路径压缩
    public int find(int x){
      if(x == root[x]) {
        return x;
      }
      return root[x] = find(root[x]);
    }
    // 按秩合并
    public void union(int x,int y){
      int rootX = find(x);
      int rootY = find(y);
      if(rootX == rootY) {
        return;
      }
      if(rank[rootX] > rank[rootY]) {
        root[rootY] = rootX;
      } else if(rank[rootX] < rank[rootY]) {
        root[rootX] = rootY;
      } else {
        root[rootY] = rootX;
        rank[rootX]++;
      }
      this.count--;
    }
    public int getCount(){
      return this.count;
    }
  }
}
```
