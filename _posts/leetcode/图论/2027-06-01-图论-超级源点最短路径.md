## [1162. 地图分析](https://leetcode.cn/problems/as-far-from-land-as-possible/)
`n*n`的网格，单元格值不是0就是1，找出一个单元格0，这个单元格离**最近**单元格1的距离是最大的，返回该距离。

求最短距离，我们可以用BFS一个一个的求最短距离，但是单元格都是0的情况下会求N^2次BFS，每次BFS的时间复杂度是O(N^2)，那时间复杂度就是O(N^4)。

单元格0采用dijkstra来算，优先队列版本的时间复杂度是O(E*logE)，

引入一种新的技巧：

既然源点是多个，用不了dijkstra，那我们何不如创建一个超级源点，这个超级源点到单元格1的距离为0，我们要求的是这个超级源点到每一个单元格0的最短距离，也是也就是等价于**单元格1集群到单元格0的最短距离**。最后求出的`dist[i][j]`就是单元格1集群到单元格0的最短距离。

我们再选择其中最大的距离，就是题目要求的单元格0离**最近单元格1**的最大距离。

> 我们求的是找到某个单元格0到最近单元格1的最大距离，但我们这里超级源点选择的是单元格1，而不是单元格0。
>
> 选择单元格0，意味着 单元格0集群到每一个单元格1的最短距离，最后得到的也就是 单元格1到最近单元格0的最短距离。
>
> 选择单元格1，意味着 单元格1集群到每一个单元格0的最短距离，最后得到的也就是 单元格0到最近单元格1的最短距离。
>

```java
class Solution {
  int INF = Integer.MAX_VALUE;
  int[][] directions = new int[][]{{0,1}, {0,-1}, {1, 0},{-1, 0}};
  public int maxDistance(int[][] grid) {

    return dijkstra(grid);
  }

  public int dijkstra(int[][] grid) {
    PriorityQueue<int[]> queue = new PriorityQueue<>((u, v) -> u[0] - v[0]);

    // 超级源点到其他顶点的最短距离
    int[][] distTo = new int[grid.length][grid[0].length];
    boolean[][] visited = new boolean[grid.length][grid[0].length];
    for(int i = 0; i < grid.length; i++) {
      for(int j = 0; j < grid[0].length; j++) {
        // 陆地作为源点集加入超级源点
        if(grid[i][j] == 1) {
          distTo[i][j] = 0;
          // 最短距离
          queue.offer(new int[]{0, i, j});
          visited[i][j] = true;
        } else {
          distTo[i][j] = INF;
        }
      }
    }

    while(!queue.isEmpty()) {
      int[] top = queue.poll();
      int du = top[0];
      int ux = top[1];
      int uy = top[2];
      for(int[] direction : directions) {
        int dx = direction[0];
        int dy = direction[1];
        int vx = ux + dx;
        int vy = uy + dy;
        if(isInGrid(grid, vx, vy) && !visited[vx][vy]) {
          // u -> v dv = du + w(u, v)
          int dv = du + 1;
          if(dv < distTo[vx][vy]) {
            distTo[vx][vy] = dv;
            visited[vx][vy] = true;
            queue.offer(new int[]{distTo[vx][vy], vx, vy});
          }
        }
      }
    }
    // display(distTo);

    return findMax(grid, distTo);
  }

  /***
distTo[i][j] 陆地到每一个海洋[i,j]的最短距离
*/
  private int findMax(int[][] grid, int[][] distTo) {
    int maxDistance = -1;
    for(int i = 0; i < grid.length; i++) {
      for(int j = 0; j < grid[0].length; j++) {
        if(grid[i][j] == 0) {
          maxDistance = Math.max(maxDistance, distTo[i][j]);
        }
      }
    }

    return maxDistance == INF ? -1 : maxDistance;
  }

  private boolean isInGrid(int[][] grid, int x, int y) {
    return x >= 0 && x < grid.length && y >= 0 && y < grid[0].length;
  }

  private void display(int[][] distTo) {
    for(int i = 0; i < distTo.length; i++) {
      System.out.print("[");
      for(int j = 0; j < distTo[0].length; j++) {
        System.out.print(distTo[i][j] + ", ");
      }
      System.out.print("]");
      System.out.println();
    }

  }
}
```

时间复杂度为O(N^2*logN)

SPFA算法：

```java
class Solution {
  int INF = Integer.MAX_VALUE;
  int[][] directions = new int[][]{{0,1}, {0,-1}, {1, 0},{-1, 0}};
  public int maxDistance(int[][] grid) {

    return SPFA(grid);
  }

  public int SPFA(int[][] grid) {
    Deque<int[]> queue = new ArrayDeque<>();

    // 超级源点到其他顶点的最短距离
    int[][] distTo = new int[grid.length][grid[0].length];
    boolean[][] inq = new boolean[grid.length][grid[0].length];
    for(int i = 0; i < grid.length; i++) {
      for(int j = 0; j < grid[0].length; j++) {
        // 陆地作为源点集加入超级源点
        if(grid[i][j] == 1) {
          distTo[i][j] = 0;
          // 最短距离
          queue.offer(new int[]{i, j});
          inq[i][j] = true;
        } else {
          distTo[i][j] = INF;
        }
      }
    }
    while(!queue.isEmpty()) {
      int[] u = queue.poll();
      int ux = u[0];
      int uy = u[1];
      inq[ux][uy] = false;
      for(int[] direction : directions) {
        int vx = ux + direction[0];
        int vy = uy + direction[1];
        if(isInGrid(grid, vx, vy)) {
          int dv = distTo[ux][uy] + 1;
          if(dv < distTo[vx][vy]) {
            distTo[vx][vy] = dv;
            if(!inq[vx][vy]){
              queue.offer(new int[]{vx, vy});
            }
          }
        }
      }
    }
    // display(distTo);
    return findMax(grid, distTo);
  }

  /***
distTo[i][j] 陆地到每一个海洋[i,j]的最短距离
*/
  private int findMax(int[][] grid, int[][] distTo) {
    int maxDistance = -1;
    for(int i = 0; i < grid.length; i++) {
      for(int j = 0; j < grid[0].length; j++) {
        if(grid[i][j] == 0) {
          maxDistance = Math.max(maxDistance, distTo[i][j]);
        }
      }
    }

    return maxDistance == INF ? -1 : maxDistance;
  }

  private boolean isInGrid(int[][] grid, int x, int y) {
    return x >= 0 && x < grid.length && y >= 0 && y < grid[0].length;
  }

  private void display(int[][] distTo) {
    for(int i = 0; i < distTo.length; i++) {
      System.out.print("[");
      for(int j = 0; j < distTo[0].length; j++) {
        System.out.print(distTo[i][j] + ", ");
      }
      System.out.print("]");
      System.out.println();
    }
  }
}
```
